# Project Eloria — 第１章チェックポイント

ブラウザで遊べる見下ろし型アクションRPGです。画像背景とユーザー指定の赤線に基づく足元の歩行判定、キャラクタースプライト、探索・戦闘・会話を組み合わせています。

第１章は、タイトルと序章→古の森→洞窟の第１〜３層→ヴェルグラン戦→封印石→森への帰還まで。取得後も洞窟へ再訪し、平穏なヴェルグランとの会話から任意帰還できます。村のプレイ可能マップや次章は未実装です。

現状・承認済み仕様・検証の限界は [引き継ぎ資料](docs/project-handoff.md) を参照してください。

## 起動

Finderから起動する場合は、プロジェクト直下の
`Project Eloriaを起動.command` をダブルクリックしてください。準備完了後にブラウザが
自動的に開きます。終了するときは `Project Eloriaを停止.command` をダブルクリックします。

開発者向けの通常起動も引き続き利用できます。

```bash
npm ci
npm run dev
```

表示されたURL（通常は `http://127.0.0.1:4173`）をPCブラウザで開いてください。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 通常攻撃 | J（長押し可） |
| 特殊技 | K |
| 大技 | L |
| キャラクター交代 | Space |
| 決定・再挑戦 | E / Enter |
| ポーズ | Esc |
| BGMミュート | M |

タッチ端末では左半分にフローティングスティック、右側に4つのアクションボタンを表示します。
最後に使った入力方式がキーボードならタッチUIは隠れます。

通常戦闘BGMは「晶界を駆ける」です。最初のクリックまたはキー操作後に再生されます。
ポーズ画面ではBGM音量とミュートを変更でき、設定は次回起動時にも引き継がれます。

## 検証環境

Node.jsとnpmに加え、テスト／ビルドの事前マスク検査にはPython 3とPillowが必要です。Python環境を分ける場合の例：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pillow
```

第２層の赤線マスクを再生成する場合はNumPyも必要です。通常の起動では、保存済みのマスクデータを使用します。

2026-10-28に型検査・全427テスト・製品ビルドの通過を再確認しました。ブラウザー検証は隔離Chromeと画面サイズ／タッチ模擬によるもので、実機・Safari/WebKit・VoiceOver・全章の手動通しプレイは未確認です。

## 開発コマンド

```bash
npm run typecheck
npm test
npm run build
```

主なバランス値とアクセシビリティ設定は `src/config.ts` に集約しています。
`ACCESSIBILITY.screenShake` と `ACCESSIBILITY.strongFlashes` を `false` にすると、
画面振動または強いヒット点滅を無効化できます。

敵AIと味方陣形の調整値は、同ファイルの `ENEMY_AI` と `PARTY_AI` に集約しています。
開発サーバーでURLへ `?debug-ai` を付けると、索敵半径、AI状態、攻撃権・準備枠、
敵の予約位置、味方の陣形スロットをCanvas上へ表示できます。本番ビルドではこの指定を
付けてもデバッグ表示は有効になりません。

## GitHub Pagesへの更新

`main` にpushすると、GitHub Actionsが依存物の導入・型検査・テスト・既存prebuild検査込みのビルドを行い、`dist` のみを公開します。PagesのSourceはGitHub Actionsです。

公開と製品previewのbaseは `/project-eloria/`、通常の開発サーバーは `/` です。ローカルで公開用ビルドを確認する場合：

```bash
npm run build
npx vite preview
```

表示されたサーバーの `/project-eloria/` を開いてください。公開検証の範囲と記録は引き継ぎ資料のGitHub Pages節を参照してください。
