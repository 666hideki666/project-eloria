# Party HUD portraits

Project Eloriaのパーティーステータス欄用ポートレートです。

## ゲーム用

- `kyle/kyle-hud-portrait-32px-v1.png`
- `nadi/nadi-hud-portrait-32px-v1.png`
- `mel/mel-hud-portrait-32px-v1.png`

いずれも32×34px、RGBA、透明背景です。原寸・nearest-neighborで表示します。

## 高密度表示用

- `kyle/kyle-hud-portrait-64px-v1.png`
- `nadi/nadi-hud-portrait-64px-v1.png`
- `mel/mel-hud-portrait-64px-v1.png`

いずれも64×68pxです。将来、HUDを拡大する場合や高DPI表示の調整に使用できます。

## 制作資料

各キャラクターのフォルダには、透過前のクロマキー版と高解像度透過版も保存しています。ゲームでは読み込まず、再加工用の資料として保持してください。
