# 操作キャラの頭上に出る黄色いマーカーを消す：実装指示案 v1

状態：**ユーザー承認・実装・技術検証済み**（2026-10-14「実装に移って！」）。頭上の黄色いひし形を共通描画から削除し、専用関数・共通設定・３人分の専用位置設定を整理した。推奨モデル：**Sol High**。

## 現象と原因

- 第１層「苔根の遺構」の開始地点で、カイルの頭上に小さな黄色いひし形が表示される。ユーザーが赤丸で示したもの。
- これは背景画像や洞窟の帰還処理ではなく、現在操作しているキャラを示す**ワールド上のアクティブマーカー**。`src/render/Renderer.ts` の `drawCharacter()` が操作キャラに `drawActiveCharacterMarker()` を呼び、`src/render/characterGroundingConfig.ts` の黄色・ひし形設定を描画している。

## 変更範囲

1. 操作キャラの頭上に描く黄色いひし形を、古の森・第１〜第３層・守護者戦の全エリアで表示しない。カイルだけでなく、ナディ・メルへ切り替えた場合も同様。別の頭上マーカーには置き換えない。
2. `drawCharacter()` から当該描画呼び出しを外し、専用関数や未使用になった設定値は参照関係を確認した上で整理する。キャラスプライト、足元の影、重なり順、位置、当たり判定、操作キャラ切り替えは変えない。
3. 左上のパーティーステータスにある操作キャラの選択表示は維持する。敵の状態表示、会話・調査の操作案内、ダメージ・回復等の演出は本件の対象外。頭上に出るものを一括で消す変更にはしない。

## 検証

- 第１層開始時の同じ場所で、黄色いひし形が消え、キャラ・影・入場タイトルが従来どおり描画される。
- 古の森→第１層→古の森の往復、キャラ切り替え、戦闘、各層の直接開始で、操作キャラの頭上に印が再表示されない。左上の選択中表示は機能する。
- 型検査、全テスト、ビルドを通し、実画面で確認する。検証に使ったブラウザ・サーバー・BGMは作業後に閉じる。

参照：`src/render/Renderer.ts`、`src/render/characterGroundingConfig.ts`、`src/render/characterSpriteConfig.ts`、`src/style.css`。

## 実装・検証結果（2026-10-14）

- 変更は `Renderer.ts`、`characterGroundingConfig.ts`、`characterSpriteConfig.ts` のマーカー専用処理のみ。左上HUD、スプライト・影・重なり順・位置・当たり判定・交代処理、ほかの案内や演出は変更していない。削除した専用関数・設定への参照が残っていないことを確認。
- `npm run typecheck`、`npm test -- --reporter=dot`（16ファイル・344件）、`npm run build` が通過。
- ブラウザで古の森・第１〜第３層・守護者戦の直接開始と各エリアでのカイル→ナディ→メルへのSpace交代を確認。全15組み合わせで頭上のひし形を描画せず、左上の「操作中」表示と選択キャラが一致した。第１層の開始地点で３人のスプライトと影、入場タイトルを目視確認。
- 古の森→第１層→古の森の実操作による往復、第１層の戦闘開始・戦闘中交代を確認。敵HP表示と戦闘案内も描画された。画面記録：`docs/screenshots/no-overhead-marker-*-v1.png`。
- 検証用Chrome・一時プロファイルを終了し、サーバーを停止した。音声は検証ブラウザでミュート。今回の表示修正について未確認の必須項目はない。各エリアの開始地点確認と第１層の戦闘確認であり、第１章の全区間連続プレイや守護者戦の完走は今回の範囲外。
