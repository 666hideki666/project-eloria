# 第１層の南階段から古の森へ戻る：実装指示案 v1

状態：**ユーザー承認・実装・技術検証済み**（2026-10-14「これで実装して！」）。第１層南階段→古の森の洞窟前を追加し、森→第１層→森→第１層を自動テストとブラウザ操作で確認した。型検査、全344テスト、ビルドが通過。赤線内の到着、押しっぱなし防止、進行状態保持、村道制限、北出口を確認済み。画面記録：`docs/screenshots/layer1-south-return-*-v1.png`。ボス後の自動帰還と村ルート解放は対象外。推奨モデル：**Sol High**。

## 目的と動線

- 現在は古の森の洞窟から第１層「苔根の遺構」の南側開始地点へ入れるが、逆方向の遷移がない。
- **第１層の開始地点より南にある階段を下へ歩く**と、既存の暗転による部屋遷移で、**古の森の洞窟入口のすぐ外**へ出す。E操作・新しいワープ装置・ゲート画像は不要。通常プレイ中なら第１層の仕掛け解除前でも引き返せる。
- 森へ戻った後はそのまま森を探索でき、洞窟へ再入場もできる。現在の村方面の物語上の制限は維持する。ボスクリア後の自動帰還、村ルート解放、帰村後の物語は本指示の対象外。

## 座標・赤線の扱い

- 第１層の南端は、元背景の赤線マスクで原画像 y=1200 付近に x=603〜688 の通路がある。現在のワールド寸法2048×1920では南階段の中央は x=1024 付近。`MOSS_ROOT_RUINS.spawn` は `(1024,1840)` なので、南出口の判定は開始位置より十分下、例えば **y≥1890、x=1024±40、下方向入力**を目安にする。最終値は実画面と足元判定で決め、画像外や赤線外から発動させない。
- 古の森の原画像では洞窟前の x=825, y=160 付近は赤線内で、既存の洞窟入場線 y≤105 より手前にある。帰還先の第一候補は `ancientForestSourceToWorld({x:825,y:160})`。森の現行1152×768ワールドではおよそ `(619,120)`。森の通常開始位置 `(585,675)` へ飛ばさない。
- 第１層・森の背景、原寸赤線画像、歩行マスクは**一切描き直さない**。足元一点と移動線分全体の判定を維持し、必要なのは既存の南階段／洞窟前に遷移条件を重ねることだけ。

## 遷移と状態

1. 既存の `beginRoomTransition` / `configureStageRoom` を使い、第１層南端から `ancientForest` へ移動する。暗転中や戦闘中、会話中は既存どおり遷移させない。森への到着時は南向きで洞窟から出たように見せ、カメラを帰還位置へ合わせる。
2. 到着位置は洞窟へ入る判定線から離し、`layerTransitionCooldown` と合わせ、入力押しっぱなしで森→第１層→森を瞬時に往復しないようにする。第１層へ再入場したときも開始階段からすぐ南出口に誤発動しないこと。
3. 帰還してもパーティーのHP/MP・技ゲージ、取得済み報酬、クリスタル／根の解除、既存の階層解放状態を不意にリセットしない。敵の再出現は現行の部屋移動ルールに合わせ、新しい例外仕様を作らない。
4. 森の中央入場タイトルを既存の演出で表示する場合、森の通常開始と同じ表現にし、古いバナーや第１層の名前を重複表示しない。BGM・カメラ・全画面UI・DEV直接開始も退行させない。

## 検証

- **往復の実操作**：古の森→洞窟→第１層→南階段→洞窟前の森→再び第１層を確認。第１層で初期位置に立つだけ、横から出口へ近づくだけ、南端の赤線外へ向かうだけでは遷移しない。
- 森到着時と再入場時に足元が赤線内で、追従者も安全位置にいる。南階段、森の洞窟前、狭い枝道の歩行が変わらない。村道制限、第１層北出口→第２層、根とクリスタルの進行も確認する。
- 自動テストに往復・押しっぱなし時の再遷移防止・進行フラグ保持を追加し、型検査・全テスト・ビルドを通す。ブラウザで確認してから、検証用ブラウザ・サーバー・BGMを閉じる。
