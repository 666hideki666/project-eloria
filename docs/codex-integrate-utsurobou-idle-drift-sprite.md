# Codex向け追加指示：ウツロボウの浮遊待機・移動スプライトを導入

Project Eloriaへ、石仮面を付けた浮遊霊「ウツロボウ」を正式な敵種別として追加し、現在の戦闘アリーナにいる3体目の仮敵をウツロボウへ置き換えてください。

現在のコードでは3体目が`iwaUroko`として生成されていますが、今回のユーザー決定では現在画面に出す2種類目はウツロボウです。`iwaUroko`の型、設定、簡易描画は後の正式実装に使うため削除しないでください。3体目の生成種別だけを新しい`utsurobou`へ変更します。

今回は待機と浮遊移動の正式スプライト化までを対象にします。ウツロボウ専用の攻撃・被弾・消滅・半透明フェーズは次の作業で追加するため、複雑な耐性システムや新しい攻撃エフェクトはまだ実装しないでください。

## 使用素材

- 画像：`assets/sprites/enemies/utsurobou/utsurobou-idle-drift-48px-v1.png`
- 設定：`assets/sprites/enemies/utsurobou/utsurobou-idle-drift-48px-v1.json`
- 採用コンセプト：`assets/concepts/monsters/utsurobou-pixel-concept-v1.png`

`utsurobou-pixel-concept-v2.png`は石仮面なしの不採用案です。今回の表示や参照へ使用しないでください。

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- 推奨描画倍率：0.8
- アンカー：`x: 0.5`, `y: 0.92`

方向行：

- 0行目：下向き・正面。石仮面が全面に見える。
- 1行目：上向き・背面。石仮面はフードの裏側なので見えない。
- 2行目：左向き。石仮面を薄い横顔として表示。
- 3行目：右向き。石仮面を薄い横顔として表示。

各行の6コマ：

1. 静かな浮遊待機
2. 少し上昇し、布と霊体の尾が揺れる
3. 身体を縮め、移動方向へ傾く
4. 布、両手、霊体の尾を後ろへ流して滑る
5. 少し行き過ぎて布が戻る
6. 通常の浮遊姿勢へ戻る

## 1. 正式な敵種別を追加

`EnemyKind`へ`"utsurobou"`を追加してください。

今回の移動表示を確認するための暫定戦闘値として、次を使用してください。

```ts
utsurobou: {
  name: "ウツロボウ",
  hp: 70,
  armor: 0,
  archetype: "basicMelee",
  radius: 13,
  damage: 16,
  attackCooldown: 2.2,
  exp: 18,
}
```

この値は正式な遠距離攻撃と半透明フェーズを作るまでの暫定値です。ただし今回の作業ではコード上に明確な設定として追加し、テストから参照できるようにしてください。

`iwaUroko`の既存設定：

- HP132
- 装甲42
- `heavyCharge`
- 半径16
- ダメージ30
- クールダウン2.7秒
- 経験値28

は削除・変更しないでください。

## 2. 現在のアリーナへ配置

`createArenaEnemies()`の3体目を次のように変更してください。

- ID：3を維持
- 位置：現在の`505, 178`を維持
- 種別：`iwaUroko`から`utsurobou`へ変更

モスプルン2体のID、位置、数は変更しないでください。

これにより現在の試作アリーナは次の3体になります。

- モスプルン
- モスプルン
- ウツロボウ

イワウロコはデータと簡易描画を残しますが、現在の3体構成には出現させません。

## 3. 既存の敵スプライト基盤を再利用

モスプルン導入時に作成した`enemySpriteConfig.ts`と`EnemySpriteRenderer.ts`をそのまま再利用してください。

ウツロボウ画像とJSONを読み込み、`ENEMY_SPRITE_CONFIGS`へ`utsurobou`を登録します。

```ts
utsurobou: UTSUROBOU_SPRITE
```

敵スプライトの型やローダーをウツロボウ専用に複製しないでください。モスプルンと同じ次の機能を使用します。

- 画像サイズ検証
- 方向選択
- 待機・移動クリップ
- 個体IDによる開始位相ずらし
- nearest-neighbor描画
- 被弾フラッシュ
- 読み込み失敗時の簡易描画フォールバック

## 4. 方向と仮面の扱い

既存の`resolveSpriteDirection()`で`enemy.facing`から4方向を選んでください。

画像をコードで回転・左右反転しないでください。

- 正面では石仮面を1枚表示。
- 背面では石仮面を表示しない。
- 左右ではマスクの薄い側面を表示。
- 背面行へ正面の仮面を別描画しない。
- 顔や仮面をCSS、Canvas図形、別画像で重ねない。

正面から背面へ方向が変わる際に仮面が消えるのは、頭の裏側へ回った自然な方向変化です。欠落扱いで正面仮面を追加しないでください。

## 5. 待機と移動クリップ

待機：

- 使用コマ：方向行内の0、1
- コマ時間：`[0.5, 0.5]`
- ループ

移動：

- 使用コマ：方向行内の2、3、4、5
- コマ時間：`[0.12, 0.18, 0.14, 0.18]`
- ループ

モスプルンと同じ`resolveEnemySpriteClip()`を使用してください。

- `notice`、`windup`：待機
- `approach`、`reposition`、後退中の`recover`：移動
- `idle`巡回中：直前位置との差または目標距離から移動を選択
- ノックバック中：専用被弾シート追加までは待機

ウツロボウの移動クリップには布と霊体の尾が後方へ流れる表現が含まれています。移動方向と表示方向が一致するようにしてください。

複数体を将来出す場合に備え、`enemy.id`由来の開始位相ずらしも維持してください。

## 6. 浮遊位置と影

スプライト自体に浮遊の上下動が含まれています。ゲーム側で追加の大きなサイン波上下移動を重ねないでください。

- 描画倍率：0.8から開始
- アンカー：`x: 0.5`, `y: 0.92`
- `enemy.pos`を地面上の基準点として維持
- スプライト内の霊体の尾は地面へ接触させない
- 当たり判定中心と見た目が極端にずれないようにする

ウツロボウ用の影は、モスプルンより薄く小さくしてください。

- 楕円半径の目安：10×3
- 足元基準からのY位置：10px前後
- 色の目安：`rgba(0, 5, 8, 0.26)`
- 影はワールド位置へ固定

浮遊アニメーションに合わせて影を上下させないでください。強い真円や水色の選択リングを追加しないでください。

## 7. 半透明フェーズは次段階へ分離

正式仕様では、ウツロボウの半透明状態にはメルの魔法が有効になります。

ただし今回の待機・移動導入では次を行いません。

- 常時の物理耐性追加
- メル専用ダメージ倍率
- 新しい属性型
- フェーズ時間管理
- 仮面の着脱
- 攻撃中の透明化

PNGは通常の不透明スプライトとして描画してください。雰囲気づけとして全体へごく軽い透明度を設定する場合も、0.9未満にはせず、被弾判定や状態を示す演出として扱わないでください。

専用攻撃・被弾モーション作成時に、通常状態と半透明状態の見分け方、魔法有効倍率、状態時間をまとめて実装します。

## 8. 暫定の攻撃・被弾表示

専用アクションシート追加までは、既存の敵共通処理を使ってください。

- `basicMelee`の接近・予兆・攻撃・後退を暫定利用
- 攻撃予兆時間と攻撃判定を敵AI設定から取得
- `hurtFlash`中は既存のスプライトフラッシュを使用
- ノックバック、撃破、経験値表示を維持
- 攻撃中に仮面や手を別描画しない

攻撃予兆の潰れ・膨らみを適用する場合は、モスプルンほど大きく潰さず、浮遊中心を保つ軽い収縮にしてください。

## 9. HPバーと描画順

現在の`drawEnemyBars(enemy)`を維持してください。

描画順：

1. 薄い浮遊影
2. ウツロボウ本体
3. 被弾・攻撃予兆表示
4. HPバー

HPバーがフードへ重なる場合は、Y位置だけを数px上へ調整して構いません。HPやバー幅の計算は変更しないでください。

## 10. 変更しないもの

- モスプルンの正式スプライト、AI、全数値
- イワウロコの型、設定、簡易描画
- プレイヤー3人の全スプライトと技
- パーティー陣形、交代、回復
- 敵の攻撃権制御と遭遇猶予
- BGM、効果音、HUD

## 11. テスト

既存テストを維持し、可能なら次を追加してください。

- `EnemyKind`へ`utsurobou`が追加されている。
- ウツロボウ画像とJSONが正常に読み込まれる。
- 4方向で正しい行が選ばれる。
- 背面行へ正面仮面を重ねていない。
- 待機は0、1コマをループする。
- 移動は2、3、4、5コマを順番にループする。
- 現在の3体目がID3、位置505・178のウツロボウになる。
- モスプルン2体が従来どおり出現する。
- ウツロボウの暫定HP70、ダメージ16、経験値18、半径13、クールダウン2.2秒が設定される。
- イワウロコの既存設定が残っている。
- 画像読み込み失敗時に簡易描画へフォールバックする。
- 攻撃予兆、攻撃判定、被弾、ノックバック、撃破が機能する。

最後に`npm test`と`npm run build`を実行してください。
