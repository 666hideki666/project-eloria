# Project Eloria ヴェルグラン戦・ボス部屋配置設計 v1

## 1. 目的

洞窟最深部に築かれた古代遺跡の開けた広間を、森晶獣ヴェルグラン専用の独立ボスマップとして構成する。

この文書は配置と移動範囲を決める設計資料であり、実装指示書ではない。

## 2. 基準サイズ

- ワールド基準：800 × 560
- 表示範囲：640 × 360
- カメラ：プレイヤー追従＋ワールド端で固定
- 通常階より小さく、上下左右へ少しだけ画面が動く規模
- 迷路要素は入れず、戦闘中に地形全体を把握しやすくする

座標は左上を `(0, 0)` とする暫定値。実際の画像切り出しとキャラクター当たり判定に合わせ、数十px以内の調整を許容する。

## 3. 全体配置

### 南：入口と撤退路

- 通路中心：`x = 400`
- 通路幅目安：`x = 330〜470`
- 入場位置：`(400, 525)`
- 前室へ戻る退場境界：`y >= 548` かつ `x = 340〜460`
- 入口はボス戦中も閉じない
- 根、岩、透明壁、演出用オブジェクトで塞がない
- 3人陣形への展開は通路内で行わず、広くなった到着前庭で行う

### 中央：戦闘円環

- 円環中心：およそ `(400, 295)`
- 主戦闘範囲：半径約190px
- 外周を含む歩行可能な円：半径約255px
- 中央半径190px内には常設の衝突物を置かない
- 円環紋様と細い発光線は床模様として扱い、衝突判定を持たせない
- 根走り、踏砕、晶片飛ばしの回避先が常に2方向以上残る広さを確保する

### 北：守護者祭壇

- 祭壇中心：およそ `(400, 95)`
- 祭壇幅目安：`x = 330〜470`
- ヴェルグラン休眠位置：およそ `(400, 145)`
- 戦闘開始後の基準位置：およそ `(400, 220)`
- 撃破後の森の封印石出現位置：およそ `(400, 82)`
- 祭壇は1段だけ高く見せるが、正面階段から接近可能にする
- 祭壇から中央まで直線の移動路を確保する

## 4. 歩行可能領域

歩行可能領域は次の3つを自然につないだ形にする。

1. 南入口通路：`x = 330〜470 / y = 430〜560`
2. 到着前庭：`x = 270〜530 / y = 380〜470`
3. 円形広間：中心 `(400, 295)`、半径約255px

祭壇前の階段と壇上も歩行可能にする。ただし祭壇背面、洞窟壁、外周の太い根、石柱、結晶柱の根元は歩行不可とする。

見た目が床である場所と実際に歩ける場所を一致させ、歩けそうに見える小島や外周の隙間を作らない。

## 5. 衝突物の配置

### 外周境界

- 洞窟岩、古代石壁、太い根を連続させ、隙間のない外周衝突判定を作る
- 内側の輪郭は滑らかにし、キャラクターやヴェルグランが角へ引っかかりにくくする
- 黒い洞窟背景へ移動できないようにする

### 結晶柱

- 4本を円環の斜め外側に配置する
- 目安位置：北西 `(165, 175)`、北東 `(635, 175)`、南西 `(190, 395)`、南東 `(610, 395)`
- 本体の見た目より小さめの足元判定を使い、中央へ張り出させない
- 攻撃予兆やキャラクターを隠さない高さ・配置にする

### 崩れた柱・瓦礫・根

- 外周15〜20%だけに置く
- 中央円環と入口正面には置かない
- 小さな装飾石は衝突なし、大きな柱や太い根だけ衝突ありとする
- ヴェルグランが自動移動で袋小路へ入る配置を作らない

## 6. 戦闘開始位置

1. プレイヤー1人が南入口の `(400, 525)` 付近から入場する
2. `y = 440` 付近を越えると初回演出を開始する
3. 操作キャラクターを到着前庭の `(400, 420)` 付近で止める
4. 仲間2人を左右後方へ安全に展開する
5. カメラを北祭壇へ動かし、ヴェルグランを起こす
6. ヴェルグランを祭壇から中央寄りの基準位置へ移動させる
7. カメラを操作キャラクターへ戻し、ボス戦を開始する

陣形展開先は必ず歩行可能判定を検証し、壁・柱・根の内部へ配置しない。

## 7. 撤退

- ボス戦中でも南入口まで戻れる
- 退場境界へ到達すると前室へ戻す
- 撤退時にヴェルグラン、装甲、コア、根、晶片、攻撃状態を初期化する
- パーティーのHP・MPは維持する
- 再入場時は短縮演出で再戦する
- 戦闘開始時に入口封鎖オブジェクトを生成しない

## 8. 撃破後

- ヴェルグランは消滅せず、中央北寄りで穏やかに伏せる
- 北祭壇へ森の封印石を出現させる
- 祭壇への移動路と階段を塞がない
- 封印石へ触れると第1ダンジョンクリア演出へ進む

## 9. ビジュアル基準

- 中央床：低コントラストで攻撃予兆を読みやすくする
- 円環：古代石材と細い青緑の発光線
- 外周：暗い洞窟岩、崩れた遺跡壁、太い古木の根
- 結晶：青緑色。光量はヴェルグランの胸部コアより弱くする
- 入口：常に開いていることが視覚で分かる
- 北祭壇：ボスと封印石へ視線を導くが、高い壁にはしない

## 10. 配置設計の完了条件

- 南入口から中央、北祭壇まで自然に移動できる
- ボス戦中も南へ撤退できる
- 中央戦闘範囲に常設障害物がない
- 外周が明確で、歩ける床と歩けない背景が一致する
- キャラクター3人の陣形が壁へ展開されない
- ヴェルグランが柱や壁へ引っかかりにくい
- 撃破後に封印石まで歩ける
- 表示範囲640×360に対して、部屋全体を把握しやすい
