# Codex向け追加指示：メル待機・歩行スプライトの試験導入

Project Eloriaの現在の試作版へ、メルの4方向待機・歩行スプライトを導入してください。

カイルとナディへ導入済みの共通スプライト読み込み、方向決定、時間ベースアニメーション、描画倍率、足元アンカー、接地影の仕組みを再利用してください。メルだけ別方式で実装しないでください。

## 使用ファイル

- スプライト：`assets/sprites/characters/mel/mel-idle-walk-48px-v1.png`
- メタデータ：`assets/sprites/characters/mel/mel-idle-walk-48px-v1.json`

仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行の最初の2コマ：待機
- 各行の後半4コマ：歩行
- 待機：約2fps
- 歩行：約8fps
- 基準点：足元中央

原寸参照版、クロマキー版、カイルとナディの既存ファイルを編集・削除しないでください。

## 表示

- メルの現在の簡易フィールド表示だけを新しい正式スプライトへ置き換える。
- カイル、ナディと同じnearest-neighbor描画を使用する。
- 2人と並んだときに自然な身長差になる描画倍率から開始する。
- 杖まで含めて48×48セルへ収める。
- 杖は各フレーム内に描かれているため、別の武器画像を重ねて二重描画しない。
- 通常時の水色足元リングを復活させない。
- 必要な接地影はカイル、ナディと同じ、小さく暗いゲーム側の影を使用する。
- 操作中の判別は頭上マーカーと左HUDの強調を使用する。

## 方向とアニメーション

- 方向、斜め入力、最後に向いていた方向の保持はカイル、ナディと同じ規則にする。
- 操作キャラクター時と後方AI時の両方で歩行アニメーションを行う。
- 後方AIでは現在の広めの陣形距離を維持し、陣形位置へ到着したら待機へ戻る。
- ポーズ、タブ非表示、ゲームオーバーでアニメーション時間が飛ばないようにする。
- キャラクター交代後も新しい操作状態と移動方向へ正しく切り替える。
- 左右画像をコード側で反転しない。

## 攻撃・回復中

今回の画像には攻撃・魔法モーションがありません。

- 燐光弾、癒しの環、天晶崩落、瞬光障壁の既存ロジック、当たり判定、エフェクト、効果音を維持する。
- 攻撃・詠唱中は現在方向の待機フレームで固定してよい。
- 杖はスプライト内に含まれているため、既存処理で杖を追加描画しない。
- 攻撃・詠唱中にスプライト全体を回転、傾斜、伸縮させない。
- 後続の攻撃・詠唱専用シートへ差し替えられる状態名と構造を保つ。
- 後方AI時のHP低下検知と自動回復を維持し、回復量は半減させない。
- 自動回復時も既存の回復エフェクトと効果音を正常に再生する。

## 戦闘不能

- 正式な片膝フレームができるまでは、既存の簡易戦闘不能表示または待機フレームの暗色表示を使用する。
- 戦闘不能、自動交代、ターゲット除外、戦闘後復帰を壊さない。

## HUD

- 今回は左ステータス欄の顔アイコンを変更しない。
- HUD用アイコンは3人のフィールドスプライト確認後にまとめて作成する。
- メルのHP、MP、操作中枠、後方状態などの表示ロジックは維持する。

## 完了条件

- メルが新しい正式スプライトで表示される。
- 上下左右の待機・歩行が正しい。
- カイル、ナディと並んだとき、身長とピクセル密度が自然に揃う。
