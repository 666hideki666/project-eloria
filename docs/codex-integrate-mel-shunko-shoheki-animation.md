# Codex向け追加指示：メル交代技「瞬光障壁」モーションを導入

Project Eloriaへ、メルの交代技「瞬光障壁」の4方向アニメーションを導入してください。

通常攻撃・特殊技・大技とカイル、ナディの交代攻撃で追加済みの共通アクションスプライト読み込み、方向固定、非ループ再生、終了後の待機・歩行復帰処理を再利用してください。メルの交代技だけ別方式のアニメーション管理にしないでください。

今回は表示モーションだけを追加します。交代順、交代地点、陣形再構築、障壁時間、ダメージ軽減率、無敵時間、交代クールダウン、効果音、半透明の晶石障壁エフェクトは変更しないでください。

## 使用素材

- 画像：`assets/sprites/characters/mel/attacks/mel-switch-shunko-shoheki-48px-v1.png`
- 設定：`assets/sprites/characters/mel/attacks/mel-switch-shunko-shoheki-48px-v1.json`

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- ループなし
- 再生時間：0.35秒

方向行：

- 0行目：下向き
- 1行目：上向き
- 2行目：左向き
- 3行目：右向き

各行は左から次の6コマです。

1. 低い警戒姿勢で交代
2. 両手で杖を握り、地面へ運ぶ
3. 杖の下端を強く地面へ突き立てる
4. 杖を支柱にし、空いた腕を前へ出して障壁を展開
5. 障壁の反動へ耐えながら姿勢を安定させる
6. 落ち着いた杖の構えへ戻る

杖は全コマの画像へ1本ずつ含まれています。別描画の杖を重ねないでください。半透明の晶石障壁、発動光、粒子などは画像へ含まれていないため、既存のゲーム側エフェクトを維持してください。

## 1. アクションスプライト登録

既存の`characterSpriteConfig.ts`へ、他の技と同じ構造で画像とJSONを読み込み、`MERU_SPRITE.actions.switch`として登録してください。

実行時のキャラクターIDは既存どおり`meru`です。素材フォルダ名とJSON上の制作名は`mel`ですが、新しいキャラクターIDを追加しないでください。

設定値：

- フレームサイズ：48×48px
- 列数：6
- 方向別行：down 0 / up 1 / left 2 / right 3
- 足元アンカー：`x: 0.5`, `y: 0.92`
- ループ：なし
- 総再生時間：0.35秒
- コマ時間：`[0.045, 0.05, 0.06, 0.075, 0.065, 0.055]`
- 視覚的な障壁展開：3番コマ

画像補間は無効にし、既存キャラクターと同じnearest-neighbor描画を使用してください。

## 2. メルへの交代時だけ再生

現在の`switchCharacter()`で次の操作キャラクターがメルになり、`performSwitchAttack(incoming)`が呼ばれた場合、この瞬光障壁シートを再生してください。

既存の

```ts
this.beginCharacterAction(member, "switch", 0.35);
```

をそのまま共通アクション開始として利用してください。

- 交代成立時のメルの`actionFacing`から方向行を選ぶ。
- 0.35秒の間、選択した同じ行を使用する。
- キャラクター画像をコードで回転・左右反転しない。
- 6コマを1回再生し、終了後は待機・歩行へ戻す。
- 同じ技を再発動したときは0番コマから再スタートする。
- カイルやナディへ交代した場合、メルのシートを再生しない。

## 3. 交代位置と陣形を維持

スプライト内には杖を突き立てる足運びが含まれていますが、ワールド座標上の移動ではありません。

- メルを現在の後方位置から別地点へ瞬間移動させない。
- メルへ追加速度やダッシュ距離を与えない。
- 交代直前の`incoming.pos`を維持する。
- 交代後の`followerState`、`followerTargetId`を変更しない。
- 送り出したキャラクターの`return`状態を変更しない。
- `formationRebuildTimer`と既存の陣形再構築を維持する。
- 杖を地面へ突く動きを、地形や当たり判定との新しい接触処理にしない。

## 4. 既存の障壁性能を維持

現在の瞬光障壁仕様をそのまま維持してください。

- 障壁時間：2.2秒
- 障壁中の被ダメージ倍率：0.3
- 交代直後の無敵時間：0.32秒
- 交代クールダウン：現在の`COMBAT.switchCooldown`、0.48秒
- バナー：`交代｜瞬光障壁`
- 既存の交代音とメルの交代技音を使用

障壁と無敵は交代成立時に即座に有効になります。3番コマまで発動を遅らせたり、3番コマで障壁時間を再設定して2.2秒を延長したりしないでください。

JSONの`visualDeployFrame`は見た目上の展開コマであり、追加の障壁発動イベントではありません。

後方被ダメージ補正が適用される状況では、既存どおり後方補正と障壁倍率を組み合わせてください。今回の作業でダメージ計算順序や最低ダメージ1の処理を変更しないでください。

## 5. 既存の障壁エフェクトを維持

現在の`barrier`エフェクトを維持してください。

- 位置：メルの現在位置
- 寿命：2.2秒
- サイズ：19
- 色：`#7ce7d0`

スプライトには障壁本体が含まれていません。既存の半透明な晶石障壁を、杖を支えて踏ん張るメルへ重ねてください。

- 障壁をスプライトへ焼き込まない。
- 既存の障壁を二重生成しない。
- 癒しの環の回復円や天晶崩落の晶石を誤って追加しない。
- 障壁の描画レイヤーとメルの前後関係は現在の実装を維持する。

## 6. 状態の優先順位

描画アクションの優先順位は既存の共通ルールを使用してください。

1. 戦闘不能
2. 交代技を含む行動中
3. 移動
4. 待機

少なくとも次を保証してください。

- 瞬光障壁中に燐光弾、癒しの環、天晶崩落のシートを再生しない。
- 通常攻撃、特殊技、大技で瞬光障壁シートを誤再生しない。
- 戦闘不能時は交代技より戦闘不能表示を優先する。
- 交代直後の陣形移動で、モーションが即座に歩行へ上書きされない。
- 0.35秒後に行動状態が正常に解除される。
- モーション終了後も障壁効果だけは残り時間まで継続する。

## 7. 変更しないもの

- カイルとナディの全スプライト
- メルの待機・歩行、燐光弾、癒しの環、天晶崩落
- 交代順と交代可能条件
- 瞬光障壁の時間・軽減率・無敵時間・エフェクト
- パーティー陣形と追従AI
- 敵AI、当たり判定、ダメージ計算
- HUD、回復、経験値、BGM、効果音
