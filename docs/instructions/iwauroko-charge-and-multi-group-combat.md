# イワウロコ突進AI・近接複数グループ同時戦闘 改修指示書

## 目的

第3層を中心に発生している以下の不自然な挙動を根本修正する。

1. イワウロコのオレンジ色の扇形攻撃予告を廃止する。
2. イワウロコが壁へ向かって突進を繰り返したり、壁・移動不能領域へ入り込んだりする問題を直す。
3. イワウロコの強い一撃は維持しつつ、攻撃間隔を短くして戦闘の緊張感を上げる。
4. 近距離に複数の敵グループがいる場合、全グループを同時に戦闘へ参加させる。
5. 戦闘中に見えている別グループが無敵・停止状態になる仕様を廃止する。

## 1. イワウロコの攻撃演出

- `heavyCharge` 用のオレンジ色の扇形テレグラフを描画しない。
- 他の敵が使用する円形予告には影響させない。
- 突進前の内部状態は残してよいが、長い待機は廃止する。
- 読み合いを完全に消さないため、突進直前に短い身構えモーションと足元の砂埃だけを約0.15〜0.22秒表示する。
- 扇形・進行方向の床マーカー・オレンジ色の範囲表示は出さない。

## 2. 突進可能位置への自律移動

イワウロコは攻撃権を得ても、現在地から対象へ安全な直線突進ができない場合は突進を開始しない。

### 突進前判定

- 現在地から対象方向へ、イワウロコ本体の半径を含む太さでスイープ判定を行う。
- 突進開始地点から最低限必要な突進距離まで、床・壁・固形オブジェクトとの衝突がないことを確認する。
- 壁が近い、通路が細い、対象との間に角がある場合は攻撃状態へ入らず `reposition` を継続する。

### 再配置

- 対象を中心に複数の候補点を探し、「現在地から候補点まで移動可能」「候補点から対象へ直線突進可能」の両方を満たす場所を選ぶ。
- 候補点は現在の連結された歩行可能領域内に限定する。
- 単純な座標クランプではなく、既存の第3層歩行可能判定と同じ判定を使う。
- 適切な候補が見つからないフレームでは突進を連打せず、通常移動で位置を変えて再探索する。

### 壁衝突後

- 突進が壁へ当たったら即座に突進終了・回復状態へ入る。
- 次の再配置では、衝突した壁から離れる方向を優先する。
- 同じ位置・同じ方向への連続再試行を禁止する短い再試行待ちを設ける。

## 3. 壁抜け・移動不能化の防止

- 高速突進は終点だけの衝突判定ではなく、前フレーム位置から次位置までを分割またはスイープして判定する。
- 通常移動、ノックバック、敵同士の押し出し、突進後の後退のすべてで、同じ歩行可能判定を最後に通す。
- 各更新後、イワウロコの円形当たり判定全体が歩行可能領域内にあることを保証する。
- 万一不正位置を検出した場合は、直前の正常位置、または同じ連結領域内の最近傍安全位置へ戻す。
- 敵同士の分離処理によって壁内へ押し込まれないこともテストする。

## 4. 攻撃テンポ

- 1撃30ダメージは現状維持する。
- 攻撃クールダウンを現状の2.7秒から、まず1.8〜2.0秒程度へ短縮する。
- 回復時間も現状の1.3秒から約0.8〜0.95秒へ短縮する。
- 突進前の見える待機時間は約0.15〜0.22秒とする。
- 複数体のイワウロコが同時突進し続けないよう、共有EnemyDirectorの攻撃権制御は維持する。

## 5. 近接複数グループの同時参加

現在の単一 `activeEncounterGroupId` 前提を、複数グループからなる戦闘参加集合へ拡張する。

### 開戦時

- 最初の敵グループを検知した時点で、プレイヤーの参加判定距離内にいる他の休眠グループも同時に参加させる。
- 1グループ最大3体という配置単位は維持してよい。
- 同時参加する総数を3体へ制限しない。近接する2グループなら、両グループの生存敵すべてが同じ戦闘へ入る。

### 戦闘中の追加参加

- 戦闘中にプレイヤーが別の休眠グループへ接近した場合、そのグループを即座に現在の戦闘へ追加する。
- 追加参加時にBGMを切り替え直したり、陣形を解除したりしない。
- 短い敵発見演出を入れる場合もゲーム進行や攻撃判定を止めない。

### 攻撃・被弾・AI

- 参加集合に属する全生存敵を `getCombatEnemies()` の対象にする。
- プレイヤーの通常攻撃、特殊技、大技、飛び道具、範囲攻撃は、参加集合内の全敵へ通常どおり命中する。
- 参加した全敵が移動・索敵・攻撃できる。
- 見えている別グループだけ無敵・静止する状態を作らない。
- 同時参加数が増えても、一度に攻撃する敵数はEnemyDirectorで調整して団子状態を防ぐ。

### 戦闘終了・逃走

- 参加中の各グループは、所属する敵を全滅させた時点で個別に撃破済みとして記録する。
- 参加集合内に生存敵が残っている間は戦闘BGMと3人陣形を維持する。
- 全参加グループを倒した時だけ通常BGM・1人表示へ戻る。
- 逃走判定は、参加集合内のすべての生存敵から十分離れた場合に成立する。
- 逃走時は参加していた未撃破グループをそれぞれ安全な初期位置へ戻す。

## 6. HUD

- `ENEMY x/y` は現在の戦闘へ参加している全グループの合計数を表示する。
- 戦闘途中で別グループが追加されたら分母・分子を即座に更新する。

## 7. テスト

最低限、以下を自動テストとブラウザ実機確認に追加する。

### イワウロコ

- heavyCharge時にオレンジ色の扇形テレグラフが描画されない。
- 正面に壁がある場合、その方向へ突進せず安全な位置へ移動する。
- 曲がり角付近から壁へ向かう突進を何度も繰り返さない。
- 高速突進・ノックバック・敵分離後も歩行不能タイルへ入らない。
- 15秒以内に複数回の攻撃機会があり、30ダメージは維持される。

### 複数グループ

- 2グループが近い状態で片方を検知すると、両方が同じ戦闘参加集合へ入る。
- 両グループの敵へプレイヤー攻撃が命中する。
- 両グループの敵がAI行動・攻撃を行う。
- 片方を全滅させても、もう片方が生存中ならBGMと陣形を維持する。
- 戦闘中に別グループへ近づくと即時追加される。
- 全参加敵撃破後のみ戦闘終了する。
- HUDの敵数が参加集合の合計と一致する。

### 回帰

- 1グループだけの戦闘は従来どおり開始・終了・逃走できる。
- 第1層・第2層・第3層すべてで同じ複数参加ルールが機能する。
- BGMが通常曲へ一瞬戻って再び戦闘曲になるちらつきがない。
- TypeScript型検査、既存テスト、ビルドをすべて通す。

## 完了条件

- イワウロコは壁へ突進を連打せず、自ら安全な射線を作ってから素早く突進する。
- イワウロコが壁・暗部・移動不能ブロックへ入り込まない。
- 近距離の複数グループが同時に戦闘参加し、全員に攻撃が当たり、全員が行動する。
- 参加敵が残る間は戦闘状態・戦闘BGM・3人陣形が途切れない。
