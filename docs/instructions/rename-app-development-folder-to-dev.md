# 「アプリ開発」フォルダを「dev」へ移行する指示書

## 目的

`/Users/katouhideki/アプリ開発` を `/Users/katouhideki/dev` に変更する。

対象は Project Eloria だけではなく、次の内容を含む親フォルダ全体。

- codex
- gemini
- personal-ai-assistant
- skil
- シフト表

## 安全な実施手順

1. Project Eloria を含む、このフォルダ配下で動作中の開発サーバーやビルド処理を停止する。
2. `/Users/katouhideki/dev` が存在しないことを再確認する。
3. Finder上のコピーではなく、同一ディスク内の移動として親フォルダを `dev` へ変更する。
4. 既存のCodexタスクが旧作業パスを参照しているため、当面は旧パスから新パスへの互換シンボリックリンクを作る。
5. Project Eloria の起動・停止ファイルを新パスから実行し、ブラウザ起動とゲーム動作を確認する。
6. 新規Codexタスクは `/Users/katouhideki/dev/...` を作業場所にする。
7. 既存タスクを使わなくなり、他プロジェクトの旧パス依存も解消できた段階で、互換シンボリックリンクを削除する。

## 注意事項

- `.venv`、ビルド成果物、過去の指示書には旧絶対パスが多数含まれている。
- 今回は生成済みビルド成果物を一括置換しない。必要なプロジェクトだけ、次回利用時に再生成または設定更新する。
- 互換リンクをすぐ削除すると、現在のCodexタスクが作業フォルダを見失う可能性がある。
- 移行中に失敗した場合は、`dev` を旧名へ戻して復旧する。

## 完了条件

- 実体が `/Users/katouhideki/dev` にある。
- Project Eloria が新パスから起動できる。
- 現在のCodexタスクも互換リンク経由で継続できる。
- データの欠落がない。
