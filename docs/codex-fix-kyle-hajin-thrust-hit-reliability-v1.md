# Codex向け修正指示：カイル特殊技「破陣突き」の命中安定化 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`Medium`
- `High` / `Sol` / `Ultra`：不要
- 理由：原因箇所が`performSpecial()`と攻撃判定に限定され、既存戦闘バランスを保った小〜中規模修正だから。

## 1. 現在の問題

カイルの特殊技「破陣突き」が実戦でほとんど敵へ当たらない。

現状の処理：

1. カイルを正面へ34px即時移動
2. 移動後の位置から前方22pxへ攻撃中心を置く
3. 半径40px、角度`Math.PI * 0.38`の狭い扇形判定を一瞬だけ生成

この方式では、次の場合に見た目が重なっても外れやすい。

- 敵が正面から少し横へずれている
- 敵が攻撃開始後に移動する
- 壁や地形によりカイルの34px移動が短くなる
- 小型敵や飛行敵へ斜め方向から使う
- スプライトの突進表現と単発判定のタイミングが一致しない
- 突進開始地点と終了地点の間を通過した敵が判定対象にならない

## 2. 修正後の狙い

- 敵へ正面付近から使えば安定して当たる
- 少し横へずれた敵にも命中する
- 突進の軌道上にいる敵へ当たる
- 壁で移動距離が短くなっても、カイルの目の前の敵へ当たる
- 見た目とダメージ発生を一致させる
- 1回の技で同じ敵へ多段ヒットしない
- 威力、クールダウン、鎧破壊量は原則維持

## 3. 軽い方向補正

プレイヤーが特殊技を押した時、現在の向きから大きく外れない範囲で最寄りの敵へ方向を補正する。

要件：

- 検索距離：カイルから約90〜110px
- 現在の向きから左右最大30〜40度以内
- 生存中かつ現在交戦可能な敵だけ対象
- 壁越し、別遭遇グループ、画面外の敵へロックしない
- 候補がなければ入力時の向きをそのまま使う
- 真横や背後へ自動旋回しない
- 補正した向きを`actionFacing`、移動、攻撃判定、エフェクトで共通利用

これは強いオートロックではなく、見た目上正面にいる敵への入力誤差を吸収する補助とする。

## 4. 突進軌道の判定

移動後の狭い扇形1個ではなく、突進開始地点から終了地点までを覆うカプセル状または複数円の判定に変更する。

推奨：

```text
開始地点 ○──────○ 終了地点
        軌道全体が攻撃範囲
```

実装方法は既存attack systemへ合わせ、次のどちらかを選ぶ。

### A. 推奨：短時間維持する移動攻撃area

- 開始地点と終了地点を持つswept/capsule判定
- 有効時間：約0.16〜0.22秒
- 横幅：半径22〜28px
- 終端は少し広く、半径30〜36px程度
- 同一敵IDのhit済み集合を持ち、1回だけダメージ

### B. 既存構造を大きく変えない方式

- 開始、中間、終了の3地点へ重なる円形areaを同一攻撃IDとして生成
- 各円の半径24〜30px
- 同じ敵へ重複ダメージを与えない共有hit setを使用

単純に3個の独立attackを出して3倍ダメージにしない。

## 5. 判定タイミングとモーション同期

現在は入力フレームで移動とarea生成が完了するため、スプライトモーションと命中がずれやすい。

修正後：

- action duration：約0.28〜0.34秒
- 予備動作：0.04〜0.07秒
- 突進・攻撃有効時間：0.08〜0.24秒付近
- 終了硬直：残り時間
- ダメージは剣を前へ突き出し、カイルが進むフレームに発生
- エフェクトも同じ方向・同じタイミング
- 入力直後に敵HPだけ先に減らない

スプライトJSONのフレームメタデータにhit frameがある場合はそれを優先する。なければ既存モーションを視覚確認して定数化する。

## 6. 地形と移動

- 最大突進距離は現在と同程度の34〜42px
- 壁、水、void、solid propを通過しない
- 実際の移動終了地点を判定終端に使う
- 壁でほぼ移動できない場合も、開始地点前方約30pxは攻撃範囲に含める
- 敵との物理押し出しでカイルが不自然に横へ飛ばない
- 技終了時に壁内部や水上へ残らない

## 7. 攻撃範囲

目標値：

- 正面到達距離：カイル中心から約70〜80px
- 横方向の許容：中心線から約24〜30px
- 終端付近はやや広め
- 背後の敵には当てない

現在の扇形角度`Math.PI * 0.38`に依存せず、突進技として読みやすい縦長範囲にする。

デバッグ表示がある場合、DEV/QA限定で軌道判定を可視化できるようにしてよい。通常プレイでは表示しない。

## 8. ダメージとバランス

維持するもの：

- `CHARACTER_TUNING.kyle.specialDamage`
- `COMBAT.specialCooldown.kyle`
- `breakArmor: 26`
- `knockback: 44`を基準
- 技名「破陣突き」
- 既存SFXとスプライト

命中しやすくなるため、初回修正では威力を上げない。複数敵が軌道上へ並んでいる場合は両方へ当たってよいが、同じ敵へは1回のみ。

## 9. エフェクト

- 既存の前方wind表現は破陣突き専用として維持可能
- 判定軌道と同じ方向へ出す
- カイルから離れた場所へ単独表示しない
- 実際の命中時には小さなimpactを敵位置へ表示
- 攻撃が外れた場合、命中impactは出さない
- 根の門演出から削除したwindとは処理経路を混同しない

## 10. 敵種別QA

最低限、次の敵へ確認する。

- モスプルン：小型地上敵
- ルミバネ：移動する飛行敵
- イワウロコ：大型／鎧持ち
- ウツロボウ：浮遊敵

確認状況：

1. 正面50〜75px
2. 正面から横へ20pxずれ
3. 斜め30度
4. 横へ40px以上ずれた対象には外れる
5. 背後には当たらない
6. 壁際
7. 敵が横移動中
8. 2体が縦に並ぶ
9. 2体が重なる

## 11. 自動テスト

既存の「moves Hajin Thrust once and preserves its combat tuning」等を維持・更新し、以下を追加する。

1. 正面72pxの敵へ命中
2. 正面から横20〜25pxずれた敵へ命中
3. 斜め30度以内の敵へ方向補正して命中
4. 45度以上外れた敵へ過剰追尾しない
5. 背後の敵へ命中しない
6. 突進開始地点と終了地点の中間にいる敵へ命中
7. 壁で移動が短縮されても目前の敵へ命中
8. 壁を越えた敵へ命中しない
9. 同じ敵へ1回だけダメージ
10. 重なる2体へそれぞれ1回命中
11. 特殊技ダメージ値を維持
12. 鎧を正確に26破壊
13. ノックバックを維持
14. クールダウンを維持
15. action facing、移動方向、判定方向が一致
16. 通常攻撃、大技、ナディ、メルの技を壊さない
17. 第1層、第2層、アリーナの戦闘テストが成功

## 12. 視覚・操作QA

1. 剣先または突進軌道へ敵が重なった時に命中する
2. モーションより前にダメージが出ない
3. 敵を明らかに外した時には当たらない
4. 軽い方向補正が勝手な旋回に見えない
5. 壁際でカイルが壁を抜けない
6. ルミバネの横移動中にも実用的に当たる
7. 同じ敵へ多段ダメージ表示が出ない
8. 通常攻撃より強く、必殺技ほど広すぎない特殊技として感じられる

## 13. 実装順序

1. 現在の特殊技スプライトと判定タイミングをQAで可視確認
2. 軽い敵方向補正を追加
3. 実移動開始・終了地点を取得
4. swept/capsuleまたは共有hit set付き複数円判定を追加
5. モーションのhit frameへ判定を同期
6. 命中エフェクトを敵位置へ同期
7. 自動テスト更新
8. `npm run typecheck`
9. `npm test`
10. `npm run build`
11. モスプルン、ルミバネ、イワウロコ、ウツロボウで実操作QA

## 14. スコープ外

- カイルの威力全般の再調整
- 特殊技スプライトの描き直し
- ナディ、メルの技変更
- コンボシステム追加
- 全攻撃判定システムの全面再構築

今回は「見た目では当たっているのに外れる」を解消し、破陣突きを信頼して使える特殊技にする。
