# Codex向け修正指示：回復晶泉の前縁デプスソート修正 v2

## 実行設定

- 推奨モデル：`GPT-5.6 Luna`
- 推論レベル：`High`
- 局所的な描画順修正であり、マップ再設計は不要。

## 1. 残っている不具合

前回の前景領域縮小後も、回復晶泉の手前縁にある水色の横線と暗い段差が、操作キャラクターの胴体を横切って描画される。

添付画像では、カイルが祭壇より手前側に立っているにもかかわらず、細い前縁overlayが常に最前面へ描画され、腰から腹部を隠している。

## 2. 修正方針

固定順の `背景 → キャラクター → 前縁overlay` を廃止し、キャラクターの接地Yと祭壇前縁の基準Yで前後関係を切り替える。

- キャラクターの接地Yが祭壇前縁より手前（画面下側）の場合：
  - 前縁をキャラクターより後ろへ描画する
  - 水色の横線や暗い段差が胴体を横切らない
- キャラクターの接地Yが祭壇前縁より奥（画面上側）の場合：
  - 前縁をキャラクターより前へ描画してよい
  - ただし隠れるのは足元だけとし、胴体や頭を覆わない

判定にはスプライト矩形の中央ではなく、足元・接地点のワールドYを使う。

## 3. 実装上の必須事項

- 回復晶泉の前縁を常時最前面に描画しない
- 前縁のdepth基準を見た目の接地線へ合わせる
- 水色の横線を祭壇全幅の独立した最前面overlayとして扱わない
- 必要なら水色の横線を祭壇ベース側へ統合し、キャラクターより先に描画する
- 前縁overlayを残す場合も、縁の厚み部分だけに限定する
- カイル、ナディ、メルで同じ判定を使う
- 頭上の操作キャラマーカーは祭壇パーツより常に前へ描画する

## 4. 変更しないもの

- 回復晶泉の構図、位置、大きさ
- 浮遊晶石、光柱、湖面
- 回復機能、回復演出、効果音
- インタラクト表示
- 衝突判定
- 敵配置およびマップルート

## 5. 視覚QA

各キャラクターで次を確認する。

1. 祭壇の真正面で、前縁より画面下側に立つ
2. 前縁の接地線を上下に何度も横切る
3. 祭壇正面の左端・中央・右端を歩く
4. キャラ交代しながら同じ位置を通る
5. 回復演出中に前後移動する

合格条件：

- 手前にいるキャラクターの胴体を横線が貫通しない
- 接地線を越えた瞬間だけ自然に前後関係が切り替わる
- 切り替え時に縁が点滅・二重描画・消失しない
- 奥側に入った際も、必要以上に全身が隠れない
- 操作キャラマーカーが隠れない

## 6. 検証

- `npm run typecheck`
- `npm test`
- `npm run build`
- 第2層の通常プレイで3キャラクターを視覚確認

今回の修正は前縁のデプスソートだけに限定し、別のマップ要素には触れない。
