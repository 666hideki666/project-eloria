# 古の森へ向かう理由：物語案 v1

状態：**物語の核は2026-10-18にユーザー承認済み**（「それでいこう！！」）。３場面・７行の旧版を経て、2026-10-19にユーザーが承認した６場面・１３行版を実装・技術検証済み（`docs/storyboard-eloria-prologue-v2.md`）。ユーザーのプレイ評価は未確認。村の名前、３人の出会った時期、章末の詳細は未決定。

## 核となる案：「森の記憶が乱れている」

村に近い古の森で、泉の水や根に青い晶光が走り、穏やかだった魔物が人を襲い始める。森の奥の洞窟が異変の中心らしい。古い地図にはそこに「森の封印石」へ通じる遺構があると記されているが、封印石が異変の原因か、止める鍵かは分からない。

- カイル：封印石を探していたトレジャーハンター。最初は未知の遺物への興味と仕事として森へ入るが、仲間と村を守る責任に向き合う。
- ナディ：森の異変が村へ広がるのを止めたい。地元出身かどうか等の細部は未定のまま、村人を守る動機だけを置く。
- メル：晶石から通常の魔力ではない「助けを求める記憶」のような反応を感じる。遺構に入る理由は研究だけでなく、その声の主を知りたいから。

３人は同じ場所へ向かうが、目的は完全には一致していない。その小さな食い違いを旅の会話で見せる。

## 導入から第１章終了まで

1. オープニング：村の井戸や根に青い晶光が走る。カイルの地図、ナディが守ろうとする村、メルの感じる晶石の声を短い場面でつなぎ、３人が森へ向かう。START後のイラスト・会話・タイプライター表示は、村の危機、手がかり、別れを加えた６場面版を実装済み（`docs/storyboard-eloria-prologue-v2.md`）。旧３場面版は v1 を参照。
2. 操作開始は確定済みの「古の森」。村へ戻る道は見えるが、異変の源を残して引き返せない。案内の仮文言：「このまま戻っても異変は止まらない。洞窟の光を確かめよう。」道を物理的に消さず、既存の物語上の制限と整合させる。
3. 洞窟へ近づくにつれ晶光と根の異常が強くなる。入口の古い結晶／遺構は単なる宝箱ではなく、かつて森を守った記憶へ通じるもの。洞窟から既存の第１層「苔根の遺構」へ接続する。結晶に触れる演出は将来の導入演出案であり、現在のマップ遷移が実装済みと誤記しない。
4. 第１〜３層の仕掛けを解くことで、記憶空間「晶界」が壊れているのではなく、守護の力が乱れていることを少しずつ示す。各層の既存ギミックと敵は変更しない。
5. ヴェルグランは異変で苦しみ、侵入者から森を守ろうと暴れている。３人は討伐ではなく鎮静する。戦いの後、守護者は封印石を自ら託す。既存の「倒さず生存」「祭壇で封印石を受け取る」結末と一致させる。
6. 森へ戻ると晶光が穏やかになり、村へ続く道を進む。第１章の解決と同時に、異変の発端が森の外にもあるかもしれない余韻を残す。ただし黒幕や次章の具体設定はここで固定しない。
