## ねらいと流れ

`タイトル画面 → START → イラスト付き序章 → 暗転 → 既存の「序章／古の森」入場表示 → 操作開始`。

「動画が流れる感じ」は静止画３枚にゆっくりしたパン／ズーム、光・霧・葉の小さな動き、場面転換、タイプライター式のテキストを重ねて作る案。映像ファイルに焼き込むより、横スマホ・iPad の画面比率、字幕速度、タップ操作、スキップに対応しやすい。絵そのものには文字・UIを焼き込まない。洞窟到着や第１層の核心はまだ見せず、プレイヤーが古の森を歩く目的を残す。

## 画面・音の留意点

- 横長16:9の原画を基準に、横スマホ／iPadでは中央の主題と３人の顔を切らない配置。下部字幕の安全領域、ノッチ、文字サイズを確認する。
- タイプ表示は読みやすい速度とし、アニメーション軽減設定ではパン／ズームや文字の逐次表示を抑え、全文を即表示できるようにする。字幕だけで筋が理解できること。
- START がユーザー操作なのでそこからの音声再生制約に従う。導入曲は未決定。既存の古の森BGMを薄く使うか、別の短い導入曲にするかはユーザーと決める。遷移・スキップ・画面非表示時に二重再生や鳴り残りを起こさない。
- 人物の基準は採用タイトル背景 `assets/concepts/title/project-eloria-title-key-art-v2.png`。カイル＝灰髪・赤服・青いマフラー、ナディ＝茶髪ポニーテール・緑服・紫の襟巻き・円月輪、メル＝青黒い短髪・青い術衣・橙の襟巻き・三日月杖。今回の試作は採用決定前に実際のキャラシートとの一致を再確認する。
