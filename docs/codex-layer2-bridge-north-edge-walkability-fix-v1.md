# 第2層・橋の北側へ水上歩行できる問題：実装指示 v1

## 承認と対象

ユーザーは2026-09-28のスクリーンショットで、橋の絵は良いが橋の上（画面奥・北側）の水面まで歩けると指摘し、本指示方針の提示後に「実装に移って！」と明示承認した。**橋の絵は維持し、出現後の橋部分の歩行判定だけ、見える石畳の踏面に合わせて局所修正する。** 第2層の他の赤線歩行領域、クリスタル、泉、橋の画質と演出は変更しない。

## 再現資料と原因

- 再現画像：`/Users/katouhideki/Desktop/スクリーンショット 2026-09-28 19.03.18.png`。キャラクターの足元が橋の北縁より水面側に見える。
- ユーザー赤線：`docs/references/lightwing-crystal-cavern-walk-boundary-red-v1.png`。
- 動的橋マスク：`assets/environments/lightwing-crystal-cavern/lightwing-crystal-cavern-walkability-v1.rle.json` の `bridgeRows`。
- 現在の橋素材：`assets/environments/lightwing-crystal-cavern/lightwing-crystal-bridge-layer-v2.png`。描画は `src/render/stages/LightwingCrystalCavernRenderer.ts`。
- 元画像座標は両方1638×960。橋中央 x=950 では現行 `bridgeRows` が y=362〜402 を許可する一方、橋素材の可視画素はおおむね y=373 から始まる。x=1000 でもマスク上端 y=362 に対し素材上端はおおむね y=371。したがって、少なくとも北縁の約9〜11画像pxに、見える橋より先行した許可帯がある。これは現行赤線を発動前背景に合わせた後、橋素材を作り直したことによる**絵と動的マスクの不一致**。キャラ全身が床内に収まる必要はなく、比較するのは足元接地点 `pos` のみ。

## 実装方針

1. 元背景と現在の透過橋素材をネイティブ座標で重ね、石畳の**歩ける上面**の北縁・南縁を x=800〜1170 で確認する。青い晶石、橋の側面、水面反射、透過素材の外縁は床とみなさない。画素のアルファ値だけで歩行範囲を自動決定しない。
2. 第2層の橋の動的マスクに限り、北側の余分な許可帯を削る。元赤線から生成した `staticRows` は完全に保持し、橋の南縁と両岸の接続も不要に狭めない。**歩行域の追加・全体膨張・描画素材の移動はしない。** この局所修正を元赤線 v1 からの承認済み差分として、座標と削除画素数を再現可能な生成手順・資料に残す。元の赤線ファイルは上書きせず、新版や局所補正データを作る。
3. 橋の見た目は現行 `lightwing-crystal-bridge-layer-v2.png` のまま。解除前・片側解除・出現演出中の橋は従来どおり通れず、表示完成と歩行解禁を同期する。足元一点判定、移動線分検査、戦闘用半径との分離は維持する。
4. マスクと橋の石畳を重ねた原寸レビュー図を保存する。左岸・中央・右岸で、北縁の足元が水面へ出ないことと、石畳上を途切れず横断できることを確認する。端部や橋の曲線が曖昧なら、推測で広げずユーザーへ問題座標を示す。

## 必須テスト

- x=950,y=365 と x=1000,y=365（元画像座標、橋完成後）は歩行不可。x=950,y=380 は歩行可。これらは回帰用の代表点であり、最終境界は石畳上面との原寸照合で決める。
- `staticRows` は修正前後で一致。橋マスク差分は x=800〜1170 内の**削除のみ**で、湖の別地点や他階層へ波及しない。
- プレイヤー、仲間、敵、ノックバック等の実移動で北縁を越えられず、両岸の狭い接続部を普通に歩いて対岸・出口へ到達できる。高速・斜め移動で境界を飛び越えない。
- ゲーム画面で、キャラの足元だけを基準に北縁沿いを歩かせ、石畳から水面に出ないことを確認する。スクリーンショットだけでなく実操作を合格条件にする。
- ビルドと関連テストを実行し、結果を報告する。検証用にブラウザやサーバーを開いた場合は作業後に閉じ、音楽を鳴らし続けない。
