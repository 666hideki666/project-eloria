# 指示書案：ヴェルグラン会話後の帰還選択と戦闘不能の専用絵 v1

状態：**2026-10-27、ユーザー承認済みの帰還二択と戦闘不能３人の専用絵を実装・技術検証済み。採用素材はカイルv2・ナディv1・メルv1。** 推奨実装モデル：**Sol High**。原版の見た目承認と、ゲーム内の最終見た目評価は区別する。

## 現状と意図

- 同一プレイ中、解除済みの第１層の根の門、第２層の二つの晶石と橋／奥への道、第３層の霊灯・石楔と中央門は、部屋を出入りしても解除状態が残る。`GameWorld` の状態フラグを通常の `configureStageRoom` で初期化していない。徒歩で祭壇から古の森まで帰れる。敵の再遭遇は別仕様。新規ゲームや開発用ワープの一部リセットは別扱い。
- 平穏なヴェルグランとの会話は３ページで終了すると、今はその場の操作に戻る。徒歩で戻る選択は保持しつつ、長い復路を省ける任意の帰還を追加したい。
- 添付画面の戦闘不能キャラは完成素材ではない。`CharacterSpriteRenderer.draw` が `downed` 時に既存のキャラシート描画を通さず、`Renderer.drawDownedCharacter` がキャラ色と髪色の単純な矩形で描いている。３人の外見が判別しにくく、背景・既存スプライトとの品質差が大きい。

## １．会話後の二択

- **封印石取得後の平穏なヴェルグランとの会話を最後まで読み終えたときだけ**、次の２ボタンを表示する。会話本文は変更しない。初回の戦闘・撃破・封印石取得・章末演出には出さない。
  1. 「洞窟の入り口に戻る」
  2. 「このままここにいる」
- 既定フォーカスは「このままここにいる」とし、誤操作で飛ばないようにする。マウス／タッチとキーボードで選択できる。会話送りの入力がそのまま選択に流れないようにする。
- 「洞窟の入り口に戻る」は短い暗転で**古の森の洞窟前**の既存 `ANCIENT_FOREST.caveReturnSpawn` へ移す。村やタイトルへは直接飛ばさない。初回封印石取得時の森帰還シネマティックは再生しない。既存の到着方向、赤線内の安全な足元、カメラ同期を使用する。
- 「このままここにいる」は選択を閉じ、祭壇で自由操作へ戻す。再度話しかければ会話と二択を使える。会話をしない場合はこれまでどおり徒歩で退出できる。
- どちらでも封印石・各層の解除状態、HP／MP、操作キャラ、経験値と報酬は変えない。平穏なヴェルグランを再戦状態に戻さない。既存の手動復路を塞がない。

## ２．戦闘不能の３人専用スプライト

- カイル、ナディ、メル各１体について、既存48pxキャラクターシートの服・髪・配色・斜め上視点に一致した**透明背景の戦闘不能ポーズ**を作る。倒れていても各人が一目で判別できることを重視する。残酷な負傷表現はしない。完全な倒れ姿に難があれば、膝をついて動けないポーズを第一候補とする。
- この `work` チャットで３人の既存シートを参照して素材案を生成し、`assets/concepts/characters/downed/{kyle,nadi,mel}-downed-concept-v1.png` に保存した。ユーザーはナディv1・メルv1を了承し、カイルv1は右手で寝ているように見えると指摘。右腕を頭から離して伸ばす `assets/concepts/characters/downed/kyle-downed-concept-v2.png` を生成し、ユーザーが「いいね！それでいこう」と承認。採用は**カイルv2・ナディv1・メルv1**。画像生成の原版は大きなキャンバス上の絵。2026-10-27に矩形クロップ・NEAREST縮小で48px枠へ調整し、本実装済み。既存の歩行／攻撃シートは保持。調整手順は `docs/downed-character-sprite-preparation-2026-10-27.md`。
- 描画は足元座標、影、前後レイヤー、pixelated 拡大、復活時の通常ポーズへの切替を維持する。暗転や被ダメージ点滅と重ねても視認でき、キャラが床から浮いたり足元がずれたりしないようにする。素材読み込み失敗時だけ現行の簡易表示へフォールバックする。
- HUDの「戦闘不能」表示と回復／蘇生ルールは変更しない。３人同時・個別の戦闘不能と復活を確認する。
