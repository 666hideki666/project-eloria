# 第１層初回入場の異変演出と全層上部メッセージ画質改善：実装指示書案 v1

状態：**2026-10-21にユーザーが「実装に移って」と明示承認。同日に実装・技術検証済み。** 推奨モデルは Sol High。実機・聴感・ユーザーの演出評価は未確認。

## 目的と範囲

1. 古の森から第１層「苔根の遺構」へ初めて入る時、魔物と水晶の異変を、既存マップ上の短い演出と読める文章で示す。
2. 第１〜３層・守護者戦を含むフィールド上部の短い通知を鮮明にする。既存の中央入場タイトルやマップのピクセル描画を変更しない。
3. 世界規模の謎、メルによるボス後の水晶鎮静、帰村から旅立ちのシーンはこの実装範囲に含めない。これらは `docs/story-crystal-anomaly-chapter1-and-world-2026-10-21-v1.md` の承認済み物語方針として別途設計する。

## 既存状態と画質原因

- 古の森→第１層は `GameWorld` の通常ルーム遷移。第１層南階段から森への復路と、再入場も実装済み。第１層の中央入場タイトルはDOMで表示され、既存の５.２秒演出を維持する。
- 通常の上部通知は `src/render/HudRenderer.ts` が640×360のゲームcanvasへ10px monospaceで描画している。`src/style.css` の `#game { image-rendering: pixelated; }` で画面いっぱいに拡大されるため、日本語通知まで粗く拡大される。**マップのドット絵用設定を消すのではなく、読ませる文字をcanvas外の高解像度DOM層へ移す。**

## 第１層初回入場演出（承認済み仕様）

- 対象は通常の古の森→第１層への**初回**遷移のみ。森↔第１層の再入場、開発用層選択、QA直接開始では再生しない。章の進行状態・敵の倒された状態を壊さない。
- 中央の層タイトルと同時に文章を重ねない。入場タイトルが落ち着いた後、操作と敵の攻撃を一時停止して短く見せ、終了／スキップ時に確実に操作を戻す。長い映画にはしない。
- 既存背景・魔物の配置・根の仕掛け・歩行範囲は不変。壁や晶石に一度だけ不規則な青い脈動、既存魔物の落ち着きのなさを小さな演出として見せる。新しい通路上のクリスタルや仕掛けは置かない。魔物が誰か／ボスから逃げる、という誤解を生む演出は避ける。
- 承認済み原稿：

  > 洞窟の奥で、青い光が不規則に脈打った。魔物たちは苦しむように暴れ、三人の姿に気づくと、我を失ったように襲いかかってきた。

- 本指示書とともに承認された短い反応：ナディ「森の魔物まで、こんなふうに……。」／メル「この光、晶石が苦しんでいるみたい。」／カイル「奥を確かめよう。」ボス名や世界規模の原因はまだ明かさない。
- E/Enter/タップ等で先へ進め、スキップもできる。表示途中の連打・押しっぱなしでページを複数飛ばさない。動き軽減時は揺れや点滅を省き、文章だけで内容が伝わるようにする。初回フラグは新規開始と再入場を区別する。

## 上部メッセージの表示改善

- `WorldSnapshot.banner` と `bannerTimer` をデータ源のまま使い、canvas描画の上部通知を廃止して `.field-shell` 上のDOM表示に置き換える。毎フレームのDOM再生成・読み上げ再通知は避ける。既存の通知優先順（会話中は通知を出さない）とゲーム進行の意味は保持する。
- 日本語が読めるシステムフォント、画面解像度で16px以上、十分な行間と高コントラストの半透明背景を使う。長文は２行程度へ自然に折り返し、途中で切らない。ズーム・全画面・横スマホ・iPadでも画面外へ出さない。
- 左上のパーティーHUD、右上のポーズUI、守護者のボスゲージ、中央入場タイトルと重ならない位置・表示優先を設計する。ボス戦では既存の「ボスゲージ下に通知」という関係を維持する。短い戦闘通知が操作・視界を過度に塞がない大きさにする。
- 通知の背景・光・縁取りは世界観に合う控えめなものとし、古いPCゲーム風の大きな枠に戻さない。マップとキャラクターのピクセル絵、現行の層タイトルの見た目を維持する。
- 第１層の物語文は時間で消える短いbannerではなく、入力で送れる鮮明な物語用UIに置く。必要に応じて既存の会話描画も同じ高解像度レイヤーへ移すが、既存イベント文と入力仕様を変えないことを優先する。

## 検証条件

- 通常開始の森→第１層で一度だけ演出し、再入場・DEV・QA直接開始では再生しない。入場タイトルと文章が競合しない。演出中に敵から不意打ちされず、終了後は通常の戦闘・探索・帰路が使える。
- 第１層の根・クリスタル・北出口、森への南帰還、歩行マスクと各層の既存ギミックは不変。魔物のAIやボス戦の戦闘バランスは変更しない。
- 第１〜３層と守護者戦で、短文／長文通知の読める画質、HUDとボスゲージとの非重複、通常・全画面のPC／横スマホ／iPad相当を実画面で確認する。層タイトル、会話、通知の優先順とキーボード／タッチ操作も確認する。
- 型検査、テスト、ビルド、製品版を確認し、検証用ブラウザ／サーバーを閉じる。実機・Safari・実耳など未確認項目は未確認として記録する。

## 実装結果（2026-10-21）

- `GameWorld` に通常の森→第１層初回だけのフラグを追加。入場タイトルの既存5.2秒が終わってから、約1.5秒の不規則な青い脈動と承認済み４ページを表示する。再入場・DEV層選択・DEVのQA経路では再生しない。
- `Layer1AnomalyController` / `layer1Anomaly` がDOMの物語表示を管理。脈動と最初の地の文では、既存の右側クリスタルと近くの既存魔物へ表示用カメラだけを切り替える。青い光と魔物の小さな揺れも描画だけで、実座標・配置・AIは変えない。動き軽減時はカメラ切替・脈動・揺れ・タイプ表示を省く。
- 演出中はワールド更新を止め、プレイヤー・敵・攻撃・HP/MP・ゲーム内タイマーを固定する。既存探索BGMは継続。E/Enter/Space・タップで全文表示／ページ送り、Esc／ボタンでスキップ。キーリピート・ダブルクリック・持ち越し入力を遮断し、完了後に操作を戻す。非表示中は文字と演出も停止する。
- `FieldMessages` が第１〜３層・守護者戦の `banner` / `bannerTimer` をDOMへ表示。日本語は16px以上で、短文・長文を折り返す。会話・入場タイトル・異変演出・ポーズ・ステータス表示を優先し、HUD／ポーズ操作／ボスゲージと重ならない位置へ配置する。テキスト変更時だけDOM本文を更新する。
- ゲームcanvasは640×360と `image-rendering: pixelated` を保持。既存ランドマーク会話とarenaの通知は従来のcanvas表示を維持。新しい異変原稿は鮮明なDOMで表示する。背景・歩行マスク・衝突・仕掛け・BGMは変更していない。
