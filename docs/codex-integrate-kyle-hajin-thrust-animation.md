# Codex向け追加指示：カイル特殊技「破陣突き」モーションを導入

Project Eloriaへ、カイルの特殊技「破陣突き」の4方向アニメーションを導入してください。

通常攻撃3人分で完成している共通アクションスプライト機構を再利用し、カイルの`actions.special`へ設定として追加してください。新しい専用レンダラーや、カイルだけのフレーム選択分岐は作らないでください。

## 使用ファイル

- 特殊技シート：`assets/sprites/characters/kyle/attacks/kyle-special-hajin-thrust-48px-v1.png`
- メタデータ：`assets/sprites/characters/kyle/attacks/kyle-special-hajin-thrust-48px-v1.json`
- 通常攻撃：`assets/sprites/characters/kyle/attacks/kyle-normal-renjinken-48px-v1.png`
- 待機・歩行：`assets/sprites/characters/kyle/kyle-idle-walk-48px-v1.png`

特殊技シート仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行6コマ：低い構え、引き、突進開始、最大突き、衝撃吸収、復帰
- 非ループ
- 合計0.28秒
- 基準点：足元中央

## 設定への追加

`characterSpriteConfig.ts`で次を行ってください。

- PNGを`?url`で読み込む。
- JSONメタデータを読み込む。
- `createCharacterActionSpriteConfig("special", ...)`を使用する。
- `KYLE_SPRITE.actions.special`へ登録する。
- 既存の`actions.normal`を維持する。

`CharacterActionKind`にはすでに`special`が存在し、`GameWorld`も`beginCharacterAction(member, "special", 0.28)`を呼び出しています。既存の共通機構で再生できるよう、必要最小限の設定追加にしてください。

## アニメーション

- カイルかつ`actionKind === "special"`の間だけ破陣突きシートを使用する。
- 攻撃開始時の`actionFacing`を6コマの間固定する。
- 左右反転せず、4方向の画像をそのまま使用する。
- 6コマをJSONの時間どおり1回だけ再生する。
- 合計時間は既存の`actionDuration = 0.28`と一致させる。
- 終了後は最後の方向の待機または移動へ戻る。
- 通常攻撃直後に特殊技を使っても、連刃剣シートから正しく切り替わる。
- ポーズ、タブ非表示、ゲームオーバー中にアニメーション時間が飛ばない。
- 画像読み込み失敗時は、現在の共通フォールバック表示でゲームを継続できる。

## ワールド移動

破陣突きでは、現在の`GameWorld`がカイルを向いている方向へ34px移動させています。

- この34px前進を維持する。
- スプライト描画側で追加の座標移動を行わない。
- 画像内の踏み込み姿勢とゲーム側の前進が重なり、二重に長距離移動しないようにする。
- アリーナ端の`clampToArena()`を維持する。
- 画像の足元アンカーは描画上の接地点であり、当たり判定座標を変更しない。

現在は技入力直後に34px前進します。アニメーションと前進の同期を改善する場合も、ゲーム判定を遅らせたり複数回移動させたりせず、まず現行タイミングのまま見た目を確認してください。

## 攻撃判定とエフェクト

既存の破陣突き性能を変更しないでください。

- ダメージ：34
- 攻撃位置：移動後のカイル前方22px
- 半径：40
- 攻撃角度：`Math.PI * 0.38`
- 装甲破壊：26
- ノックバック：44
- 特殊技クールダウン：2.8秒

既存の次の表現も維持します。

- 青緑色の前方`wind`エフェクト
- 石装甲へ当てた時の石片
- 装甲破壊音
- 特殊技効果音
- ヒットストップ
- アクセシビリティ設定に従う画面振動と発光

剣は全フレームの画像内に含まれているため、別の剣を描画しないでください。突進線、風、石片は画像へ焼き込まず、現在どおりゲーム側で描画します。

## 描画

- 待機・歩行・連刃剣と同じ`drawScale`を使用する。
- 同じ足元アンカーと方向別Y補正を使用する。
- 技開始時と終了時に身体が拡大、縮小、上下移動して見えないようにする。
- 全方向で剣が1本だけ表示される。
- 剣先が48×48セル境界で欠けたり、隣フレームの剣が混ざったりしない。
- `image-rendering`相当のnearest-neighbor描画を維持する。
- 通常時の水色リングを復活させない。
- 接地影、操作中マーカー、HUD強調を維持する。

## 後方AI

- 後方AIが特殊技を自動使用しない現在仕様なら、その仕様を変更しない。
- 将来AI特殊技が追加されても、同じ`actionKind === "special"`で再生可能な共通構造を維持する。
- 陣形、後方攻撃力半減、後方被ダメージ半減を変更しない。

## 変更しないもの

- カイルの待機、歩行、連刃剣
- ナディとメルの全スプライト
- 通常攻撃エフェクト
- 裂空断、先陣斬り
- 敵AI、陣形、経験値、ドロップ
- HUD、BGM、効果音
- ゲームバランス

## テスト

既存テストを維持し、少なくとも次を追加・確認してください。

- `KYLE_SPRITE.actions`に`normal`と`special`が登録される。
- 特殊技シートが288×192として検証される。
- 6フレームの合計が0.28秒である。
- 下、上、左、右の各行から正しいフレームを選択する。
- `actionKind === "special"`で特殊技シートを使う。
- `actionKind === "normal"`では連刃剣シートを使い続ける。
- 新しい`actionSequenceId`で1コマ目から再生する。
- 特殊技中の向きが`actionFacing`へ固定される。
- 特殊技1回につきワールド移動が34pxを超えて二重発生しない。
- ダメージ、範囲、装甲破壊、ノックバック、クールダウンが変わらない。

## 完了条件

- 破陣突き入力時に専用の6コマが再生される。
- 上下左右すべて正しい向きで突く。
- 低い構えから最大突き、復帰まで自然につながる。
- 34pxの前進と画像の踏み込みが一つの動きに見える。
- 足元位置と身体サイズが他のモーションから変わって見えない。
- 剣が全コマで1本だけ表示される。
- 同じ敵へ不正な多段ダメージが入らない。
- 装甲破壊、石片、風、効果音が正常に動く。
- 連刃剣で特殊技シートが誤再生されない。
- ナディ、メル、敵、HUDへ意図しない変更がない。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。

実装後は、上下左右、アリーナ中央、壁際、連刃剣直後、空振り、通常命中、石装甲命中を確認してください。登録した設定、各方向の足元位置、34px前進との同期、剣の欠け、装甲破壊値を変更していないことを日本語で報告してください。
