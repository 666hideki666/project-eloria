# Codex向け修正指示：隠し部屋の根ゲートと湖上晶泉の構図修正 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：2層分のランドマーク描画、タイル配置、衝突、演出、敵配置を連動して修正するため。

## 1. 目的

次の2点を修正する。

1. 第1層の隠し小部屋を塞ぐ根ゲートが左右へ開き、構造的に不自然
2. 第2層の回復の晶泉が地下湖へ自然に統合されず、巨大な円盤を床へ貼り付けたように見える

## 2. 添付画像から確認できる問題

### 第1層

- 縦長の太い根2本が左右へ移動している
- 木製の観音扉に見える
- 根の生え方と開き方が一致しない
- 中央のシアン発光板だけが残り、根ゲートらしくない

### 第2層

- 大型円形泉が矩形の床へ載っている
- 湖の水面と泉の水面が別物に見える
- 泉の上半分が画面外へ切れ、全体像を確認しづらい
- 泉の周囲が戦闘広場になり、敵4体がすぐ近くへ集まる
- 右側の副晶石・湖上足場と視覚的に競合する
- 回復の聖域ではなく、巨大な機械設備に見える

## 3. 隠し小部屋の根ゲート

左右へ開く現在の演出を廃止する。

### 閉鎖状態

- 上側の壁・天井亀裂から複数の根が垂れ下がる
- 太い根2〜3本と細い根3〜5本が絡み、通路を塞ぐ
- 根の下端は床へ食い込む
- 中央へ扉の合わせ目を作らない
- シアンの板や縦長の発光扉を置かない
- 石碑の力を示す場合、根の表面に細い光脈だけを入れる

### 開放演出

推奨は「上へ縮んで消える」。

1. 石碑から根へシアンの光が走る
2. 根の表面が数か所だけ淡く発光
3. 床へ食い込んでいた細い根がほどける
4. 太い根が下から上へ短くなる
5. 上側の壁亀裂へ吸い込まれるように収縮
6. 小さな葉、木屑、土埃だけが落ちる
7. 根が完全に消え、通常の石造通路が現れる

- 左右へ平行移動させない
- 上下に2分割して開く機械扉にも見せない
- 根を消滅させる場合も、一瞬で透明化せず1.2〜2.0秒かける
- 戦闘用wind、slash、大きなringを使わない
- 既存の根開放SFXを収縮速度へ同期

### 開放後

- 中央に根や発光板を残さない
- 上側の壁亀裂へ短い根の切れ端を少し残す
- 床へ葉と土を少量残す
- 通路幅を完全に開ける
- 不可視衝突を残さない

## 4. 根ゲートの描画と衝突

- `hiddenRoomUnlocked === false`の時だけ根ゲートを描画・衝突
- animation中は見た目の根の高さに合わせて衝突を即時細分化する必要はない
- 開放演出完了まで閉鎖衝突を維持
- 完了フレームで衝突を完全解除
- 開放後に再入場しても根は戻らない
- 敵再出現でゲートを閉じない
- 空の宝箱台座と隠し小部屋は維持

## 5. 湖上晶泉のデザイン方針を変更

「大きな独立円形施設を湖へ移す」のではなく、「地下湖の一部を回復聖域に変える」。

円形石リングを完全な巨大円盤として残さない。

### 新しい構成

- 湖岸へ半円形の小さな石祭壇
- 祭壇幅：約112〜144px
- 湖面へ突き出す半円または欠けた円環
- 中央の浮遊晶石は祭壇の少し奥、湖上に浮く
- 天井光は浮遊晶石と湖面へ落ちる
- 2本の小晶石は岸側の左右へ配置
- 湖面上へ淡い古代紋様と波紋
- 水面は既存の大湖と完全に連続
- 巨大な内側プールを別に描かない

## 6. 晶泉の縮尺

現在の直径約180pxの完全円を廃止する。

目標：

- 岸側祭壇：幅112〜144px、奥行48〜72px
- 浮遊晶石：幅20〜28px、高さ40〜56px
- 天井光：幅28〜48px
- 回復紋様：湖面上に半径50〜70px
- 操作距離：約70〜90px
- solid prop：祭壇と晶石の接地範囲だけ

晶泉全体を小さくするというより、石造構造を小さくし、広がりは湖面の光と波紋で表現する。

## 7. 湖と泉の境界をなくす

- 晶泉専用の楕円形水面塗りつぶしを削除
- 背景の`water`タイルをそのまま回復水面に使う
- 作動時のみ周囲water tileの色を少し明るくする
- 波紋は湖タイルを跨いで広がる
- 円形の太い二重枠をやめ、欠けた半円石リングにする
- 床へ正円を貼った見た目を避ける
- 石祭壇の影を湖面へ自然に落とす

## 8. 配置とカメラ

- 通常接近時に晶泉の全体が画面内へ収まりやすい位置へ調整
- 画面上端へ密着させない
- 操作位置から、祭壇・晶石・天井光の上端まで見える
- 必要なら晶泉座標を湖岸から64〜128px下側へ調整
- カメラを強制的に上端へclampした状態で泉が切れないこと
- QA spawnは泉の手前中央へ置く

## 9. 晶泉周辺を非戦闘区域にする

スクリーンショットでは敵4体が泉の直前で戦っており、回復聖域の静けさがない。

- 晶泉中心から最低260〜320px以内へ敵homeを置かない
- 混成戦グループを泉の手前の別広場へ移動
- 戦闘中の敵が晶泉まで追跡しないようleashを調整
- 晶泉の画面内に敵HPバーが入らない程度の距離を確保
- 戦闘を終えてから静かな通路を通り、晶泉へ到達する構成
- 敵から逃げて晶泉へ駆け込んでも、戦闘状態中は使用不可を維持

## 10. 副晶石・足場との視覚分離

- 晶泉と副晶石を同一画面へ常時並べない
- 右側の副晶石から最低1ビューポート相当の移動感を確保できると理想
- 難しい場合でも壁、湖岸、細い通路で区画を分ける
- 晶泉は白シアン中心
- 副晶石は紫中心
- 湖上足場は青紫中心
- 光柱や床紋様が重ならない

## 11. 回復演出の調整

既存phaseと回復機能は維持する。

- idle→charging→healing→afterglow
- HP・MP全回復
- 戦闘不能解除
- 初回固定会話
- 専用SFX

描画変更：

- charging：湖面の古代紋様が岸から晶石へ点灯
- healing：湖上晶石から3人へ細い光
- afterglow：湖面へ大きな波紋が広がる
- 巨大円盤全体の発光は使わない
- 三人は岸側祭壇の手前へ並ぶ

## 12. 操作と衝突

- プレイヤーは岸側から晶泉に触れる
- 湖面は歩行不可
- 半円祭壇の手前部分は歩行可能
- 浮遊晶石直下と祭壇奥は歩行不可
- collisionは新しい小さな構造へ合わせて縮小
- 旧巨大円形collisionを残さない
- 旧座標へ不可視衝突・interactionを残さない
- 仲間の回復整列位置は歩行可能床上

## 17. 実装順序

1. 根ゲートの現在の左右offset描画を特定
2. 上方向収縮アニメーションへ変更
3. 根ゲート完了後の残留描画・衝突を確認
4. 晶泉の専用円形水面と完全円リングを削除
5. 湖water tile上の半円祭壇と浮遊晶石へ再構成
6. 座標、カメラ、collision、interactionを調整
7. 混成戦グループを別広場へ移動しleashを確認
8. 回復phaseの描画を湖面へ同期
9. QAとテスト更新
10. `npm run typecheck`
11. `npm test`
12. `npm run build`
13. 第1層ゲートと第2層晶泉を通常プレイで視覚QA
