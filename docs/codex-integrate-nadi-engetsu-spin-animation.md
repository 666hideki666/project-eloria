# Codex向け追加指示：ナディ特殊技「円月旋」モーションを導入

Project Eloriaへ、ナディの特殊技「円月旋」の4方向アニメーションを導入してください。

通常攻撃3人分とカイルの破陣突きで使用している共通アクションスプライト機構を再利用し、ナディの`actions.special`へ設定として追加してください。専用レンダラーや、ナディだけのフレーム選択処理は作らないでください。

## 使用ファイル

- 特殊技シート：`assets/sprites/characters/nadi/attacks/nadi-special-engetsu-spin-48px-v1.png`
- メタデータ：`assets/sprites/characters/nadi/attacks/nadi-special-engetsu-spin-48px-v1.json`
- 通常攻撃：`assets/sprites/characters/nadi/attacks/nadi-normal-moonblade-throw-48px-v1.png`
- 待機・歩行：`assets/sprites/characters/nadi/nadi-idle-walk-48px-v1.png`

特殊技シート仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向きから開始し、下向きで終了
- 2行目：上向きから開始し、上向きで終了
- 3行目：左向きから開始し、左向きで終了
- 4行目：右向きから開始し、右向きで終了
- 各行6コマ：構え、ひねり、旋回開始、最大旋回、旋回完了、復帰
- 非ループ
- 合計0.34秒
- 基準点：足元中央

## 中間フレームの方向

円月旋は身体が時計回りに一周するため、各行の中間コマでは横向き、背面、正面など、開始方向とは異なる身体の向きが描かれています。これは意図したアニメーションです。

- 行の選択は技開始時の`actionFacing`で固定する。
- 中間コマを現在の向きに合わせて別行へ差し替えない。
- フレームごとに方向判定をやり直さない。
- スプライト全体をCanvas側で回転させない。
- 左右反転しない。
- 6コマを順番どおり再生する。

## 設定への追加

`characterSpriteConfig.ts`で次を行ってください。

- PNGを`?url`で読み込む。
- JSONメタデータを読み込む。
- `createCharacterActionSpriteConfig("special", ...)`を使用する。
- `NADI_SPRITE.actions.special`へ登録する。
- 既存の`actions.normal`を維持する。

`GameWorld`はすでに`beginCharacterAction(member, "special", 0.34)`を呼び出しています。現在の`actionKind`、`actionFacing`、`actionSequenceId`をそのまま使用してください。

## アニメーション

- ナディかつ`actionKind === "special"`の間だけ円月旋シートを使用する。
- 各使用開始時に1コマ目から再生する。
- JSONのフレーム時間で6コマを1回だけ再生する。
- 合計時間を既存の`actionDuration = 0.34`と一致させる。
- 技の途中で操作入力により行を変更しない。
- 終了後は技開始方向の待機または新しい移動方向へ自然に戻る。
- 月輪投げ直後に使用しても、通常攻撃シートから正しく切り替わる。
- ポーズ、タブ非表示、ゲームオーバー中に時間が飛ばない。
- 画像読み込み失敗時は現在の共通フォールバック表示でゲームを継続する。

## ワールド位置

円月旋はナディを中心とする回転攻撃です。

- 技のためにナディのワールド座標を移動させない。
- スプライト側でもセル内の足元基準を固定する。
- 回転中に当たり判定中心がナディからずれないようにする。
- ノックバック以外の追加移動を発生させない。

## 攻撃判定

既存の円月旋性能を変更しないでください。

- ダメージ：29
- 攻撃中心：ナディの現在位置
- 外半径：53
- 内半径：7
- ノックバック：32
- 特殊技クールダウン：3.3秒
- 1回の使用で同じ敵へ1回だけ命中

現在の`AttackArea.hitIds`による多段防止を維持してください。見た目の回転コマが3コマ続いても、同じ敵へ3回ダメージを与えないでください。

## エフェクト

既存の円形エフェクトを維持します。

- 種類：`ring`
- 位置：ナディの現在位置
- 寿命：0.38秒
- 大きさ：58
- 色：`#aefcf7`

通常攻撃エフェクト調整後の共通Canvas表現と共存させてください。

- 太い青白い円形斬撃はゲーム側で描画する。
- 月輪刃の回転光をスプライトへ焼き込まない。
- 命中火花、効果音、ヒットストップ、画面振動を維持する。
- 円形光がナディ本人、敵、HPバー、危険予兆を長時間隠さない。
- `strongFlashes`と`screenShake`の設定を尊重する。

月輪刃は全24コマの画像内に1つずつ含まれています。別の手持ち月輪刃を追加描画しないでください。

## 描画

- 待機・歩行・月輪投げと同じ`drawScale`を使用する。
- 同じ足元アンカーと方向別Y補正を使用する。
- 技開始・終了時に身体が拡大、縮小、上下移動して見えないようにする。
- ポニーテール、三つ編み、スカーフの回転が6コマで自然につながる。
- 月輪刃が全方向・全コマで1つだけ表示される。
- 48×48セル境界で月輪刃や髪が欠けない。
- nearest-neighbor描画を維持する。
- 接地影、操作中マーカー、HUD強調を維持する。

## 変更しないもの

- ナディの待機、歩行、月輪投げ
- カイルとメルの全スプライト
- カイルの破陣突き
- 月蝕乱舞、輪光掃
- 通常攻撃エフェクト
- 敵AI、陣形、経験値、ドロップ
- HUD、BGM、効果音
- ゲームバランス

## テスト

既存テストを維持し、少なくとも次を追加・確認してください。

- `NADI_SPRITE.actions`に`normal`と`special`が登録される。
- 特殊技シートが288×192として検証される。
- 6フレームの合計が0.34秒である。
- 下、上、左、右の開始方向から正しい行を選ぶ。
- 中間コマでも開始時に選んだ行を維持する。
- `actionKind === "special"`で円月旋シートを使う。
- `actionKind === "normal"`では月輪投げシートを使う。
- 新しい`actionSequenceId`で1コマ目から再生する。
- 攻撃中心がナディの位置からずれない。
- 同じ敵へ1回だけダメージを与える。
- ダメージ、半径、内半径、ノックバック、クールダウンが変わらない。

## 完了条件

- 円月旋入力時に専用の6コマが再生される。
- どの開始方向でも身体が一周して元の方向へ戻る。
- 中間フレームが誤って別行へ切り替わらない。
- 足元を中心に回転し、ワールド位置がずれない。
- ポニーテール、三つ編み、スカーフが旋回へ追従する。
- 月輪刃が全コマで1つだけ表示される。
- 半径53の円形攻撃と画像の旋回が一つの技に見える。
- 同じ敵へ不正な多段ダメージが入らない。
- 円形エフェクト、命中、効果音が正常に動く。
- 月輪投げで特殊技シートが誤再生されない。
- カイル、メル、敵、HUDへ意図しない変更がない。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。

実装後は、上下左右、月輪投げ直後、空振り、単体命中、複数敵への同時命中、壁際を確認してください。登録した設定、行を固定する方法、方向別の足元位置、円形判定との同期、同じ敵へ1回だけ命中することを日本語で報告してください。
