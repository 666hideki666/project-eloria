# Codex向け追加指示：カイル待機・歩行スプライトの試験導入

Project Eloriaの現在の試作版へ、完成したカイルの4方向待機・歩行スプライトを試験導入してください。

今回はカイルだけを差し替え、ゲーム内サイズ、移動時の読みやすさ、陣形内での見え方を確認します。ナディ、メル、敵、背景、HUDは変更しないでください。

## 使用する正式ファイル

- スプライトシート：`assets/sprites/characters/kyle/kyle-idle-walk-48px-v1.png`
- フレーム情報：`assets/sprites/characters/kyle/kyle-idle-walk-48px-v1.json`

シート仕様：

- 全体：288×192px
- 1フレーム：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行の0〜1列：待機
- 各行の2〜5列：歩行

原寸参照版とクロマキー版は編集・削除しないでください。

## 描画

- Canvasの画像補間を無効化し、nearest-neighborで描画する。
- CSSでCanvasを拡大している場合も`image-rendering: pixelated`を維持する。
- スプライトをぼかさない。
- キャラクターの基準点は足元中央にする。
- 地面の影は既存のゲーム描画を使い、画像へ追加しない。
- 既存の当たり判定を48×48全体へ広げない。
- 当たり判定は足元付近の小さな矩形または円を維持する。
- 見た目の大きさが現在の簡易キャラと大きく違う場合は、ワールド座標の当たり判定を変えず、描画倍率だけを調整する。

## 方向

- 下入力：下向き
- 上入力：上向き
- 左入力：左向き
- 右入力：右向き
- 斜め入力時は、最後に強く入力された軸または既存の方向決定規則を使う。
- 移動を止めたら、最後に向いていた方向を維持して待機する。
- 左右画像をコード側で反転せず、シート内の左向き・右向きをそれぞれ使う。

## アニメーション

- 待機：各方向2コマ、約2fps。
- 歩行：各方向4コマ、約8fps。
- ゲームループのフレームレートではなく経過時間でコマを進める。
- ポーズ中はアニメーション時間も停止する。
- ゲームオーバーや非表示タブから戻った際に、アニメーションが高速で飛ばないようにする。
- キャラクター交代後も向きとアニメーション状態を正しく更新する。
- 後方AIとして移動しているカイルにも歩行アニメーションを適用する。
- 陣形位置で停止したら待機へ戻す。

## 攻撃中

今回のシートには攻撃専用フレームがありません。

- 通常攻撃、特殊技、大技、交代攻撃の既存ロジックとエフェクトは維持する。
- 攻撃中は現在方向の待機フレームまたは自然な歩行フレームで固定してよい。
- 画像全体を回転、伸縮、傾斜させて仮の攻撃モーションを作らない。
- 後続作業で攻撃シートを追加できる状態にする。
- 攻撃アニメーションがないことを理由に、技の当たり判定やタイミングを変えない。

## 戦闘不能

今回のシートには片膝の戦闘不能フレームがありません。

- 現在の簡易戦闘不能表示を一時的に維持するか、最後の待機フレームを暗くして表示する。
- 戦闘不能ロジック、自動交代、ターゲット除外、戦闘後の復帰を壊さない。
- 後続の戦闘不能シート追加を前提に、状態名を明確に分ける。

## 読み込み

- 画像の読み込み完了前に描画して例外を出さない。
- 読み込み失敗時はゲームを停止せず、現在の簡易カイル表示へフォールバックする。
- 開発サーバーと本番ビルドの両方で画像パスが解決される方法を使う。
- 既存のアセット読み込み方式がある場合はそれに合わせる。
- 同じ画像をキャラクターごと、フレームごとに重複読み込みしない。

## 調整可能値

次の値を1か所へまとめる。

- 描画倍率
- 足元アンカー
- 待機fps
- 歩行fps
- 描画オフセットX
- 描画オフセットY
- 足元影の大きさ

## 完了条件

- カイルだけが新しい正式スプライトで表示される。
- 上下左右へ移動すると正しい方向の歩行アニメーションになる。
- 停止すると最後の方向を向いた待機アニメーションになる。
- 操作キャラでも後方AIでも正しくアニメーションする。
- キャラクター交代後も向き、陣形、移動が壊れない。
- スプライトがぼやけない。
- 足元が滑って見えず、壁や敵との当たり判定も従来どおり。
- 左右スプライトの剣とスカーフの向きが正しい。
- 攻撃、特殊技、大技、交代攻撃、効果音、BGMが従来どおり動く。
- 戦闘不能と再挑戦が従来どおり動く。
- ナディ、メル、敵の表示は変わっていない。
- 本番ビルドで画像が404にならない。

実装後は、ゲーム内で下・上・左・右を向いたスクリーンショットを確認し、採用した描画倍率、アンカー、fps、見た目の大きさに関する所感を日本語で報告してください。
