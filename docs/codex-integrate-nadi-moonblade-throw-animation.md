# Codex向け追加指示：ナディ通常攻撃「月輪投げ」モーションを導入

Project Eloriaへ、ナディの通常攻撃「月輪投げ」の4方向攻撃アニメーションを導入してください。

カイルの連刃剣で追加済みの共通行動種別、攻撃シート読み込み、非ループ再生、攻撃開始時のリスタート処理を再利用してください。ナディだけ別のアニメーション方式にしないでください。

## 使用ファイル

- 攻撃シート：`assets/sprites/characters/nadi/attacks/nadi-normal-moonblade-throw-48px-v1.png`
- メタデータ：`assets/sprites/characters/nadi/attacks/nadi-normal-moonblade-throw-48px-v1.json`
- 待機・歩行シート：`assets/sprites/characters/nadi/nadi-idle-walk-48px-v1.png`

攻撃シート仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行6コマ：構え、引き、投擲、振り抜き、復帰動作、受け戻し
- 非ループ
- 合計0.18秒
- 基準点：足元中央

## 設定への追加

`characterSpriteConfig.ts`で、カイルの`normal`アクションと同じ構造を使用してナディの通常攻撃を登録してください。

- PNGとJSONをURL／メタデータとして読み込む。
- `NADI_SPRITE`の`actions.normal`へ登録する。
- `CharacterActionKind`、`actionKind`、`actionSequenceId`など、連刃剣で導入済みの共通状態をそのまま使う。
- カイル用コードをキャラクター名の条件分岐で複製せず、設定駆動で処理する。

## アニメーション再生

- ナディかつ`actionKind === normal`の間だけ月輪投げシートを使用する。
- 攻撃開始時の方向を6コマの間固定する。
- 上下左右の画像をそのまま使い、左右反転しない。
- 各攻撃開始時に必ず1コマ目から再生する。
- ボタン長押しで次の通常攻撃が成立した場合、新しい攻撃ごとに再スタートする。
- 終了後は最後の方向の待機または移動へ戻る。
- 後方AIの通常攻撃でも同じモーションを再生する。
- ポーズ、タブ非表示、ゲームオーバー中にアニメーション時間が飛ばないようにする。

JSONのフレーム時間は合計0.18秒です。最初の予備動作を短くし、入力直後の反応が鈍く見えない構成になっています。

## 月輪刃と投射物

画像内の月輪刃は次の構成です。

- 0、1コマ目：手に持っている。
- 2、3、4コマ目：投げた後なので手元にない。
- 5コマ目：受け戻して再び手に持っている。

既存の`moonBlade`投射物はゲーム側で描画し続けてください。

- キャラクター画像とは別に、飛翔する月輪刃を既存処理で描画する。
- キャラクターの手元へ別の月輪刃画像を追加しない。
- 投射物の速度154、半径7、寿命0.92秒、ダメージ16、後方攻撃半減を変更しない。
- 投射物の生成位置、命中判定、効果音を維持する。
- 現段階では投射物生成を遅延させず、入力への即応性を優先する。
- 2コマ目へ到達するまでが約0.035秒と短いため、投射物が手元から飛び出したように見えるか実画面で確認する。
- 5コマ目で武器が戻る表現は、短い魔力回収として扱う。投射物寿命に合わせて操作を長時間固定しない。

将来エフェクトを作り込む際は、投擲直後の細い青白い円軌跡と、受け戻し時の小さな収束光をゲーム側へ追加できます。今回は追加しなくて構いません。

## 描画

- ナディの待機・歩行と同じdrawScale、足元アンカー、方向別Y補正を使用する。
- 攻撃開始・終了時に身体が拡大、縮小、上下移動して見えないようにする。
- ポニーテール、三つ編み、スカーフの動きを消さない。
- nearest-neighbor描画を使用する。
- 通常時の水色足元リングを復活させない。
- 接地影、操作中マーカー、HUD強調を維持する。

## 変更しないもの

- カイルの待機、歩行、連刃剣
- メルの全スプライト
- ナディの円月旋、月蝕乱舞、輪光掃
- 攻撃力、クールダウン、投射物性能
- 敵AI、陣形、当たり判定、ゲームバランス
- HUDポートレート
- BGMと効果音

## 完了条件

- ナディの通常攻撃時だけ月輪投げの6コマが再生される。
- 上下左右すべて正しい向きで再生される。
- 投擲途中で向きが変わらない。
- 武器を持つコマと空の手のコマが正しく表示される。
- 飛翔する月輪刃がゲーム側投射物として1つ表示される。
- 手元へ月輪刃が二重描画されない。
- 攻撃開始時の反応が遅く感じられない。
- 足元位置と身体サイズが待機・歩行時から変わって見えない。
- 後方AIの通常攻撃でも再生される。
- 円月旋と月蝕乱舞で月輪投げシートが誤再生されない。
- カイル、メル、敵、HUDへ意図しない変更がない。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。
- 既存テストが通り、ナディの通常攻撃状態に必要なテストが追加されている。

実装後は、上下左右、移動直後、ボタン長押し、後方AIで月輪投げを確認してください。採用した設定追加方法、投射物と手元の同期、方向別の足元位置、武器の二重表示、既存技への影響を日本語で報告してください。
