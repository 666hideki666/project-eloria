## 今回の意図

- 封印石の既存３場面が終わったら「森の遺跡へ戻る」のクリア選択を出さず、三人を**古の森の洞窟前**へ帰す。そこで「いったん村へ戻ろう」と自然に決める短いイラスト演出を流す。
- 初回の森→第１層で、現在の第１層背景の上に載る操作説明をやめる。洞窟に入った直後、**ゲーム背景・HUDを見せない独立した暗い画面**で説明し、終わってから第１層の入場タイトルと既存の異変演出へ進む。
- 左上のキャラ名・顔を押すと開く既存の状態パネルに「操作方法」ボタンを足し、いつでも説明を見直せるようにする。現在のポーズ画面の「操作を見る」も残す。

## A. 封印石後の流れ

1. ボス後に封印石へ接触→既存の「乱れる晶光／メルの声／託された石」３場面は維持。最後の送り／スキップで封印石の取得と効果音を**一度だけ**確定する。
2. 取得後はクリア結果オーバーレイを見せず、短い暗転で古の森の `caveReturnSpawn`（洞窟の外）へ移動。第１層のスポーンや「森の遺跡へ戻る」選択を通らない。三人のHP・MP・経験値・操作キャラと章進行を保持し、古の森BGMへ自然に切り替える。
3. 森の洞窟前に着いたら、下記２場面を既存の章末イラスト演出と同じ形式（緩いパン、２文連続タイプ、送り／スキップ、動き軽減、画像失敗時の文字継続）で表示。演出中は移動・攻撃・再遷移を遮断する。最後に古の森の操作へ戻す。
4. 以後、同じ封印石の演出・帰還演出は再発火しない。洞窟には任意で入り直せる。DEV／QA直行や arena のクリア動線は維持する。
5. 封印石取得後は村道の序盤用制止を解除する。プレイヤーが自分で古の森の南端まで進むと短く暗転し、**今回は村マップを挟まずゲームを終了して既存のタイトル画面へ戻る**。村での会話や次章の導入はまだ作らない。タイトルの音楽・START・開発用WARPは通常の起動画面どおりに戻し、STARTは新規プレイとして開始する。

### 村道南端の確定方針

ユーザーは2026-10-25に「村は今から作る段階で今回は村に戻ったらゲーム終了でスタート画面に戻ればいい」と指定。従って一時的な「第一章・完」画面案は**採用しない**。封印石取得前は既存どおり村道を制止し、取得後だけ静的なユーザー赤線内の村道を開ける。`AncientForestCollisionOptions.villageExitOpen` の既存拡張点を活用し、南端到達で一度だけタイトルへ遷移する。村マップ・追加の物語・強制的な自動歩行は作らない。赤線マスクそのものは変更しない。

## B. 洞窟に入った時の操作案内

1. 通常プレイで古の森の洞窟へ**初めて**入る時だけ、森からの暗転後に独立した不透明な説明画面を先に出す。第１層の背景、キャラ、敵、HUD、中央入場タイトルを背後に見せない。新しい背景イラストは不要。既存の顔絵、技ゲージ実演、読みやすいDOM文字を使う。
2. 既存の２枚の説明内容（３人の交代／攻撃と５秒１段のゲージ）を維持し、冒頭の洞窟の地の文も独立画面内に置く。最後のカードに「操作方法は、いつでも左上のキャラ名を選び、状態画面の『操作方法』から見られます。」をはっきり表示。タッチ・PCのボタン表示を切り替える。ポーズからも見られる旨は小さく添えてよい。
3. 最後の送り／スキップで説明画面を閉じ、第１層のフィールド→中央入場タイトル「第一層／苔根の遺構」→既存の異変演出→操作開始へ進む。説明画面終了の入力を、戦闘・移動・異変演出の送りへ持ち越さない。
4. 森への復路・第１層への再入場、DEV／QA直行では強制表示しない。説明をスキップしても状態パネルから再表示できる。

## C. 状態パネルからの再表示

- 左上のキャラ名・顔は現在すでに状態パネルを開く。ここに「操作方法」ボタンを追加する。開く対象は既存の２カードで、再表示時は洞窟導入文・第１層タイトル・異変演出を再生しない。
- 状態パネルから呼んだ場合、説明中はゲームを止め、閉じたら同じキャラの状態パネルへ戻して操作位置とフォーカスを保つ。ポーズから呼んだ場合は従来どおりポーズ画面へ戻す。どちらも押しっぱなしや連打でゲーム操作を発火しない。
- 画面幅・タッチ操作・キーボード・動き軽減・読上げ・フォーカス復帰を確認。既存のステータス閲覧、交代、ポーズの挙動を変えない。

## 実装・技術検証結果（2026-10-25）

### 実装

- `GameWorld` は封印石取得時にクリア状態を挟まず古の森への暗転を開始。移動中は入力と資源タイマーを止め、暗転だけを進める。操作中のキャラを `caveReturnSpawn` に配置し、到着後の２場面を完了するまで操作を遮断する。取得・帰還完了はそれぞれ一度だけ受理する。
- `ChapterSequence`／`ChapterCinematicController` を場面数・原稿・画像・完了処理を渡せる形にし、既存３場面と新しい帰還２場面を共通形式で表示。新しい原稿／画像の参照は `src/ui/forestReturnScenes.ts`。移動中は不透明画面で待ち、到着前に送り／スキップして絵を先行表示できない。
- `villageExitOpen` は取得フラグに同期。静的マスクは不変。南端の原寸画像下端３px以内へ下向き移動で到達すると `TitleReturnController` が暗転し、クエリ／ハッシュなしの同じパスを新規読み込みする。既存タイトル／START／音楽／DEV UIを再構築し、前周のゲーム進行とDEV／QA指定を持ち越さない。音量・ミュートは既存localStorageの設定を引き継ぐ。
- 操作案内はbody直下の不透明な全画面モーダルへ移し、森→第１層の暗転が黒になった時点で表示する。背景のゲーム領域をinert／aria-hiddenにし、案内を閉じてからフィールドの暗転を解除し入場タイトル・異変へ進む。
- 状態パネルの「操作方法」からも既存２カードを再表示。選択キャラと状態パネルを保持してゲームを停止し、閉じると同ボタンへフォーカスを戻す。ポーズ案内も同様。小さい横画面は余白とカード送り時のスクロールを調整し、最後の説明文とボタンの見切れを修正した。
