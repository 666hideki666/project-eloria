# Codex向け実装指示：第2層「光羽の晶洞」v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：既存の第1層を壊さず、独立した横長マップ、カメラ、複数遭遇、2段階ギミック、層移動、QAを追加する中〜大規模実装のため。

## 1. 目的

第1層「苔根の遺構」の出口から、第2層「光羽の晶洞」へ進める探索・戦闘層を追加する。

この層で体験させるもの：

- 横長の広い晶洞を左から右へ探索する
- 地下湖、水路、橋、晶石足場による経路の変化
- ルミバネを中心とした飛行敵戦
- ナディの広範囲攻撃が役立つ戦闘
- 2つの晶石装置を探して湖上の道を完成させる
- 任意の行き止まりと回復地点
- 最終広場を突破して第3層入口へ到達する

今回の完了条件は、第2層へ進入し、探索、戦闘、逃走、装置作動、湖横断、最終戦、第3層入口到達まで一連でプレイできること。

## 2. 第1層との接続

- 第1層最終戦のクリア条件と、既存の第2層門を維持する
- 門へ近づくと既存形式の操作案内を表示する
- `E` / `Enter`で第2層へ遷移する
- 第2層開始位置は左端の到着広場
- 遷移時に敵、戦闘状態、攻撃、エフェクト、近接案内、古いカメラ位置を安全にリセットする
- HP、MP、戦闘不能状態、経験値は原則引き継ぐ
- 第1層の回復地点を使わず進んだ場合も、第2層で詰まない難度にする
- 第2層から第1層へ戻る入口を用意してよい。ただし戦闘中は層移動不可

層の識別は曖昧なbooleanを増やさず、既存構造に合わせて列挙可能な状態にする。

例：

```ts
type StageArea = "arena" | "transferChamber" | "mossCorridor" | "mossRootRuins" | "lightwingCrystalCavern";
```

実際の型名は現状へ合わせる。

## 3. マップ寸法と進行方向

- ワールド：`2304 × 1344px`
- タイル：`32px`
- グリッド：`72列 × 42行`
- 表示範囲：現在の`640 × 360`を維持
- 開始：左端中央寄り
- 最終広場：右上
- 第3層入口：最終広場の奥
- 主進行：左から右
- ただし一直線の通路は禁止
- 上下方向の折り返しを最低3回作る
- マップ端ではカメラを正しくclampする

マップの縦横比を固定の共通定数へ逆流させない。今後、縦長・横長・正方形の層を追加できるよう、各マップ定義から`worldWidth`と`worldHeight`を参照する。

## 4. 本番ルート

次の順序を基本とする。

```text
A 到着広場
  → B 水晶の浅瀬
  → C 光羽の吹き抜け
  → D 主晶石装置
  → F 青水路の下道
  → G 混成戦広場
  → H 回復の晶泉
  → I 副晶石装置
  → J 晶石足場で地下湖を横断
  → K 光羽の巣
  → L 第3層への門
```

任意分岐：

```text
D付近 → E 崩れた橋の行き止まり → 元の経路へ戻る
```

要件：

- 到着地点からゴールを直線で結ばない
- 壁越しまたは湖越しに後半エリアの光を見せる
- 行き止まりは完全な無駄に見せず、将来宝箱を置ける台座と景観を用意する
- 通路幅は通常96〜160px
- 戦闘広場は3人陣形と敵4体が重ならず動ける広さ
- 通路封鎖は一切使わない
- 敵から離れれば既存の逃走処理が働く

## 5. エリア別配置

### A. 到着広場

- 左端の円形石床
- プレイヤー1人表示で開始
- 敵は開始画面に入れない
- 青い晶洞と地下湖を最初に見せる静かな場所
- 第1層へ戻る入口を置く場合は、接触だけで戻さず操作式にする

### B. 水晶の浅瀬

- 蛇行する石床と浅瀬
- 水面は進入不可
- ルミバネ1体の導入戦
- 敵が最初から高速で突進せず、発見→旋回→接近の順にする
- 初戦場所は最低320×240px程度の有効床面を確保

### C. 光羽の吹き抜け

- 上側の大きな円形または楕円形広場
- ルミバネ3体
- 3体同時突撃は禁止
- 攻撃権を持つ個体を最大1〜2体へ制限
- 退路を常に開ける

### D. 主晶石装置

- 大型の青シアン晶石と円形台座
- 台座は衝突対象で、上を歩けない
- 近接案内：`E　主晶石に触れる`
- 作動時：発光、環状波、湖方向へ光が走る
- 一部の湖上足場だけが点灯または出現する
- この時点では湖を渡れない
- バナー：`晶石の光が湖の奥へ流れていく……まだ道は繋がらない`

### E. 崩れた橋の行き止まり

- 任意探索区間
- ルミバネ2体
- 橋の先端に空の台座を置く
- 今回はアイテムを実装しない
- 将来の宝箱配置を想定したデータIDだけ付けてもよいが、空の取得処理は作らない

### F. 青水路の下道

- 大きく下へ迂回する非戦闘区間
- 水路、低い橋、晶石柱、滝の装飾
- 装飾物の当たり判定で通路幅を96px未満にしない
- 景色を眺める緩急区間として敵を置かない

### G. 混成戦広場

- モスプルン2体＋ルミバネ2体
- 必須戦
- 地上敵と飛行敵の違いが分かる横長広場
- 敵全員が同時にプレイヤーへ密着しない
- カメラ外から即攻撃しない
- 上下どちらかへ十分離れれば逃走可能

### H. 回復の晶泉

- 非戦闘小広場
- HP、MP、戦闘不能を回復
- 見た目は第1層の泉と差別化し、天井から落ちる晶光が水面へ集まる
- 台座または泉の中心は衝突対象
- 外周から`E　晶泉に触れる`
- 戦闘中は使用不可

### I. 副晶石装置

- 主晶石より小さいが、操作対象だと分かる台座付き結晶
- 主晶石未作動時：`遠くの晶石と繋がっていないようだ`
- 主晶石作動後：`E　副晶石に触れる`
- 作動すると全足場が順番に点灯・出現
- バナー：`二つの晶石が共鳴し、湖上に道が現れた`
- 一度完成した足場はそのプレイ中は維持

### J. 晶石足場

- 大きな地下湖を斜め右上へ渡る
- 1足場の有効幅は最低96px
- 落下処理は今回作らない
- 足場外の湖を衝突で進入不可にする
- 足場上に敵を置かない
- 足場未完成時、途中まで渡れて行き止まる危険を避ける。完成前は入口側で明確に通行不能にするか、最初の足場を未出現にする
- キャラクターが出現アニメーション中の足場内部へ埋まらない

### K. 光羽の巣

- 右上の大広場
- ルミバネ4体
- 必須最終戦
- 攻撃役は最大2体
- 旋回待機する個体と接近する個体を分ける
- ナディの通常・特殊・大技の広範囲攻撃が複数へ当たりやすい間隔
- 逃走する場合は晶石足場側へ戻れる
- 全撃破で第3層門を点灯

### L. 第3層への門

- 最終広場の奥に大きな晶石門
- 最終グループ未撃破時：`光羽の気配が門を閉ざしている`
- 撃破後：`E　第3層への門を調べる`
- 第3層は未実装なので、操作時は次のように表示する

```text
この先から、さらに強い晶力を感じる。
第3層は今後の開発で追加予定です。
```

- 黒画面や未定義座標へ遷移しない

## 6. マップ定義

第1層の定数へ第2層情報を混在させず、新規マップ定義を作る。

推奨：

```text
src/stage/maps/lightwingCrystalCavernMap.ts
```

含めるもの：

- world size
- tile size / rows / columns
- player spawn
- return gate / next gate
- walkable tilesまたは領域
- water / void / walls
- bridges
- primary crystal
- secondary crystal
- healing spring
- future chest pedestal
- enemy group spawns
- crystal platform positions
- solid props

座標を`GameWorld`、Renderer、collisionへ重複記述しない。マップ定義を単一の基準にする。

## 7. 遭遇配置

合計14体。

| ID | 敵 | 数 | 必須 | 場所 |
| --- | --- | ---: | --- | --- |
| `lightwingIntro` | ルミバネ | 1 | 必須 | B |
| `lightwingDraft` | ルミバネ | 3 | 必須 | C |
| `lightwingDeadEnd` | ルミバネ | 2 | 任意 | E |
| `mixedChannel` | モスプルン2＋ルミバネ2 | 4 | 必須 | G |
| `lightwingNest` | ルミバネ | 4 | 必須 | K |

要件：

- 各敵は所属グループIDを持つ
- 任意グループを倒さなくても進行可能
- 最終門は`lightwingNest`のみを条件にする
- 画面外の未発見グループを戦闘へ参加させない
- 複数グループの追跡範囲が重なり、全14体が連鎖して来ないようにする
- 逃走後、敵は適切にホーム位置へ戻る
- 撃破済み敵は再出現しない

## 8. ルミバネAIの確認と調整

既存ルミバネの見た目・攻撃モーション・当たり判定を再利用する。

第2層で必要な挙動：

- 発見後に短い予備時間
- 中距離を旋回
- 攻撃権を得た個体だけ接近
- 攻撃前に羽の発光または既存予兆
- 攻撃後は距離を取る
- 水路や穴の上は飛べる
- ただし壁を無視した索敵・攻撃で一方的に攻撃しない
- 攻撃判定がモーションだけで終わらず、既存のダメージタイミングで発火する
- 同一個体が連続して攻撃権を独占しない

第1層やアリーナのルミバネ挙動を壊す共通変更は避ける。必要なら遭遇ディレクター側の同時攻撃数をマップまたはグループ設定として渡す。

## 9. 晶石装置と足場状態

状態例：

```ts
primaryCrystalActivated: boolean;
secondaryCrystalActivated: boolean;
crystalPathUnlocked: boolean;
crystalPathAnimationProgress: number;
```

ルール：

1. 主晶石を先に作動
2. 主晶石作動後に副晶石が操作可能
3. 副晶石作動で`crystalPathUnlocked = true`
4. 足場を湖の入口側から奥側へ順番に出現
5. 演出完了後に通行可能
6. 操作連打でタイマーを重複起動しない
7. 層を出て戻った場合の状態は、そのプレイセッション中は維持

Rendererは`GameWorld`のprivate timerへ直接触れず、0〜1へclampしたsnapshot値を使う。

足場衝突は描画と一致させる。未解放時の透明足場に見えない床判定を残さない。

## 10. 操作物と衝突

常設solid props：

- 主晶石台座
- 副晶石台座
- 回復の晶泉中心
- 大型晶石柱
- 将来宝箱用台座（歩行の邪魔にならない場合）

要件：

- プレイヤー、戦闘中の仲間、敵が台座を不自然に通過しない
- 見た目の接地面に合わせた円・楕円または矩形衝突
- 発光エフェクト全体を衝突にしない
- 衝突の外側から操作できる
- 通路角で引っかかりにくくする
- 水、穴、崖は常に非歩行
- 橋と足場だけ歩行可
- 飛行敵は水上を移動できるが、索敵と攻撃は地形越しに暴発させない

## 11. 描画

新規Rendererを推奨：

```text
src/render/stages/LightwingCrystalCavernRenderer.ts
```

色調：

- 地：濃紺、青緑、暗い紫
- 石床：青灰色
- 水：暗い青＋シアンの反射
- 結晶：シアン、青、紫、白い小ハイライト
- 植物：第1層より少なく、苔は寒色

描画レイヤー：

1. void / cavern darkness
2. water and distant depths
3. ground tiles / bridges / platforms
4. low decorations and prop bases
5. entity ground layer
6. tall props foreground
7. particles / crystal glow
8. combat effects / prompts / HUD

ピクセル表現を維持し、大きな滑らかなグラデーションや写真調フィルターは避ける。水面と結晶は2〜4段階の明滅で動きを出す。

## 12. BGMと音

- 第2層専用探索曲はまだ必須ではない
- 専用曲が未登録なら、現在の探索曲をフォールバック使用
- 戦闘時は現在の戦闘曲
- 逃走・全滅・戦闘終了時のBGM復帰を第1層同様に維持
- 層遷移で二重再生しない
- 晶石装置は既存の魔力系SFXを再利用可能
- 足場出現は短い連続音または低い晶石音。新規音源ファイル生成は不要

## 13. HUDとバナー

- エリア名：`晶界・光羽の晶洞`
- 探索中は操作キャラクター1人表示
- 戦闘開始で3人陣形
- 既存のパーティーステータスを維持
- ENEMY表示は現在交戦中のグループだけを対象にする
- 全14体の残数を常時ENEMYへ出さない
- 近接プロンプトと重要バナーが毎フレーム上書きし合わない

## 16. 視覚QA

3. 横長マップを左から右へ進んでいる感覚がある
4. ルートが一直線でなく、上下に折り返す
5. 地下湖越しに後半の目的地が見える
6. 水面、床、壁、橋、足場の歩行可否が見た目で分かる
7. 主晶石、副晶石、回復晶泉が区別できる

## 18. 実装順序

1. 現状の型、stage分岐、カメラ、衝突、QA構造を確認
2. 第2層マップ定義と到達可能な歩行領域を作成
3. 層遷移とカメラを接続
4. 第2層Rendererで地形を描画
5. 水、壁、橋、台座衝突を接続
6. 敵14体と遭遇グループを配置
7. 逃走とBGM切り替えを確認
