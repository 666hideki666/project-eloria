# Codex向け実装指示：苔の回廊とモスプルン初戦

> **停止・旧仕様**：この指示書は「1部屋＝1画面」の固定画面方式を前提にしているため、2026-08-11に停止した。今後の実装は`docs/codex-implement-scrolling-layer1-moss-root-ruins.md`を正とする。モスプルン3体戦、敵AI、探索・戦闘BGM切り替えの成果は新方式へ再利用する。

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Ultra`：不要
- 理由：部屋遷移、ステージ内戦闘、敵スポーン、BGM切り替え、クリア状態を既存基盤に接続する中規模実装のため。

## 目的

「晶界・転送の間」から「苔の回廊」へ進めるようにし、モスプルン3体との最初のチュートリアル戦闘を完成させる。

このタスクで初めて、次の一連の遊びをつなげる。

1. 非戦闘で1人探索
2. 仕掛けを調べて門を解放
3. 固定画面の部屋遷移
4. 敵に発見される
5. 3人が陣形展開
6. 探索BGMからバトルBGMへ切り替え
7. モスプルンを撃破
8. 陣形を1人探索へ戻す
9. 探索BGMへ戻す

既存のアリーナ戦闘、3キャラ、モスプルンAI・スプライト・攻撃、SFX、HUD、QAを壊さないこと。

- 総合仕様：`docs/game-design-first-stage.md`

## 1. ステージ状態を部屋遷移対応にする

現在の`GameWorld`は初期化時の部屋を`readonly`で保持している。既存テストを守りつつ、実行中に部屋を変更できるようにする。

方針：

- `stageId`は第1ステージ中は`forestRuins01`のまま
- `roomId`、`roomName`、現在の`room`を遷移時に更新する
- `STAGE_ROOMS`を部屋定義の取得箇所にする
- 未実装の`RoomId`へ遷移しない
- 遷移時に戦闘用攻撃判定、弾、エフェクト、バナーを次の部屋へ持ち越さない
- HP、MP、経験値、操作中キャラは維持

今回は大きなステージマネージャ、イベントスクリプト言語、セーブデータ層を追加しない。

## 2. 苔の回廊の定義

`src/stage/roomDefinitions.ts`へ`MOSS_CORRIDOR`を追加し、`STAGE_ROOMS`へ正式登録する。

推奨値：

```ts
export const MOSS_CORRIDOR: StageRoomDefinition = {
  id: "mossCorridor",
  name: "晶界・苔の回廊",
  bounds: { left: 58, top: 52, right: 582, bottom: 322 },
  spawn: { x: 320, y: 292 },
  obstacles: [
    { kind: "rect", left: 58, top: 52, right: 238, bottom: 102 },
    { kind: "rect", left: 402, top: 52, right: 582, bottom: 102 },
    { kind: "rect", left: 58, top: 120, right: 118, bottom: 214 },
    { kind: "rect", left: 522, top: 120, right: 582, bottom: 214 },
    { kind: "circle", x: 190, y: 224, radius: 18 },
    { kind: "circle", x: 452, y: 204, radius: 20 },
  ],
  exits: [
    { direction: "south", target: "transferChamber", locked: false },
    { direction: "north", target: "luminousGarden", locked: true },
  ],

```

敵スポーンやクリアフラグを`StageRoomDefinition`の汎用型へ無理に追加しない。今回は第1エンカウント用の小さな定数または状態として保持する。

## 3. 転送の間の門を開ける

現在の中央クリスタル調査を、北門解放の一度きりイベントにする。

### 初回の中央クリスタル調査

1. 現在のメッセージを表示

```text
「クリスタルの奥から、森の鼓動が聞こえる……」
```

2. 短いクリスタル発光と小さな地面波紋
3. 0.5〜0.8秒後に門の根がほどける
4. バナー：

```text
北門の封印が解けた
```

実装を単純にするため、メッセージを2枚の会話ウィンドウで連続表示する必要はない。既存バナーとEffectPoolを再利用する。

解放後：

- 門の根と発光表現を「開いた状態」に変える
- 北門の中央通路を通行可能にする
- 近づくと`苔の回廊へ`を表示
- `E`で苔の回廊へ遷移
- すでに解放済みならクリスタル調査を繰り返してもイベントを再生しない

門解放状態はページ再読み込みまで保持でよい。`localStorage`やセーブに入れない。

## 4. 部屋遷移演出

固定画面式のレトロアクションRPGらしく、短い暗転で切り替える。

- `E`で門を通る
- 0.18〜0.25秒のフェードアウト
- 暗転中に部屋、衝突定義、スポーン位置、敵を更新
- 0.18〜0.25秒のフェードイン
- 遷移中は移動、交代、攻撃、ポーズ以外の決定を受け付けない
- 新しいページやCanvasを作らず、現在のCanvas上で行う

入室時は上部に短く表示：

```text
晶界・苔の回廊
```

フェード用に巨大な画面トランジション管理クラスは作らない。現在の`GameWorld`、`Renderer`、または小さな遷移状態で実装する。

## 5. 転送の間へ戻る出口

苔の回廊の南端で`E`を押すと、転送の間の北門内側へ戻る。

- 門解放状態は維持
- モスプルン未撃破中は戦闘を放棄して戻れない
- 敵に発見される前は戻ってよい
- 撃破後も戻ってよい

苔の回廊から戻った場合の転送の間スポーンは北門の手前とし、中央台座内や壁内に出ない。

## 6. 苔の回廊の描画

新規ファイル：

```text
src/render/rooms/MossCorridorRenderer.ts
```

描画順：

1. 暗い晶界背景
2. 縦に続く古い石の回廊
3. 転送の間より不規則で小さい床石
4. 左右の崩れた石壁
5. 壁から張り出す木の根
6. 苔、小さな草、落ち葉
7. 青緑色の小型クリスタル
8. 南の転送の間へ戻る門
9. 北のまだ開かない根の門
10. キャラ・敵と重なる手前の根や草

見た目：

- 限られた16ビット風パレット
- 暗緑、苔緑、青緑の晶石、湿った灰色の石
- 中央は3人の戦闘を見分けられる広さを確保
- 左右の張り出しで「回廊」らしさを出すが、モスプルン戦の回避空間を狭くしすぎない
- 中央よりやや北側にモスプルンが待機する空地を作る
- 床のノイズは`hash2d()`など固定値を使い、毎フレーム変化させない

## 7. モスプルン3体の初エンカウント

最初の戦闘はモスプルン3体にする。ただし、3体が一斉にプレイヤーへ密着する団子状態を避け、初戦として落ち着いて戦える配置とAI運用にする。

推奨スポーン：

```ts
createEnemy(1, "mossPlun", 320, 154)
createEnemy(2, "mossPlun", 220, 190)
createEnemy(3, "mossPlun", 430, 202)
```

- 3体の初期位置を十分に離す
- 中央の1体が最初に気づきやすい配置にする
- 左右の2体は壁、根、障害物の中へ置かない
- スポーン後の最小距離を確保する

初期状態：

- 入室直後は3体のモスプルンがそれぞれの位置で寝息のようにゆっくり上下する
- 未発見の間は追跡、攻撃予約、攻撃を行わない
- プレイヤーは1人表示のまま近づく
- いずれか1体とプレイヤーの距離が約115px以内になると、部屋の3体が発見状態に入る

発見演出：

1. 最初に気づいたモスプルンの頭上に`!`を約0.35秒
2. 短いヒットストップに似た0.12〜0.18秒の間
3. `beginStageCombat()`を呼ぶ
4. 後方2人が安全な陣形位置へ展開
5. バナー：`モスプルンの群れが現れた`
6. バトルBGMへフェード切り替え
7. 0.6〜0.9秒の開始猶予後にモスプルンAIが動き出す

戦闘中の要件：

- 既存の敵攻撃トークンと間合い制御を必ず使う
- 原則として攻撃動作に入るのは同時に1体まで
- 残りの2体は待機・再配置し、プレイヤーの同じ座標へ一斉に押し寄せない
- 敵同士の分離を維持し、スプライトが完全に重ならない
- 一方向だけでなく、中央と左右に緩く分かれる
- モスプルンの能力値や攻撃力は現在の実装を変えない

発見後は南門と北門を一時的に戦闘封鎖する。門から戻って戦闘をリセットできないようにする。大きな戦闘結界エフェクトは不要。門の小結晶が強く光る程度でよい。

モスプルンの数値、AI、攻撃モーション、攻撃判定、ドロップ率は現在の実装を再利用し、初戦用にハードコードした別敵を作らない。

## 8. 初戦用チュートリアル表示

戦闘開始時のみ、画面下部またはバナーに短く表示：

```text
J 通常攻撃　・　Space キャラ交代
```

要件：

- 戦闘を長時間停止しない
- 現在のアクション欄を見れば分かる程度の補助にする
- 実機がタッチ入力なら、キー文字列ではなく`通常攻撃　・　キャラ交代`と表示する
- 今回は説明ダイアログ、手の指アイコン、強制操作を追加しない

## 9. 撃破と戦闘終了

3体のモスプルンをすべて倒したら、現在の経験値・ドロップ処理を終えてから戦闘を終了する。

1. 現在の撃破エフェクト、`EXP +数値`、ドロップが発生
2. 0.7〜1.0秒待つ
3. バナー：`戦闘終了`
4. `endStageCombat()`を呼ぶ
5. 操作キャラ以外の2人を非描画・非衝突へ戻す
6. 戦闘封鎖を解除
7. 探索BGM「森晶遺跡の静寂」へ戻す

ステージ戦闘では敵が0体になっても、アリーナ用の`cleared`オーバーレイを出さない。ゲームの`phase`は`playing`を維持し、探索へ戻る。

撃破済み状態はページ再読み込みまで保持する。

- 撃破後に転送の間へ戻って再入室してもモスプルンを再スポーンしない
- 再読み込した場合は再び初戦を遊べてよい
- 今回はセーブデータを追加しない

## 11. HUD

- AREA：`晶界・転送の間`
- TRIAL・ENEMY表示なし

- AREA：`晶界・苔の回廊`

- ENEMY表示を非表示に戻す

## 12. SFXとBGM

新しい音声ファイルは追加しない。

- 門解放：既存のクリスタル系またはUI系SFXを小さく再利用
- 敵発見：既存のUI系の短い音を再利用してよい
- 戦闘開始：`partyPresence` becoming `formation`でバトルBGM
- 戦闘終了：`partyPresence` becoming `solo`で探索BGM
- 部屋遷移で探索BGMを最初から再読み込まない

戦闘開始・終了のたびに曲が二重再生されないこと。

## 14. テスト

最低限、次を追加・更新する。

### 部屋定義・遷移

- `MOSS_CORRIDOR`が`STAGE_ROOMS`に登録される
- 南出口は`transferChamber`、北出口はロック中の`luminousGarden`
- 中央クリスタルの初回調査で北門が開く
- 開門前は苔の回廊へ遷移できない
- 開門後は苔の回廊へ遷移できる
- 遷移後の操作キャラは安全な南スポーンへ配置される
- HP、MP、EXP、操作キャラが遷移で維持される

### 初エンカウント

- 入室時はモスプルン3体が十分に離れた位置で未発見待機
- 発見距離外では戦闘が始まらない
- 発見距離内で`partyPresence` becoming `formation`
- 発見猶予中にモスプルンの攻撃判定が出ない
- 攻撃トークンにより3体が同時に攻撃しない
- 3体が同じ座標へ集まって団子状態にならない
- 戦闘中は出口を使えない
- 撃破後は`partyPresence` becoming `solo`
- 撃破後はステージの`phase` becoming `playing`のまま
- 再入室で撃破済みモスプルンが復活しない

### BGM・回帰

- 未発見と撃破後は`exploration`
- 戦闘中は`battle`
- ポーズ後に正しい曲の続きが再生される
- アリーナの敵数、クリア、次波、BGMが変わらない

最後に実行：

```bash
npm test
npm run build
```

## 15. 画面確認

1. 転送の間で中央クリスタルを調べ、北門が開く
2. 門を調べ、暗転後に苔の回廊へ入る
3. 入室時は操作キャ1人と、離れて待機するモスプルン3体が表示される
4. 近づくと`!`が出て、他の2人が後方に展開する
5. BGMが探索曲からバトル曲へ切り替わる
6. 3体が現在のジャンプ攻撃で戦うが、原則と1体ずつ攻めてくる
7. 3体すべてを撃破するとEXPが加算され、他の2人が非表示に戻る
8. BGMが探索曲へ戻る
9. 南門から転送の間へ戻れる
10. 苔の回廊へ再入室しても、モスプルンは復活しない
11. 北門は「光羽の庭」の予告までで、まだ進めない
12. `?mode=arena`で従来のバトルを遊べる
