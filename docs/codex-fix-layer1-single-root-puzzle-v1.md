## 現状コードで確認した原因と参照箇所

- `src/game/GameWorld.ts` の第1層インタラクト処理では、石碑が `mossMonumentActivate` → `hiddenRoomUnlocked` を操作する。クリスタルは別に `mossCrystalActivate` → `northGateUnlocked` を操作する。
- `src/render/stages/MossRootRuinsRenderer.ts` は `drawAncientMonument()` と `drawHiddenRoomRootGate()` を追加描画している。`drawRootGate()` が残すべき大きな根、`drawTransferCrystal()` が残すべきクリスタル。
- `src/stage/tileCollision.ts` の `isMossRootPositionWalkable()` は足元一点の赤線マスクだけを見て `options.gateOpen` を無視する。そのため、見た目の根が閉じていても足元が赤枠内なら通れる。旧テストには閉じた根を通過できることを期待するものまである。
- `src/stage/maps/mossRootRuinsMap.ts` に根の中心・見た目・既存の衝突用寸法 `MOSS_ROOT_GATE_TRANSFORM` がある。これを出発点として、実際の絵の根元・通路幅と整合する閉鎖領域を定義する。

## 実装要件

1. 石碑と隠し部屋用障害物の**追加描画・プレイヤー向けインタラクト・解除演出**を外す。背景に元からあるアーチや岩の画像は加工しない。石碑の小さな前景オーバーレイと不要な障害物が見えなくなること。不要になった状態、QA操作、テスト、文言は参照関係を確認して整理する。他階層の石碑・隠し部屋機能は変更しない。
2. 右広場のクリスタルと北側の大きな根の見た目・解除演出は維持する。クリスタルに触れる前と開放アニメーション中、根の足元領域は通れない。根が十分に引いた後、`northGateUnlocked` と通行可を一致させる。視覚的にまだ塞がっている間だけ先に通れる状態は作らない。
3. 第1層の歩行判定を「赤線内の足元一点」**かつ**「閉じた北側の根の障害領域外」とする。赤線の外を通す例外、キャラクターの全身円判定への逆戻り、赤線画像やマスクの膨張は行わない。戦闘用の当たり半径も変えない。
4. 移動線分の検査にも動的な根の障害領域を反映し、速い移動・斜め移動・ノックバックで根を跨げないようにする。横へ回り込める隙間が赤線内にないか、クリスタル未解除の状態で入口側から奥側への到達性を検査する。根の当たり領域は絵と通路に沿わせ、周囲の無関係な床を過剰に塞がない。
5. 解除後は根の場所を狭い通路も含めて足元一点で通れる。追従キャラや敵も開閉状態に対して不自然な通り抜け／閉じ込めがないことを確認する。

## 必須の回帰・受け入れテスト

- 石碑の位置で `E` を押しても新しい仕掛けや隠し部屋の開放が起きない。不要な小石碑・板状障害物が画面から消えている。
- 右広場のクリスタルには通常操作で到達・接触でき、そこで唯一の根の解除が始まる。
- 解除前に `MOSS_ROOT_GATE_TRANSFORM.approach` から `beyond` へ通常歩行、高速移動、斜め移動を試しても越えられない。反対側からも閉じた根を横断できず、両端を回り込む抜け道がない。
- 解除アニメーション中も絵と当たり判定の状態が一致する。解除後は同じ経路を通れ、最終広場へ進める。
- 既存の `mossRootRequiredRoute` は静的マスクの確認として維持できるが、「クリスタル未解除でも最後まで移動できる」という旧テストは直す。クリスタルまでは閉鎖状態で移動、解除後は根の向こう・最終広場まで**実際の移動処理**で到達するテストにする。
- 赤線外・崖への逸脱防止、狭い通路、他階層、戦闘に回帰がない。`npm run typecheck`、`npm test`、`npm run build` を通す。
