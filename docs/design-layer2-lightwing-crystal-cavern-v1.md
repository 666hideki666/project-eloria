# 第2層「光羽の晶洞」構成案 v1

## 層の役割

第1層「苔根の遺構」で覚えた基本操作を使いながら、飛行する敵、水路、橋、遠回りする経路を学ぶ層。

- 第1層：縦横に広がる森の遺跡、モスプルン中心
- 第2層：横長の晶洞、左から右へ進行、ルミバネ中心
- 推奨攻略キャラクター：ナディ
- 想定テーマ：飛行敵へ広範囲攻撃を当てる楽しさ
- ボスはこの層には置かず、第1ダンジョン全体の最終層に守護者を置く

## マップの基本形

- 横長ワールド
- 仮サイズ：2304×1344
- ビューポート：640×360を維持
- タイル：32px
- グリッド：72列×42行
- 開始地点：左端
- ゴール：右上寄り
- 一直線では進めず、上下を3回以上往復する
- 大きな地底湖と穴で中央を分断
- 橋、浅瀬、晶石足場を使いながら進む

進行イメージ：

```text
左端・入口
→ 下層の水辺
→ 上側の飛行戦広場
→ 中央晶石装置
→ 下側へ迂回
→ 混成戦広場
→ 出現した晶石足場で地底湖を横断
→ 右上の光羽広場
→ 第3層への門
```

## エリア構成

### A. 第1層からの入口

- 左端の小さな円形広場
- 第1層の門から到着
- 最初は操作キャラクター1人
- 地底湖の反射光と遠くを飛ぶ羽影を見せる
- 最初の敵は画面内へ置かない

### B. 水晶の浅瀬

- 浅い水と石床が入り混じる探索区間
- 水は歩けないが、石床が蛇行する
- 小型晶石を目印に進む
- ルミバネ1体が遠くから近づき、飛行敵の導入戦になる
- 初戦なので広い場所を確保

### C. 光羽の吹き抜け

- 上側にある大きな戦闘広場
- ルミバネ3体の必須戦
- 崖と水路に囲まれているが、戦闘封鎖は使わない
- 元の道へ戻れば逃走できる
- 広場中央の装飾密度を下げ、ナディの月輪刃を見やすくする

### D. 中央晶石装置

- 層の主要ギミック
- 地底湖の向こうに浮いている複数の晶石足場と連動
- 近づくと「晶石の奥で光が脈打っている」
- `E　晶石に触れる`
- 操作すると湖上に足場が順番に出現
- ただし最短ルートはまだ完成せず、反対側の副晶石も必要

### E. 崩れた橋の行き止まり

- 任意探索区間
- 壊れた橋の先に将来の宝箱台座
- ルミバネ2体の任意戦
- 現段階では橋の一部がなく、先端の台座までのみ進める
- 後の追加開発でアイテムを置ける

### F. 青水路の下道

- 中央装置から下へ大きく迂回する必須ルート
- 滝、浅い水路、低い晶石柱
- 狭く見えるが通路幅は96〜128px
- 戦闘を置かず、景色と移動の区間にする
- 途中に第1層へ戻るショートカット候補は作らない

### G. 混成戦広場

- モスプルン2体＋ルミバネ2体
- 第2層の中盤必須戦
- 地上敵と飛行敵の優先順位を学ぶ
- ナディでまとめて攻撃、カイルで地上敵を処理、メルで回復という役割を体感
- 広場は横長で、上下に逃走路を確保

### H. 回復の晶泉

- 混成戦後の静かな小部屋
- 第1層の泉と同じ回復機能
- 見た目は水の泉ではなく、天井から落ちる晶光が水面へ集まる形
- HP、MP、戦闘不能を回復
- 探索BGMは継続

### I. 副晶石装置

- 回復地点の先
- 操作すると中央装置と共鳴し、湖上の足場がすべて接続
- 遠くで複数の晶石が順番に光る演出
- 出現後は地底湖を横断できる
- 一度出現した足場はそのプレイ中は維持

### J. 晶石足場の横断区間

- 地底湖上を右へ渡る
- 足場幅は最低96px
- 落下システムは今回は実装しない
- 足場外は通常の衝突で進入不可
- 足場上で敵を出さない
- 青い光が進行方向を示す

### K. 光羽の巣

- 右上の大きな最終戦広場
- ルミバネ4体の必須戦
- 一斉突撃させず、攻撃役は1〜2体に制限
- 上空待機、旋回、接近攻撃を混ぜる
- ナディの広範囲攻撃が有効だと明確に感じられる調整
- 逃走時は晶石足場側へ戻れる

### L. 第3層への門

- 光羽の巣の奥
- 最終グループ撃破で門の晶石が点灯
- 第3層の雰囲気を少し見せる
- 次層の敵はまだ出さない

## 敵配置案

合計14体。

| グループ | 構成 | 必須 | 場所 |
| --- | --- | --- | --- |
| `lightwingIntro` | ルミバネ1体 | 必須 | B：水晶の浅瀬 |
| `lightwingDraft` | ルミバネ3体 | 必須 | C：光羽の吹き抜け |
| `lightwingDeadEnd` | ルミバネ2体 | 任意 | E：崩れた橋 |
| `mixedChannel` | モスプルン2体＋ルミバネ2体 | 必須 | G：混成戦広場 |
| `lightwingNest` | ルミバネ4体 | 必須 | K：光羽の巣 |

第1層の10体より少し増やすが、マップが広いため通路には敵を敷き詰めない。

## ルミバネの戦闘特性

- 地上敵より移動が速い
- 常に突進せず、一定距離で旋回する
- 攻撃権を持つ個体だけが接近
- 攻撃前に羽が明るくなる
- 攻撃後は一度距離を取る
- 穴や水路の上を通過できる
- プレイヤーは地形越しに一方的に攻撃されないよう、攻撃開始距離と追跡範囲を制限
- 逃走判定は地上敵と同様に機能

## 晶石足場ギミック

状態案：

```ts
primaryCrystalActivated: boolean
secondaryCrystalActivated: boolean
crystalPathUnlocked: boolean
```

- 中央晶石のみ：一部足場が光るが未接続
- 副晶石のみ：単独では起動しない
- 両方作動：湖上の全足場が接続
- 作動済み装置は色と発光で判別
- 足場出現中は敵AIを止めず、そもそも装置周辺を非戦闘区域にする
