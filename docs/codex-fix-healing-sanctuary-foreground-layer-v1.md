# Codex向け修正指示：回復晶泉の前景レイヤー修正 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Luna`
- 推論レベル：`High`
- 理由：局所的な描画順・前景マスク修正であり、マップ全体の再設計は不要なため。

## 1. 症状

第2層「光羽の晶洞」の回復晶泉で、操作キャラクターが祭壇の手前へ立った際、祭壇前縁または段差表現がキャラクターより前へ広く描画される。

添付スクリーンショットでは、ナディの上半身が段差に隠れ、頭上マーカーと下半身だけが見える状態になっている。

## 2. 原因として確認する箇所

- 回復晶泉の前景パーツが、祭壇全体を覆う大きな矩形として描画されていないか
- 前縁の `foreground` / `overlay` / `upper layer` の高さやクリップ領域が過大でないか
- キャラクターとのY座標ソートをせず、常にキャラクターの後に描画していないか
- 見た目の段差位置と、前景へ切り替える基準Y座標が一致しているか

## 3. 修正方針

回復晶泉を次の3層に分ける。

1. 背景層
   - 湖面
   - 祭壇床面
   - 奥側の石組み
   - 回復紋様
   - キャラクターより先に描画する

2. ワールドオブジェクト層
   - 浮遊晶石
   - 光柱
   - キャラクターとの位置関係を壊さない既存の描画順を維持する

3. 前景層
   - 祭壇の最手前にある縁の厚みだけ
   - 前景マスクは見た目の縁と同じ高さに限定する
   - キャラクターの足元が縁の奥側へ入った場合に、靴先または下腿の一部だけが隠れる程度にする
   - 胴体、頭、頭上マーカーを隠さない

## 4. 必須要件

- 現在キャラクターを覆っている大きな前景矩形を廃止または縮小する
- 前景の高さは祭壇前縁の実ピクセル高に合わせる
- キャラクターが祭壇の手前、中央、左右端へ立っても上半身が隠れない
- 晶泉へ近づいた際の `E 回復の晶泉に触れる` 表示を維持する
- 回復処理、回復演出、効果音、使用回数・状態管理を変更しない
- 晶泉、主晶石、副晶石、敵、壁の衝突判定を変更しない
- マップ構図と晶泉の大きさを変更しない

## 5. 推奨実装

- 祭壇のベース描画と前縁描画を別関数または別パスに分離する
- 前縁overlayを使う場合、祭壇全体のbounding boxではなく手前縁専用の細い矩形にする
- ワールドYソートが既にある場合は、前縁の基準Yを見た目の接地線へ合わせる
- 固定順描画の場合は、背景 → キャラクター → 細い前縁overlay の順にする

## 6. 視覚QA

次の位置へ各キャラクターを立たせて確認する。

1. 祭壇正面中央
2. 正面左端
3. 正面右端
4. 祭壇の真横
5. 晶泉のインタラクト可能距離ぎりぎり

確認対象：

- カイル、ナディ、メルの頭・胴体が常に見える
- 前縁の奥へ入った足だけが自然に隠れる
- 頭上の操作キャラマーカーが隠れない
- 移動中に前景が点滅しない
- キャラ交代時にも描画順が変化しない
- 回復演出中にもキャラクター全体が不自然に消えない

## 7. 回帰確認

- `npm run typecheck`
- `npm test`
- `npm run build`
- 第2層へ入り、晶泉の利用前・利用中・利用後を通常プレイで確認する

## 8. スコープ外

- 回復晶泉の再デザイン
- マップ配置変更
- 敵配置変更
- 回復仕様変更
- 第1層および第3層の変更

今回の修正は、祭壇前縁の描画範囲と描画順だけを直す局所修正とする。
