## 赤線レビュー結果と確認待ち

- 南端の通路から中央広場、北側の階段と祭壇まで、一つの連続領域になっている。
- 手前左右の結晶柱の台座は赤線が回り込んでおり、台座中心は歩行範囲外。周辺の床は歩ける。
- 北側祭壇の床と階段は歩行範囲内。祭壇の背後にある根・結晶は範囲外。
- 左の赤線は画像下端の **(618, 1045)** 付近で終わり、画像端まで約5 pxだけ届いていない。確認用オーバーレイでは **(618, 1045)→(618, 1050)** の線だけを仮に補って塗りつぶした。ここを画像端までつなぐ扱いについて、ユーザー確認を得てから実装用マスクに確定する。右側は画像下端へ達している。
- 赤線抽出の確認では、上記の局所補完とアンチエイリアス対策の1 px程度の線幅処理で内側約435,635ソース画素を抽出した。この画素数はレビュー用の目安であり、実装用マスクを無検証で固定する値ではない。

## 実装範囲（承認後）

1. 既存の `crystalAltar` ボス部屋の仮タイル背景を、上記承認画像に置き換える。背景の縦横比を変えずに描く。二重の床・壁・仮祭壇・仮入口装飾は残さない。ボス、封印石、攻撃エフェクト、UIは引き続き個別レイヤーで描く。
2. 赤線画像を背景ネイティブ座標で抽出し、内側を静的な床マスクにする。広場、階段、南入口の床を含める。赤線外の見た目が歩けそうな箇所を勝手に足さない。赤線を全体的に膨張・再描画しない。
3. 背景座標とワールド座標の対応を単一の変換にまとめる。旧 **800×576 px／25×18タイル** の位置値を流用して背景を非等方に引き伸ばさない。入口・退路、登場演出開始点、ボス休眠／戦闘位置、北祭壇、封印石、カメラ範囲、攻撃範囲・移動先を新座標で再点検する。
4. プレイヤーと仲間は足元の接地点 `pos` 一点で静的床マスクを判定する。ヴェルグランも地面上の移動点を静的床内に保ち、戦闘用の当たり半径を床判定へ流用しない。ボスが入口の細い通路や祭壇の階段へ不自然に入り込まないよう、既存の戦闘行動範囲は別に制限できる。
5. 移動終点だけでなく、移動線分が通るマスクセルを検査する。歩行、斜め移動、仲間追従、ボス移動、ノックバック、演出移動、ワープ／部屋遷移で赤線外へ抜けないようにする。戦闘中も南入口から第3層へ撤退できる。
6. 赤線内の床でも立体物は必要なら**別の物体コライダー**で扱う。左右の結晶台座、北祭壇上の封印石、ヴェルグラン本体の接触処理などを床マスクの改変で表現しない。階段や中央の床紋様は通行を妨げない。
7. 従来のボス戦の内容、登場・撤退・再戦・鎮静・封印石取得・クリア処理を保持する。画像置換のために挙動や難易度を無断変更しない。

## 検証条件

- 元画像と赤線とマスクの1496×1051ソース座標を照合したオーバーレイを残す。補完箇所とマスク差分も確認する。
- 第3層の門から入場し、南入口→中央広場→北階段→祭壇に、実際のゲーム移動で到達できる。仲間と演出配置も床内に収まる。
- 左右の結晶台座周り、外周の根・壁・奈落、南入口外側、北祭壇の背後を歩けない。高速・斜め・ノックバックでも赤線を越えない。
- ヴェルグランが中央で移動・攻撃・帰還し、壁や祭壇へめり込まず、攻撃予兆とキャラの視認性を維持する。
- ボス戦中の南撤退、再入場時の再戦、撃破後の北祭壇／封印石到達とクリア演出をブラウザで確認する。
- 型チェック、関連テスト、全テスト、ビルドを実行する。検証用ブラウザ／サーバーを終了し、BGMが残らないようにする。
