## マップ制作で確立した方法（全層共通）

1. 背景マップ画像を先に作り、ユーザーと絵柄・ルート・仕掛けの位置を確認する。見た目の石畳・苔・階段から自動的に歩行可否を推測しない。
2. ユーザー自身が背景画像上に赤線で歩行範囲を囲む。**赤線の内側が歩行可能、外側は不可**。線の修正や通路の補完は承認なく行わない。
3. 赤線と背景の原寸座標を揃えた二値マスクを作り、背景との重ね図と必要なら新旧差分図で確認する。
4. 判定するのはキャラクターの**足元一点 `pos`**。上半身・影・靴の絵が境界に少し重なるのは許容する。戦闘の当たり半径と歩行判定を混同しない。
5. 高速・斜め移動で細い禁止領域を飛び越えないよう移動線分を検査する。プレイヤーだけでなく追従者、敵、ノックバック、スクリプト移動、ワープも確認する。
6. スポーンから重要地点・仕掛け・出口まで、実際の操作で通れることと、崖・水・通路外へ出られないことを検証する。マスク上の連結だけで完了としない。

詳しい根拠・チェックリストは `AGENTS.md` と `docs/map-walkability-redline-handoff.md`。動的な根、結晶台座、門、橋などの物体・ギミック判定は静的床マスクと別扱いにする。
