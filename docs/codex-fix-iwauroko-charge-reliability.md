# Codex向け修正指示：イワウロコの「岩甲突進」を実戦で当たる攻撃にする

Project Eloriaのイワウロコは「岩甲突進」のモーションを再生しますが、通常プレイでは空振りが多く、攻撃してこないように見えます。専用画像とモーションは変更せず、突進挙動と接触判定を修正してください。

## 現在の原因

現在の実装では次の条件が重なっています。

- `windup`開始時、1.15秒前のプレイヤー位置へ攻撃方向を固定する。
- 実際に前進する`attack`時間は0.42秒だけ。
- ダメージは更新後のイワウロコ中心とキャラクター中心が直接重なった場合だけ。
- 高速移動の前後を結ぶ軌道上は判定していない。

静止したキャラクターには既存テスト上で30ダメージが通りますが、実プレイで少し移動すると古い位置へ突進して外れやすくなっています。

## 修正方針

「予兆を見て避けられる重い体当たり」は維持します。

1. 突進開始時に最大12度だけ方向補正する。
2. 突進時間を0.42秒から0.55秒へ延長する。
3. 1フレーム前後の移動軌道を使った連続接触判定へ変更する。
4. 接触したら、ダメージの成否にかかわらず制動へ入る。

追尾攻撃や円形攻撃にはしないでください。

## 1. イワウロコ専用定数

`config.ts`へ専用定数を追加してください。

```ts
export const IWAUROKO_ROCK_ARMOR_CHARGE = {
  attackDuration: 0.55,
  attackSpeedRatio: 2.15,
  maxAimCorrectionRadians: Math.PI / 15,
  collisionPadding: 6,
} as const;
```

`Math.PI / 15`は12度です。

共有`heavyCharge`は将来ほかの敵が利用できるよう、数値を直接変更しないでください。イワウロコだけこの定数を使用します。

維持する値：

- `windupDuration: 1.15`
- `recoverDuration: 1.3`
- HP132
- 岩鱗42
- ダメージ30
- クールダウン2.7秒
- 経験値28

## 2. 突進開始時の限定的な方向補正

予兆開始時に保存した`enemy.attackDirection`を基準にします。`beginEnemyAttack()`でイワウロコの攻撃が始まる瞬間だけ、現在の対象方向へ最大12度回してください。

必要な挙動：

- 0〜12度のずれ：現在の対象方向へ合わせる。
- 12度を超えるずれ：保存方向から対象側へ12度だけ回す。
- 攻撃開始後は方向を更新しない。
- 毎フレーム追尾しない。
- 180度反転しない。
- ゼロベクトルとNaNを発生させない。

小さな純粋関数として、角度差を`[-Math.PI, Math.PI]`へ正規化し、最大角度でクランプしてください。

```ts
enemy.attackDirection = rotateDirectionToward(
  enemy.attackDirection,
  normalize(sub(target.pos, enemy.pos), enemy.facing),
  IWAUROKO_ROCK_ARMOR_CHARGE.maxAimCorrectionRadians,
);
enemy.facing = { ...enemy.attackDirection };
```

この補正はイワウロコだけへ適用します。モスプルン、ルミバネ、ガラクロウ、ウツロボウの方向固定処理は変更しません。

## 3. 突進時間

`beginEnemyAttack()`でイワウロコのみ次を使います。

```ts
IWAUROKO_ROCK_ARMOR_CHARGE.attackDuration
```

`updateEnemyAttack()`の速度選択でもイワウロコのみ次を使います。

```ts
IWAUROKO_ROCK_ARMOR_CHARGE.attackSpeedRatio
```

突進時間は0.55秒、速度比は2.15です。速度を上げるのではなく、前進時間を少し延ばします。

## 4. 移動軌道を使った連続接触判定

現在は移動後の`enemy.pos`だけで距離判定しています。高速移動でキャラクターを飛び越えないよう、次の区間を判定してください。

```text
previousPos -------- nextPos
```

`updateEnemyAttack()`の移動前位置を保存します。

```ts
const previousPos = { ...enemy.pos };
```

イワウロコの`heavyCharge`判定では、キャラクター中心から`previousPos`〜`enemy.pos`線分への最短距離を求めます。

判定半径：

```ts
enemy.radius +
member.radius +
IWAUROKO_ROCK_ARMOR_CHARGE.collisionPadding
```

線分最近点の計算は純粋関数へ分離してください。

```ts
function distancePointToSegment(
  point: Vec2,
  start: Vec2,
  end: Vec2,
): number
```

要件：

- 線分長がほぼゼロでも安全に通常距離を返す。
- 最近点の係数を0〜1へクランプする。
- 平方距離を利用してもよい。
- イワウロコ以外の攻撃判定を変更しない。

## 5. 接触とダメージ成功を分離

キャラクターが無敵時間中の場合、`damageCharacter()`が`false`を返しても、イワウロコは身体へ衝突したものとして制動へ入る必要があります。

次を分けて扱ってください。

- `chargeCollided`：物理的に接触した。
- `enemy.attackConnected`：今回の接触処理を消費した。

接触時：

1. `damageCharacter()`を1回だけ呼ぶ。
2. 戻り値にかかわらず`enemy.attackConnected = true`にする。
3. 同じフレームでほかのパーティメンバーへ連続ダメージを与えない。
4. `enterEnemyRecovery()`へ入り、制動フレームを開始する。

戦闘不能キャラクターは従来どおり判定対象外です。

## 6. アニメーション時間

設定ファイルを更新します。

対象：

`assets/sprites/enemies/iwauroko/attacks/iwauroko-rock-armor-charge-48px-v2.json`

`attack`を合計0.55秒へ変更してください。

```json
"attack": {
  "framesWithinDirection": [2, 3],
  "frameDurationsSeconds": [0.25, 0.3],
  "loop": false
}
```

画像PNG、`windup`1.15秒、`recover`1.30秒、`drawScale: 0.94`、`anchor.y: 0.82`は変更しません。

壁またはキャラクターへ早く接触した場合は、これまでどおりすぐ`recover`のフレーム4へ移行します。

## 7. 予兆の公平性

方向補正が見えない不意打ちにならないよう、`windup`の最後0.18秒だけ既存の予兆方向表示を補正後の方向へ滑らかに寄せても構いません。ただし必須ではありません。

禁止事項：

- 攻撃中の追尾
- 12度を超える方向補正
- キャラクター位置への瞬間移動
- 半径の大きな円形ダメージ
- 画面端を越える移動

既存の`clampToArena()`と壁衝突終了を維持してください。

## 8. エフェクトと接地

現在の専用画像とエフェクトを維持します。

- 溜め時の砂埃2個
- 突進中の短い砂埃最大3個
- 接触・壁衝突後の砂埃8個
- 接地影
- `anchor.y: 0.82`
- 岩鱗ゼロ時の破壊後フォールバック

ジャンプ、浮遊、追加の岩飛散、大きな画面揺れは追加しません。

## 9. テスト

既存テストを更新し、次を追加してください。

### 時間と速度

- イワウロコの攻撃時間が0.55秒。
- 速度比が2.15。
- 共有`heavyCharge.attackDuration`は0.42秒のまま。

### 方向補正

- 8度のずれは対象方向へ補正される。
- 30度のずれは12度だけ補正される。
- 攻撃開始後に対象が移動しても方向は変化しない。

### 軌道判定

- 更新前後の位置の中間にキャラクターがいる場合、移動後中心が通り過ぎても1回命中する。
- 軌道から判定半径より外れたキャラクターには命中しない。
- 1回の突進で複数回ダメージを与えない。
- 無敵中のキャラクターへ接触してもダメージは増えず、イワウロコは回復へ入る。

### 実戦条件

通常配置から静止した操作キャラクターに対し、15秒以内に少なくとも一度、30ダメージを与える統合テストを追加してください。

最後に実行します。

```bash
npm test
npm run build
```

## 完了条件

- イワウロコが予兆後、プレイヤーへ向かって明確に前進する。
- 少し動いただけで毎回空振りする状態にならない。
- 予兆を見て大きく横へ避ければ回避できる。
- 高速移動でキャラクターをすり抜けない。
- 接触時に30ダメージは1回だけ発生する。
- 無敵時間中の接触でも、イワウロコは制動へ移行する。
- 専用モーション、接地、岩鱗破壊表示、他の敵の攻撃へ意図しない変更がない。
