# Project Eloria 第1ステージ仕様書

## 1. ゲームの方向性

- ファミコン時代の見下ろし型アクションアドベンチャーを思わせる、オリジナル世界観のWebゲーム。
- 1人プレイを基本とし、3人パーティーを切り替えながら攻略する。
- タイムアタック、スコア、ランキングは採用しない。
- 楽しく遊びながらクリアを目指すアクションRPGとする。
- 第1ステージ「森の遺跡」は、大きなチュートリアル兼プロローグとして扱う。
- 経験値は最初から蓄積する。レベルアップ時の能力上昇は各キャラクターに適した自動成長を基本とする。
- 第2ステージ以降にレベル、装備、新キャラクター、アイテム所持などのRPG要素を追加できる設計にする。

## 2. 物語と舞台

カイル率いるトレジャーハンターチームが「森の封印石」を求め、星巡りの森にある古代遺跡へやってくる。

森の中央には封印された遺跡があり、その周囲には複数のクリスタル遺跡が存在する。最初に入れるクリスタル以外は不思議な力でパーティーを弾く。最初のクリスタルへ触れると、3人はクリスタル内部の記憶空間「晶界」へ吸い込まれる。

## 3. メインパーティー

### カイル

- 若い人間の旅人で、チームリーダー。
- 灰色の髪、軽装、青いスカーフ、片手剣。鞄は持たない。
- バランス型。単体攻撃、装甲破壊、前線維持を担当する。
- 通常攻撃：連刃剣
- 特殊技：破陣突き
- 大技：裂空断
- 交代攻撃：先陣斬り

### ナディ

- 月輪刃を扱う女性戦士。
- 広範囲攻撃、飛び道具迎撃、複数の敵や障害物の処理を担当する。
- 通常攻撃：月輪投げ
- 特殊技：円月旋
- 大技：月蝕乱舞
- 交代攻撃：輪光掃

### メル

- 杖を扱う女性魔法使い。
- 通常攻撃と耐久力は低いが、大技魔法と回復魔法を使える。
- 通常攻撃：燐光弾
- 特殊技：癒しの環
- 大技：天晶崩落
- 交代攻撃：瞬光障壁

## 4. 3人パーティーシステム

- プレイヤーは常に1人を操作する。
- 残り2人は後方メンバーとして陣形を取り、AIで追従する。
- 交代操作で操作キャラクターを順番に変更できる。
- 後方メンバーは通常攻撃のみ自動で行う。
- 後方メンバーの攻撃力は50%になる。
- 後方メンバーが受けるダメージは50%になる。
- メルが後方にいて味方のHPが少なくなると、MPがある場合に回復魔法を自動使用する。
- 後方から行う回復魔法の回復量は半減しない。

## 5. PC・モバイル操作

### PC初期設定

| 操作 | 初期キー |
| --- | --- |
| 移動 | WASD / 矢印キー |
| 通常攻撃 | J |
| 特殊技 | K |
| 大技 | L |
| キャラクター交代 | Space |
| 調べる・決定 | E / Enter |
| ポーズ | Esc |

- キー設定は将来的に変更可能にする。
- PC操作中は技アイコンへ対応キーを小さく表示する。

### モバイル方針

- 左側の移動領域を触ると、その位置にフローティングスティックを表示する。
- 指を離すと約0.5秒で薄くなって消える。
- 初回チュートリアルでは操作可能範囲を案内する。
- 設定でスティックを常時表示できるようにする。
- 右側の攻撃・特殊技・大技・交代ボタンは薄く常時表示し、操作時に明るくする。
- PC入力を検出した場合はタッチUIを非表示にし、タッチ入力を検出した場合はモバイルUIへ切り替える。

## 6. 戦闘不能と再挑戦

- 攻撃を受けると軽くノックバックする。
- 被ダメージ後は約1秒間無敵になり、キャラクターが点滅する。
- HPが0になったキャラクターは、その場で片膝をついて頭を下げる。
- 武器を地面へ下ろし、呼吸するような小さな待機アニメーションだけを行う。
- 戦闘不能中は敵から狙われず、攻撃判定や衝突判定を持たない。
- 操作キャラクターが戦闘不能になると、生存している仲間へ自動交代する。
- 戦闘不能キャラクターは、その戦闘が終わるとHP30%で復帰する。
- 3人全員が戦闘不能になるとゲームオーバー。
- 現在の部屋から再挑戦でき、HP・MPは全回復する。
- 再挑戦しても獲得済み経験値は失わない。
- 第1ステージでは専用の回避ボタンを設けず、敵の予兆を見て移動で避ける。

## 7. HUDと経験値表示

- 左上に3人の状態を縦に表示する。
- 操作中キャラクターの枠を大きく、明るく表示する。
- 後方2人は小さい枠でHPを表示し、メルはMPも表示する。
- メルの自動回復が使用可能な場合は、小さな回復アイコンを表示する。
- 右下に通常攻撃、特殊技、大技、キャラクター交代の4アイコンを置く。
- 経験値ゲージは通常画面へ常設しない。
- 敵を倒した位置に小さく `EXP +数値` を表示し、上へ浮かせながら約1秒で消す。
- 複数体を同時に倒した場合は、近いタイミングの経験値を合算してもよい。
- 現在の経験値はポーズメニューで確認する。
- レベルアップ時のみ画面上部へ通知する。
- タイム、スコア、コンボ、ランキングは表示しない。

## 8. 回復とドロップ

### 若葉の雫

- 春の若葉を内包した緑色の小さな雫。
- 近づくと自動取得し、最もHPが減っている仲間を少量回復する。

### 魔力の露

- 渦状の紋様を内包した青紫色の小さな雫。
- 近づくと自動取得し、メルのMPを少量回復する。

### 休息のクリスタル

- ボス前に置く、根と石台に支えられた淡い水緑色の大型クリスタル。
- 触れると一度だけ3人のHP、メルのMPを全回復し、戦闘不能キャラクターも復帰させる。
- 使用後は光を失い、そのステージ中は再利用できない。

第1ステージでは手動使用するポーション、アイテム欄、所持数管理を採用しない。

## 9. 第1ダンジョン構成

当初の「1部屋＝1画面」方式は廃止し、画面より広い連続マップをカメラが追従するスクロール方式を採用する。通常階層は探索感が出る程度の広さとし、ボス階は戦闘へ集中できる小さな専用エリアにする。

1. 第1層「苔根の遺構」：転送広場、苔の回廊、中央分岐、行き止まり、モスプルンの群れ
2. 第2層「崩れた晶洞」：光羽の庭、崩れ橋、ルミバネ、ガラクロウ
3. 第3層「霊布と石鱗の深層」：霊布の広間、石鱗の通路、ウツロボウ、イワウロコ、回復の泉、守護者の前室
4. ボス階「クリスタル祭壇」：森晶獣ヴェルグラン戦

第1層の暫定基準サイズは1280×1152とし、640×360のビューポートで歩いてテストする。広すぎる、または狭すぎる場合はプレイテスト後に調整する。

各階層にはメインルート以外に、行き止まり、ループ、近道、将来の宝箱候補、石碑、回復地点を置ける余白を用意する。

最終広間で通常敵5種類を混成させる総合戦は行わず、守護者戦へ進む。

## 10. 通常モンスター

- モスプルン：小型のスライム系。最初の基本戦闘を教える。
- ルミバネ：小型の飛行昆虫系。射程や位置取りを教える。
- ガラクロウ：やや大型の飛行系。崩れ橋で空中敵への対応を教える。
- ウツロボウ：石仮面を付けた浮遊霊。半透明状態には魔法が有効。
- イワウロコ：岩の装甲を持つ爬虫類。装甲破壊後に広範囲攻撃が有効。

## 11. ボス

### 森晶獣ヴェルグラン

- 森と晶界を守る聖なる守護獣であり、悪意のある怪物ではない。
- 巨大な四足獣で、苔、樹木、石装甲、枝角を持つ。
- 胸部に大きなクリスタルコアが埋め込まれている。
- カイルが前脚の石装甲を壊す。
- ナディが根や飛晶を広範囲攻撃で処理する。
- メルが露出した胸部コアへ遠距離魔法を当てる。
- 第1ボスなので戦闘は長引かせず、装甲破壊と転倒を2〜3回成功させれば倒せる。
- 攻撃予兆は長めにし、複数攻撃を同時に重ねない。
- HP半分後も新技を増やさず、動きが少し速くなる程度にする。

攻撃：

- 岩樹の踏砕：前脚を叩きつける。回避後は装甲を攻撃する好機になる。
- 根走り：予兆線に沿って根を突き出す。ナディで破壊可能。
- 晶片飛ばし：扇状に結晶片を飛ばす。回避またはナディで迎撃できる。

撃破後、ヴェルグランは消滅せず穏やかさを取り戻す。3人を認め、祭壇へ森の封印石を出現させる。

## 12. 攻撃エフェクト方針

- 通常攻撃は短く明快にし、操作レスポンスを優先する。
- 特殊技はキャラクター固有の色と形を強く出す。
- 大技は画面を派手に見せるが、敵や危険予兆を完全に隠さない。
- ヒット時に短いヒットストップ、軽い画面振動、火花や破片を組み合わせる。
- 大技中も長時間操作不能にせず、テンポを維持する。
- 点滅や画面振動を弱くできるアクセシビリティ設定を将来用意する。
- 星形の意匠は多用せず、斬撃、月輪、晶石、燐光、風、根、葉を中心にする。

### カイル

- 連刃剣：白銀色の短い斬撃弧と小さな衝撃火花。
- 破陣突き：前方へ伸びる鋭い青緑色の突進線。装甲へ当てると石片が飛ぶ。
- 裂空断：大きな風の刃が前方を走り、床へ一瞬だけ亀裂状の残光を残す。
- 先陣斬り：交代位置へ高速で入り、青いスカーフを思わせる短い軌跡を残す。

### ナディ

- 月輪投げ：月輪刃の回転軌跡を細い青白色の円で表現する。
- 円月旋：ナディを中心に広がる太い円形斬撃。
- 月蝕乱舞：複数の月輪軌跡が段階的に広がり、最後に大きな円環が弾ける。
- 輪光掃：交代直後、前方を広く払う半円状の光刃。

### メル

- 燐光弾：淡い青緑色の小さな魔法弾。着弾時に燐光の粒が散る。
- 癒しの環：足元へ葉と晶石を思わせる柔らかな回復円を表示する。
- 天晶崩落：上空から巨大な晶石光が落下し、着弾点から結晶片と魔力波が広がる。
- 瞬光障壁：交代時に短時間だけ半透明の晶石障壁を展開する。

## 13. 最初に作る試作版

第1段階ではダンジョン全体を作らず、1つの戦闘アリーナで操作感を確認する。

必須項目：

- カイル、ナディ、メルの移動と追従
- キャラクター交代
- 3人分の通常攻撃、特殊技、大技
- 後方AIの通常攻撃
- 後方メンバーの攻撃力・被ダメージ半減
- メルの自動回復
- 通常敵2〜3体との戦闘
- 戦闘不能の片膝ポーズと自動交代
- 経験値取得時の一時表示
- 若葉の雫と魔力の露
- PC操作
- 攻撃エフェクト、ヒットストップ、軽い画面振動

第2段階でモバイル操作、ヴェルグラン戦、各部屋の接続を追加する。
