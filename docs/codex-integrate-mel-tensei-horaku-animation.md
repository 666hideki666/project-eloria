# Codex向け追加指示：メル大技「天晶崩落」モーションを導入

Project Eloriaへ、メルの大技「天晶崩落」の4方向アニメーションを導入してください。

通常攻撃「燐光弾」と特殊技「癒しの環」で追加済みの共通アクションスプライト読み込み、方向固定、非ループ再生、終了後の待機・歩行復帰処理を再利用してください。大技だけ別方式のアニメーション管理にしないでください。

今回は表示モーションを既存の`crystalFall`シーケンスへ同期させます。着弾時刻、対象選択、攻撃範囲、ダメージ、ノックバック、クールダウン、効果音、晶石と破片エフェクトは変更しないでください。

## 使用素材

- 画像：`assets/sprites/characters/mel/attacks/mel-ultimate-tensei-horaku-48px-v1.png`
- 設定：`assets/sprites/characters/mel/attacks/mel-ultimate-tensei-horaku-48px-v1.json`

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- ループなし
- 再生時間：1.12秒

方向行：

- 0行目：下向き
- 1行目：上向き
- 2行目：左向き
- 3行目：右向き

各行は左から次の6コマです。

1. 杖を持った静かな構え
2. 腰を落とし、杖へ大きな魔力を集める
3. 両手で杖を頭上へ掲げる
4. 杖を空へ突き上げ、空いた手で落下地点を指す
5. 晶石落下の反動へ耐えながら命令を維持する
6. 力を解き、通常の構えへ戻る

杖は全コマの画像へ1本ずつ含まれています。別描画の杖を重ねないでください。落下する晶石、標的円、光柱、衝撃波、晶石片、火花などは画像へ含まれていないため、既存のゲーム側エフェクトを維持してください。

## 1. アクションスプライト登録

既存の`characterSpriteConfig.ts`へ、通常攻撃と特殊技と同じ構造で画像とJSONを読み込み、`MERU_SPRITE.actions.ultimate`として登録してください。

実行時のキャラクターIDは既存どおり`meru`です。素材フォルダ名とJSON上の制作名は`mel`ですが、新しいキャラクターIDを追加しないでください。

設定値：

- フレームサイズ：48×48px
- 列数：6
- 方向別行：down 0 / up 1 / left 2 / right 3
- 足元アンカー：`x: 0.5`, `y: 0.92`
- ループ：なし
- 総再生時間：1.12秒
- コマ時間：`[0.08, 0.18, 0.26, 0.24, 0.22, 0.14]`
- 晶石着弾に対応するコマ：3
- 着弾時刻：0.52秒

画像補間は無効にし、既存キャラクターと同じnearest-neighbor描画を使用してください。

## 2. メルだけ表示時間をシーケンスへ合わせる

現在の`performUltimate()`にある共通の行動開始時間を、キャラクター別の表示時間にしてください。

- カイル「裂空断」：0.5秒を維持
- ナディ「月蝕乱舞」：導入済みなら1.04秒を維持
- メル「天晶崩落」：1.12秒

たとえば、`beginCharacterAction()`を一度だけ呼ぶ前に、キャラクターIDから表示時間を選択してください。

```ts
const actionDuration =
  member.id === "nadi" ? 1.04 :
  member.id === "meru" ? 1.12 :
  0.5;
this.beginCharacterAction(member, "ultimate", actionDuration);
```

プロジェクトの既存形式に合わせて同等の実装へ変更して構いません。

重要：

- 1.12秒への変更はアクションスプライトの表示時間だけに使う。
- 大技クールダウン、入力制御、無敵時間、移動速度などを変更しない。
- `crystalFall`シーケンスの着弾0.52秒と終了1.12秒は変更しない。
- `beginCharacterAction()`を分岐の内外で二重に呼ばない。
- カイルとナディの大技モーションへ影響させない。

## 3. 天晶崩落の発動へ接続

メルが大技を使い、`crystalFall`シーケンスが追加された場合、この天晶崩落シートを再生してください。

- 発動開始時の`actionFacing`から方向行を一度選ぶ。
- 1.12秒の間、選択した同じ行を使用する。
- キャラクター画像をコードで回転・左右反転しない。
- 6コマを1回再生し、終了後は現在の待機・歩行へ戻す。
- メル自身のワールド座標は固定する。
- 画像内の踏ん張りや身体の揺れをワールド移動として扱わない。
- 同じ技を再発動したときは0番コマから再スタートする。

## 4. 既存の対象選択を維持

現在の対象地点決定を変更しないでください。

- メルから最も近い敵がいる場合、その敵の現在位置を対象にする。
- 敵がいない場合、メルの向いている方向へ92px先を対象にする。
- 敵がいない場合の地点は、既存どおりアリーナ内へ24pxの余白で収める。
- `crystalFall`シーケンスへ対象地点のコピーを保存する。
- 詠唱中に敵が移動しても、落下地点を再追尾させない。

発動直後に表示される既存の予告リングを維持してください。

- 種類：`ring`
- 位置：対象地点
- 寿命：0.7秒
- サイズ：38
- 色：`#79e7cf`
- レイヤー：`back`

## 5. 0.52秒の着弾と同期

既存の`crystalFall`シーケンスでは0.52秒に着弾します。アニメーションでは3番コマの開始が0.52秒になるよう設定済みです。

現在の着弾仕様を維持してください。

- 着弾時刻：0.52秒
- 攻撃半径：56
- ダメージ：64
- ダメージ倍率：1
- ノックバック：58
- 攻撃色：`#8af3dc`
- シーケンス終了：1.12秒
- 大技クールダウン：11秒
- 既存の大技効果音とバナー`メル｜天晶崩落`を使用

着弾判定をアニメーション側の新しいイベントとして二重に発生させないでください。既存の`updateSequences()`だけが攻撃判定を生成し、3番コマは視覚的に同期するだけです。

## 6. 晶石と破片エフェクトを維持

着弾時の既存`crystal`エフェクト：

- 位置：対象地点
- 速度：`{ x: 0, y: -14 }`
- 寿命：0.72秒
- サイズ：58
- 色：`#9cf8e4`

既存の16個の`spark`エフェクト：

- 16方向へ均等に放射
- X速度：`cos(angle) * 70`
- Y速度：`sin(angle) * 45`
- 寿命：0.55秒
- サイズ：`3 + (shard % 3)`
- 色：`#dfffee`と`#50d5bd`の交互

既存の`triggerImpact(4)`も維持してください。

スプライトはメル本人の詠唱だけを担当します。晶石本体、落下光、標的円、衝撃波、破片、火花をスプライトへ追加したり、既存エフェクトを二重生成したりしないでください。

## 7. 状態の優先順位

描画アクションの優先順位は既存の共通ルールを使用してください。

1. 戦闘不能
2. 大技・特殊技などの行動中
3. 通常攻撃
4. 移動
5. 待機

少なくとも次を保証してください。

- 天晶崩落中に燐光弾や癒しの環のシートを再生しない。
- 燐光弾、癒しの環、瞬光障壁で天晶崩落シートを誤再生しない。
- 戦闘不能時は大技より戦闘不能表示を優先する。
- 移動状態によって大技モーションが即座に歩行へ上書きされない。
- キャラクター交代後も大技状態が不正に残らない。

## 8. 変更しないもの

- カイルとナディの全スプライト
- メルの待機・歩行、燐光弾、癒しの環
- 瞬光障壁
- 天晶崩落の対象選択・着弾判定・数値・エフェクト
- 敵AI、当たり判定、ダメージ計算
- パーティー陣形、交代、後方補正
- HUD、回復、経験値、BGM、効果音

## 9. テスト

既存テストを維持し、可能なら次の確認を追加してください。

- メルの`ultimate`画像とJSONが正常に読み込まれる。
- 大技は開始方向に対応する正しい行を使用する。
- 1.12秒で6コマを1回だけ再生する。
- 3番コマが0.52秒から表示される。
- 攻撃判定が0.52秒に1回だけ発生する。
- 攻撃半径56、ダメージ64、ノックバック58が変わっていない。
- 大技クールダウン11秒が変わっていない。
- 最も近い敵、または前方92pxという対象選択が変わっていない。
- 晶石1個と火花16個が既存どおり生成される。
- カイルとナディの大技表示時間へ影響がない。
- 燐光弾、癒しの環、瞬光障壁で大技シートが誤再生されない。
- 行動終了後に待機・歩行へ正常に戻る。

最後に`npm test`と`npm run build`を実行し、既存機能に回帰がないことを確認してください。

## 完了条件

- メルが4方向すべてで杖へ力を集め、上空へ晶石落下を命じる。
- 0.52秒の着弾と、杖を突き上げて対象を指す3番コマが同期して見える。
- 癒しの環より力強く、攻撃用の大魔法だと明確に分かる。
- メルの足元がずれず、浮いたり瞬間移動したりしない。
- 杖が二重表示されず、全コマで1本だけ見える。
- 天晶崩落の対象選択、ダメージ、半径、ノックバック、クールダウンが変更されていない。
- 他キャラクター、通常攻撃、特殊技、交代攻撃へ意図しない変更がない。
