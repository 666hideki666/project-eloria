# 古の森の歩行範囲と第１層への接続：実装指示案 v1

状態：**ユーザー承認済み・実装タスクへ依頼済み**（2026-10-10「これで実装に移って！」）。`work | エロリア2` は画像照合と本指示書まで。ゲームコード・本番歩行データ・起動経路の実装・検証は `コード実装 | エロリア2` が担当する。検証完了の報告はまだない。推奨モデルは **Sol High**。

## 今回の範囲

- 通常のゲーム開始時に第１層より前の「古の森」から遊べるようにする。下側は村への道、上側は洞窟。森を歩いて洞窟へ進むと、既存の第１層「苔根の遺構」の南側開始位置につながる。
- 村方面へ進もうとしたら、最初は移動を止め、「まずは森の奥の洞窟を調べよう」といった趣旨の短い案内を出す。文言は仮案。赤線内の村道を物理的に消さず、端の出口だけを進行制御で閉じる。
- 既存の第１層から守護者戦までの実装・開発用の各層直接開始は維持する。オープニングムービー、３人の出会いの詳細、敵や新しい仕掛け、章クリア後の村帰還は**今回作らず**、将来の接続点だけ見失わないようにする。

## 赤線の読み方

- 内側は土、草、石畳、苔、洞窟内の見える床も歩行可能。材質で再判定しない。外側の森・岩壁・装飾・見かけ上の床は不可。
- 中央の円形広場と左の円形遺構、左右の枝道・右端の小広場、上の洞窟、下の村道は一続き。左上の道は画面外への第三出口ではなく、赤線内で終わる袋小路。
- 中央広場の柱・根など、赤線が小さく閉じて囲んだ島は歩けない。赤線抽出時に穴を埋めない。立体物の必要な追加判定は、床マスクとは別の物体判定として最小限にする。
- 右側の狭い折り返しや左遺構への細い接続を勝手に太らせたり、途切れを床の見た目だけで繋いだりしない。
- 村道の左右の赤線は画像下端の直前で終わる。**端から画像境界までの残り数画素だけ**線を延長して閉じる。上の洞窟は画像内の赤線に従い、勝手に洞窟を広げない。
- 初期位置は下側の赤線内・村出口の制御線より北側、洞窟入口は上中央の赤線内に置く。具体的なワールド座標は背景変換と完成マスクを照合して実装側で決め、数値だけでなく画面でも確認する。

## 歩行・遷移

1. 赤線との差分から境界を取り、内側を二値化する。マスクの背景重ね図で左右の袋小路・中央の穴・洞窟・村道を確認し、生成スクリプトに原画像寸法、参照画像のハッシュ、重要地点の正負アサーションを残す。今回の仮図を無検証で本番データとして流用しない。
2. プレイヤー、追従者、敵が後で追加された場合の敵、ノックバック、演出移動、ワープの足元接地点 `pos` だけで歩行を判定する。戦闘の当たり半径は使わない。移動の全線分を検査して赤線外への飛び越しを防ぐ。
3. 洞窟内の上方向の出口判定で既存の部屋遷移を開始し、第１層の南側開始地点へ入る。単に画像上端に達しただけ、または赤線外を通っただけでは遷移しない。遷移後は既存の第１層の入場タイトル、敵、根の仕掛け、カメラ、音を壊さない。
4. 村方面の下端は出口として位置を予約するが、初回は案内を出して森側に留める。キーを押し続けたときの案内連打を防ぐ。章クリア後の解放条件・村マップは次工程で設計する。
5. 本番起動の既定部屋は古の森にする。今の「ワープ機能」は `src/main.ts` の **DEV限定**開始層選択で、通常のゲーム内ワープとは別。開発確認用の直接開始は残し、古の森を選べる入口を追加する。全画面ボタンと既存の層選択・QA URLは維持する。オープニングムービーはまだないため、現行の開始操作後に森を表示する。
6. 森のエリア名を出す場合は既存の中央入場タイトルの演出を共用し、初回ゲーム開始で第１層名が先に出ないようにする。タイトル演出や画面枠の新デザインは今回の対象外。

- 最初の森に敵・謎解き・通路上クリスタル・余分なゲートは追加しない。

## 合格条件

- 本番相当の通常開始で森の赤線内に出現し、村方面は案内で止まり、洞窟から第１層へ入れる。DEVでは森と各既存層を直接開始できる。
- 足元一点で中央・左右の細い枝道・各袋小路・洞窟まで移動できる。中央の赤線で囲まれた物体島、森外、画像外へは歩けない。斜め、高速、押し戻し、追従でも漏れない。
- 洞窟移動後の第１層が従来どおり動く。層選択、全画面、既存４エリア、QA URL、BGMを退行させない。
- マスク連結テストだけで終えず、実際のブラウザ操作で下端→中央→洞窟、左・右の寄り道、村出口の拒否、洞窟遷移を確認する。テスト・型検査・ビルドを通し、検証後はテスト用ブラウザと音楽を止める。
