# Codex向け実装指示：転送クリスタル・根の門・石碑の改善 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：既存の進行ロジックを維持しながら、3種類のランドマーク描画、近接案内、衝突、開放演出、QAを連動させる中規模修正のため。

## 最初に確認する資料

1. `assets/concepts/environments/moss-root-ruins/landmarks/moss-root-ruins-interactive-landmarks-design-board-v1.png`
2. `assets/concepts/environments/moss-root-ruins/tiles/moss-root-ruins-core-terrain-design-board-v1.png`
3. 現在の`src/render/stages/MossRootRuinsRenderer.ts`
4. 現在の`src/game/GameWorld.ts`内の`interactWithStage()`、`updateStageContext()`、`gateUnlockTimer`
5. 現在の`src/stage/tileCollision.ts`と`mossRootRuinsMap.ts`

デザインボードは見た目と接地面の基準である。画像をランタイムへ貼り付けず、既存のCanvasピクセル描画へ翻訳する。

## 1. 目的

現在の問題：

- 転送クリスタルが小さく、クリスタルらしい立体感と発光が弱い
- 近づいても、触れられる対象だと十分に伝わらない
- 最初の根の門が茶色い床模様に見え、通路を塞ぐ巨大な根だと分かりにくい
- クリスタルと石碑の上を歩けるため、立体物として不自然
- 石碑も床上の記号に見えやすい

改善後：

- クリスタルへ近づくと状態説明と操作案内が出る
- E/Enterで触れるとクリスタルが強く発光し、根の門が開く
- 根は閉鎖中に完全な物理障害物として見える
- クリスタルと石碑の台座へ衝突し、上を歩けない
- 当たり判定は見た目の台座部分だけで、発光や上部シルエットへ過剰に広げない

## 2. 転送クリスタルの本番描画

デザインボード左上を基準に、`drawCrystalCluster()`とは別のランドマーク用描画を用意する。

推奨：

```ts
drawTransferCrystal(context, x, y, time, activated)
```

見た目：

- 主結晶1本＋周囲の小結晶4本
- 主結晶はキャラクター身長の約1.5〜2倍
- 暗い青緑、鮮やかなシアン、白に近いハイライトの3〜4段階
- 尖った多面体シルエット
- 石造りの円形ソケット
- 接地影
- 床に欠けた同心円状の古代紋様
- 常時、弱い段階的な明滅
- 小さな光粒を低頻度で上昇させる
- `northGateUnlocked === false`では脈打つような発光
- 開放後は落ち着いた一定光へ変化

滑らかな大きなグラデーションを避け、2〜4フレーム相当の段階発光にする。攻撃エフェクトより明るくしすぎない。

通常の小晶石描画は変更しなくてよい。転送クリスタルだけ明確に格上のランドマークにする。

## 3. クリスタルの近接表示

現在の`updateStageContext()`へ、泉・石碑と同様のクリスタル近接案内を追加する。

### 未開放時

距離80px以内：

```text
クリスタルがまばゆい光を放っている
```

距離52px以内：

```text
E　クリスタルに触れる
```

1行表示しかできない場合、52px以内では操作案内を優先する。状態説明は80px境界へ初めて入った時に1.2秒程度表示し、その後は近接操作案内へ切り替える。

毎フレーム長いバナーを再生成して戦闘や他の通知を消さない。近接プロンプトと一時バナーを可能なら概念的に分ける。大規模UI追加は不要。

### 開放後

52px以内：

```text
E　クリスタルを調べる
```

再度操作した場合：

```text
クリスタルは穏やかな光をたたえている。
```

戦闘中・敵発見演出中はクリスタル操作と近接案内を出さない。

## 4. クリスタルへ触れた時の演出

既存の`gateUnlockTimer`による遅延開放を維持し、演出を強化する。

操作直後：

1. クリスタルが強く白シアンに発光
2. 2〜3本の環状波
3. 光粒が上昇
4. 0.6〜0.9秒の短い魔力充填
5. 根の門側へシアンの光が走る
6. 根が左右へほどける
7. `northGateUnlocked = true`
8. バナー：「大きな根がほどけ、道が開いた」

既存の効果音を利用してよいが、操作時と根の開放時が分かるよう、可能なら短い魔力音＋低い根の移動音の2段階にする。新しい音声素材生成は今回必須ではない。

操作中に連打して複数回発火しない。`gateUnlockTimer >= 0`中は入力を無視する。

## 5. 最初の根の門

デザインボード右上・左下を基準に、現在の`drawRootGate()`を改善する。

### 閉鎖中

- 通路幅全体を6〜10本の太い根で塞ぐ
- 左右の壁または柱から根が伸びる
- 中央に大きな絡み目
- 茶色3段階＋苔＋接地影
- 中央の絡み目に弱いシアンの脈
- キャラクターが通れそうな隙間を作らない
- 床模様ではなく、床より上に立つ壁として描画

### 開放後

- 中央の通路幅を完全に開ける
- 太い根は左右の壁へ巻き付いた状態で残す
- 床に小さな根の切れ端、葉、土
- シアンの残光を短時間表示
- 開放後の根が見えない壁として残らない

既存の`gate`タイルの衝突条件を維持し、見た目と開閉状態を一致させる。

## 6. 古代石碑の本番描画

デザインボード右下を基準に、`drawAncientMonument()`を改善する。

- 胸程度の高さがある石板または細いオベリスク
- 幅のある2〜3段の石台座
- 欠けた角、苔、暗い接地影
- 中央に幾何学的な古代紋様
- 未作動時は暗い青緑
- 作動後は明るいシアン
- 両脇に小さな補助石
- 上を歩けないことが見た目で理解できる

発光しても輪郭を失わない。石碑はキャラクターの前後関係を考慮し、台座は背景、上部は必要なら前景へ分ける。

## 7. ランドマーク衝突

クリスタルと石碑に、タイル全体ではなく見た目の台座へ一致した常設衝突を追加する。

推奨定義：

```ts
export const MOSS_ROOT_SOLID_PROPS = [
  { id: "transferCrystal", center: MOSS_ROOT_RUINS.crystal, radiusX: 24, radiusY: 15 },
  { id: "monument", center: MOSS_ROOT_RUINS.monument, radiusX: 28, radiusY: 18 },
] as const;
```

実際の描画サイズに合わせて±6px調整可。

要件：

- プレイヤー、探索中の操作キャラクター、戦闘中の仲間が台座を通過しない
- 敵も必要なら台座を通過しない。現在の敵移動衝突構造を確認し、無理に別系統を作らない
- 円または楕円の押し出しで、角へ引っかかりにくくする
- 台座の上部シルエット全体を衝突にしない
- 近接操作距離は台座衝突の外側から届く
- 衝突追加後、クリスタルと石碑が既存通路を塞がないこと
- QAで配置されたキャラクターが台座内部に出現しないこと

`tileCollision`へランドマーク固有座標を直接散在させず、マップ定義側のsolid propsから参照する。

## 8. 操作対象の優先順位

E/Enterを押した時の優先順位を明確にする。

1. 戦闘中の禁止メッセージ対象
2. 最も近い操作可能ランドマーク
3. 泉
4. 石碑
5. クリスタル
6. 第2層の門

実際には同時近接しない配置だが、長い`if`の順番だけで偶然決まらないよう、可能なら近接候補から最短距離を選ぶ。今回の範囲を超える大規模なinteraction system化は不要。

## 9. SnapshotとRenderer

必要なら次の描画状態を`WorldSnapshot`へ追加する。

```ts
gateUnlockProgress: number
```

値は0〜1へclampし、クリスタルの強発光と根の開放アニメーションに使う。Rendererが`GameWorld`のprivate timerへ直接触れない。

近接テキストを独立表示する場合：

```ts
interactionPrompt: string | null
```

既存のバナーだけで安全に実現できるなら追加不要。ただし短時間の近接表示が、重要な戦闘バナーや開放メッセージを上書きしないこと。

## 10. 維持する機能

- ワールド2048×1920とマップ構造
- モスプルン10体と戦闘
- 戦闘封鎖なし
- 距離による逃走
- 回復の泉
- 実用的な新ショートカット
- BGM、陣形、経験値
- 最終戦と第2層門
- 基本地形の本番描画
- アリーナモード

今回の衝突追加で、開始地点から最初の根の門への経路や、石碑周辺の専用通路を塞がない。

## 12. 自動テスト

最低限追加・更新する。

1. 未開放時、クリスタル近接で案内状態になる
2. 遠い位置では案内が出ない
3. E/Enterで開放タイマーが一度だけ開始
4. タイマー完了まで根は閉鎖状態
5. 完了後`northGateUnlocked === true`
6. 開放後、根の門を通行できる
7. クリスタル台座中心へ進入できない
8. 石碑台座中心へ進入できない
9. 台座の外側から操作できる
10. 操作キャラクターを交代しても衝突が働く
11. 戦闘中はクリスタル操作案内と開放操作を出さない
12. 石碑の開通処理を壊さない
13. 泉の操作を壊さない
14. 既存の全stageテスト、逃走テスト、経路テストが成功
15. アリーナモードへランドマーク衝突を適用しない
