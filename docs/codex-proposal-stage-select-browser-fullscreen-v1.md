# 実装指示案：層選択メニューからブラウザ全画面表示

**承認待ち。ここでは実装しない。** ユーザーが指示書を確認して承認した後、`コード実装 | エロリア2` で実装する。

## 現状と目的

- `src/style.css` の field-first レイアウトは、すでにゲームをブラウザの表示領域いっぱいに広げている。ただしブラウザのタブ・アドレスバーは残る。
- ユーザーが指す「ステージを選ぶメニュー」は `src/main.ts` の `mountDevLayerSelector()`。開発ビルドで、QA用の直行指定がないときに表示される。現在は第1〜3層と守護者戦を選べる。
- このメニューに「⛶ 全画面で遊ぶ」ボタンを追加し、押した後もメニューを残したまま、好きな層を選んで遊べるようにする。全画面の出入りでゲームの進行状態をリセットしない。

## UIと操作

1. 層選択ボタンの下に、同じ画面になじむ**二次ボタン**として全画面ボタンを置く。層の選択肢とは色と余白を少し分け、誤って層を開始しないようにする。
2. 未実行時は「⛶ 全画面で遊ぶ」、実行中は「全画面を終了」。補足に「Escで通常表示に戻れます」を表示する。
3. ボタン押下では層を開始せず、メニューを閉じない。ブラウザ全画面になってから第1〜3層／守護者戦を選んでも、全画面状態を保って開始する。
4. `document.documentElement` を全画面対象にする。`#game-shell` だけを対象にすると、その外側に動的生成される層選択メニューが隠れるため避ける。既存の640×360論理キャンバスと16:9の表示比率は維持し、画面の比率差は黒余白として扱って画像を伸ばさない。
5. `fullscreenchange` でボタン表示・`aria-pressed`・補足を同期する。ブラウザ側のEsc、画面外からの終了でも状態が一致するようにする。失敗・非対応時はメニューを維持し、短いエラーを表示する。自動で全画面に入ろうとしない。
6. キーボード操作：Tabで全画面ボタンへ移動でき、Enter/Spaceで押せる。現行の層選択メニューはウィンドウの`keydown`捕捉段階でEnterを層開始に使っているため、**全画面ボタンにフォーカスがあるEnterは層開始へ流さない**。数字1〜4、↑↓＋Enterによる従来の層選択は維持する。
7. ゲーム開始後にEscで全画面を抜けた際、既存のEscポーズ処理と衝突して予期しない二重操作にならないか実ブラウザで確認し、必要なら全画面終了の1回だけポーズ入力を抑制する。全画面以外でのEscポーズは維持する。
8. クリック・キーボード・タッチから操作可能にし、フルスクリーンへの切り替えで音量、音楽、入力フォーカス、進行状態を変えない。

## 実装範囲

- 主対象：`src/main.ts` の `mountDevLayerSelector()`。
- 見た目：必要に応じて層選択メニュー用のスタイル。可能なら現在のインラインスタイルを必要以上に広げず、全画面ボタンを既存の層ボタンと視覚的に区別する。
- `src/input/InputController.ts` を変更する場合は、全画面とEscの干渉解消に必要な最小範囲のみ。
- 今回は**開発用の現行層選択メニュー**を対象とする。一般公開時に層選択メニューを追加することや、プレイ中の常設ボタン追加は別件。
- マップ、歩行マスク、戦闘、音楽再生、セーブ・進行ルールは変更しない。

## 完了条件・QA

- PCのブラウザでメニューからボタンを押すとタブ・アドレスバーのない全画面へ移り、メニューはそのまま表示される。
- 全画面のまま各層をクリック／数字キー／矢印＋Enterで開始できる。
- 全画面ボタンをフォーカスしてEnter/Spaceを押しても、層は勝手に始まらない。
- Escやボタンで通常表示へ戻れ、表示状態と実際の全画面状態が一致する。拒否・非対応時にもゲームが遊べる。
- 16:9表示、HUD、ポーズ、キー入力、BGMが全画面前後で正常。ブラウザの幅・高さ変更時にも引き伸ばしや切れがない。
- typecheck、テスト、build、実ブラウザでの目視確認を行う。QAのために開いたブラウザ・サーバーは終了し、音を残さない。
