# Codex向け追加指示：3人の通常攻撃エフェクトを仕上げる

Project Eloriaのカイル「連刃剣」、ナディ「月輪投げ」、メル「燐光弾」に、キャラクターごとの個性が伝わる通常攻撃エフェクトを実装してください。

今回は画像素材を追加せず、現在のCanvas描画と`EffectPool`を拡張してください。攻撃方向、投射物、命中位置へ正確に追従させ、640×360の論理解像度で16ビット時代らしい明瞭な表現にします。

## 目標

- 攻撃モーションとエフェクトが一体に見える。
- カイル、ナディ、メルを色だけでなく形と動きでも区別できる。
- 通常攻撃なので派手すぎず、敵、HPバー、危険予兆を隠さない。
- ダメージ、攻撃範囲、投射物性能、クールダウンを変更しない。
- 既存の効果音、ヒットストップ、画面振動を維持する。
- PCと小画面の両方で輪郭がぼやけない。

## 共通表現ルール

- Canvasの論理座標を使用し、主要な座標と小さな矩形は整数へ丸める。
- CSS blur、Canvas shadowBlur、画像補間、半透明グラデーションへ頼らない。
- 1〜4px程度の明瞭な線、矩形、円弧、菱形を組み合わせる。
- 白一色ではなく「暗い縁、中間色、明るい芯」の2〜3段階で描く。
- 星形、十字型の強いきらめき、画面を覆うフラッシュを使用しない。
- 通常攻撃1回の主エフェクトは、おおむね0.12〜0.22秒で消える。
- 軌跡は`back`、主攻撃と命中は`front`を基本にする。
- ランダム値が必要な場合は、既存の注入済み`this.random()`を使用し、`Math.random()`を直接使用しない。
- 新しい配列やCanvasを毎フレーム生成せず、既存の`EffectPool`を利用する。
- `EFFECT_POOL_SIZE = 220`で、3人と敵が同時に動いても重要なエフェクトが上書きされ続けない粒子数にする。

## 実装構造

必要に応じて`EffectKind`へ、通常攻撃専用の種類を追加してください。名称は既存設計に合わせて変更できます。

- `bladeArc`：カイルの二重斬撃弧
- `moonTrail`：ナディの途切れた円環残光
- `phosphorMote`：メルの小さな燐光粒
- `impactRing`：短く広がる命中円

すべてを汎用`"spark"`へ押し込まず、形が異なるものは`Renderer.drawEffect()`で明示的に描き分けてください。一方、既存の`ring`や`spark`で十分な部分は再利用し、種類を増やしすぎないでください。

命中時のキャラクター別表現を選べるよう、攻撃から命中まで描画用の識別情報を渡してください。

例：

- `AttackArea`／`AreaOptions`へ任意の`impactStyle`
- `applyDamageToEnemy()`の`impact`へ任意の`visualStyle`
- 投射物は既存の`projectile.kind`から識別

ゲーム判定用の`owner`や`kind`を描画都合で変更しないでください。

## 1. カイル「連刃剣」

### 発動・斬撃

現在の単線`slash`を、連刃剣専用の短い二重斬撃弧へ置き換えます。

- 位置：現在と同じ、カイルの前方約17px
- 回転：`Math.atan2(member.facing.y, member.facing.x)`
- 寿命：0.15〜0.18秒
- 大きさ：外側約29px、内側約25px
- 角度：前方を覆う約110〜135度
- 外側：青緑色`#55cfc3`前後、太さ3〜4px、低めの透明度
- 内側：白銀色`#effff9`前後、太さ1〜2px、高めの透明度
- 消え際：線幅とアルファを減らし、外側へ2〜3pxだけ広がる
- 線端：丸くぼかさず、短く切れた剣閃らしい形

斬撃弧を2本重ねる場合は完全に同じ位置へ置かず、内側をわずかに前方へ寄せて剣の速度が読めるようにしてください。

攻撃モーションの振り抜きコマと合って見えるよう確認します。ただし攻撃判定を遅延させず、現在の入力応答を維持してください。

### 命中

- 実際に敵へ命中した時だけ表示する。
- 白銀色の短い火花を3〜4個。
- 青緑色の小さな破片を2個まで。
- 火花は攻撃方向へ扇状に流す。
- 0.12〜0.2秒で消す。
- 現在のヒットストップ0.045秒と通常攻撃の画面振動を増やさない。
- 石装甲へ当たった場合は既存の石片と衝突音を優先し、白い光で石片を隠さない。

## 2. ナディ「月輪投げ」

### 発射

- 投射物生成位置に、直径10〜14pxの細い青白い円を1つ出す。
- 寿命は0.12〜0.16秒。
- 円は外側へ少し広がりながら消える。
- 投げモーションで手元から月輪刃が消えるタイミングと、投射物が前へ進む流れが自然に見えること。

### 飛翔する月輪刃

現在の単純な円を、細い二重円環として描き直します。

- 外周：白銀色または薄い青白色、太さ1〜2px
- 内周：青緑色、外周より暗く細い
- 円周の一部を2か所だけ短く切り、回転方向が読める形にする
- 小さな青緑の装飾を1〜2か所入れてよい
- 現在の回転速度`time * 13`を大きく変更しない
- 実際の当たり判定半径7から大きく外れない見た目にする
- 塗りつぶした円盤や盾にしない

### 軌跡

現在、月輪刃と燐光弾が同じ四角い`spark`を毎更新で生成しています。月輪刃は専用の途切れた円環残光へ変更してください。

- 投射物の後方へ、半円または2本の短い弧を残す。
- 色：`#c6ffff`と`#60cfcb`付近
- 寿命：0.12〜0.18秒
- 大きさ：4〜7px
- `back`レイヤー
- 同時に表示する残光は3〜5個程度
- 往路と復路の両方へ対応する
- フレームレート依存で粒子数が増えないよう、投射物ごとの時間ベース発生間隔を使用する
- 目安は毎秒24〜30個以下

必要なら`Projectile`へ`trailTimer`を追加し、生成時に初期化してください。60fpsと30fpsで軌跡の密度が大きく変わらないようにします。

### 命中・受け戻し

命中時：

- 直径12〜16pxの細い円が一度だけ広がる。
- 青白い短い破片を4〜6個。
- 円を何重にも重ねず、敵の輪郭を残す。

持ち主へ戻った時：

- ナディの手元に8〜10px程度の小さな収束円を出す。
- 大きな命中音や画面振動は追加しない。
- 既存の`projectileReturn`効果音を維持する。

## 3. メル「燐光弾」

### 発射

- 杖先付近へ直径6〜9pxの小さな収束円を表示する。
- 色：淡い青緑`#9ff4dc`、中間色`#54d4b9`
- 0.1〜0.14秒で素早く収束または消滅する。
- 大きな魔法陣、星、長い詠唱光を出さない。

発射位置は現在のメル前方約10pxを維持します。上下左右で杖先から極端に離れて見える場合は、ゲーム判定を変えず、描画専用の発生位置だけを方向別に数px調整して構いません。

### 飛翔する燐光弾

現在の十字型表示を、星に見えない小さな燐光へ変更します。

- 中心：2〜4pxの生成り色または淡い青緑の菱形
- 外側：1px程度の青緑色ピクセルを非対称に2〜3個
- 全体の見た目は直径6〜9px
- 発光の十字、五芒星、花火形状にしない
- 現在の弱い誘導、速度122、当たり判定半径4を変更しない

### 軌跡

- 1〜2pxの燐光粒を疎らに残す。
- 1個ごとの寿命：0.16〜0.28秒
- 後方へゆっくり流し、少しだけ上下へ散らす
- 色は`#7ae3c8`、`#b9f7e5`付近の2色
- `back`レイヤー
- 同時表示は4〜7粒程度
- 毎秒18〜24個以下
- 月輪刃と同様に時間ベースで生成し、フレームレートへ依存させない

### 命中

- 小さな青緑色の円を1つ、0.12〜0.18秒だけ表示する。
- 燐光粒を5〜7個、全方向へ短く散らす。
- 粒はすぐ減速し、敵の周辺へ柔らかく残る。
- 白い大爆発、強い画面フラッシュ、追加の画面振動を使用しない。
- 弱い基本攻撃であることを保ちつつ、命中したことは明確に分かるようにする。

## 命中表現の選択

`applyDamageToEnemy()`の既存処理では、すべての攻撃が同じ`emitHit()`を使用しています。通常攻撃3種だけ専用の形を追加し、特殊技・大技・敵攻撃の既存表現を意図せず変えないでください。

推奨：

- 共通ダメージ処理、HP減少、装甲、音、ノックバックはそのまま維持。
- `visualStyle`がある時だけ専用の小さな命中エフェクトを追加。
- 既存の汎用火花を完全に重ねると過剰になる場合、専用スタイルでは汎用火花数を減らす。
- 敵撃破時のEXP表示、葉、粉塵は変更しない。

## アクセシビリティ

- `ACCESSIBILITY.strongFlashes === false`の時は、白銀の芯や命中時の明色を少し暗くし、強い白表示を避ける。
- `ACCESSIBILITY.screenShake === false`の時は、これまでどおり画面を揺らさない。
- 通常攻撃のために新しい全画面フラッシュを追加しない。
- 点滅回数を増やさず、短いフェードまたは縮小で消す。

## 変更しないもの

- 3人の待機、歩行、通常攻撃スプライト
- 通常攻撃のダメージ、範囲、速度、寿命、誘導、クールダウン
- ナディの月輪刃の往復ロジック
- メルの通常攻撃にMPを消費しない仕様
- 後方AIの攻撃力半減
- 特殊技、大技、交代攻撃
- 敵AI、陣形、経験値、ドロップ
- HUD、BGM、既存効果音

## テスト

既存テストを維持し、少なくとも次を確認・追加してください。

- カイルの通常攻撃が同じ敵へ1回だけダメージを与える。
- 月輪刃の速度154、半径7、寿命0.92秒、往復動作が変わらない。
- 燐光弾の速度122、半径4、寿命1.25秒、弱い誘導が変わらない。
- メルの通常攻撃でMPを消費しない。
- 後方AIのダメージ半減が維持される。
- 追加した`trailTimer`が投射物生成時とプール再利用時に正しく初期化される。
- 30fps相当と60fps相当で、一定時間後の軌跡生成数が大きく変わらない。
- エフェクト追加後も`EffectPool`の上限を超える配列増加がない。
- `strongFlashes`と`screenShake`の無効設定が守られる。

## 完了条件

- カイルは白銀と青緑の短い二重斬撃として見える。
- ナディは回転する月輪刃と途切れた円環軌跡として見える。
- メルは星形ではない淡い燐光弾と小粒の軌跡として見える。
- 3人を連続で交代・攻撃しても、誰の攻撃か瞬時に判別できる。
- 攻撃モーションと発動位置が大きくずれていない。
- 命中した時だけ命中エフェクトが出る。
- エフェクトが敵、HPバー、危険予兆を長時間隠さない。
- 大量の自動攻撃中も処理落ちや著しい粒子欠落がない。
- ゲームバランスと既存の戦闘ロジックが変わっていない。
- 開発サーバーと本番ビルドの両方で正常に動作する。

実装後は、3人それぞれについて上下左右、空振り、通常命中、石装甲命中、後方AI攻撃を確認してください。各エフェクトの寿命、色、粒子数、軌跡生成間隔、30fps／60fps相当の差、ゲーム数値を変更していないことを日本語で報告してください。
