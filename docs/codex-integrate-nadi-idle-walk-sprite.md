# Codex向け追加指示：ナディ待機・歩行スプライトの試験導入

Project Eloriaの現在の試作版へ、ナディの4方向待機・歩行スプライトを導入してください。

カイルへ導入済みのスプライト読み込み、方向決定、時間ベースアニメーション、描画倍率、足元アンカー、接地影の仕組みを再利用してください。ナディだけ別方式で実装せず、3人で共通利用できるキャラクタースプライト構造へ整理してください。

## 使用ファイル

- スプライト：`assets/sprites/characters/nadi/nadi-idle-walk-48px-v1.png`
- メタデータ：`assets/sprites/characters/nadi/nadi-idle-walk-48px-v1.json`

仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行の最初の2コマ：待機
- 各行の後半4コマ：歩行
- 待機：約2fps
- 歩行：約8fps
- 基準点：足元中央

原寸参照版、クロマキー版、カイルの既存ファイルを編集・削除しないでください。

## 表示

- ナディの現在の簡易フィールド表示だけを新しい正式スプライトへ置き換える。
- カイルと同じnearest-neighbor描画を使用する。
- カイルと同程度の身長に見える描画倍率から開始する。
- 月輪刃まで含めて48×48セルへ収める。
- 月輪刃を別武器画像として二重描画しない。
- 待機・歩行中の月輪刃はスプライト内に含まれている。
- 通常時の水色足元リングを復活させない。
- 必要な接地影はカイルと同じ、小さく暗いゲーム側の影を使用する。
- 操作中の判別は頭上マーカーと左HUDの強調を使用する。

## 方向とアニメーション

- 方向、斜め入力、最後に向いていた方向の保持はカイルと同じ規則にする。
- 操作キャラクター時と後方AI時の両方で歩行アニメーションを行う。
- 陣形位置へ到着したら待機へ戻る。
- ポーズ、タブ非表示、ゲームオーバーでアニメーション時間が飛ばないようにする。
- キャラクター交代後も新しい操作状態と移動方向へ正しく切り替える。
- 左右画像をコード側で反転しない。

## 攻撃中

今回の画像には攻撃モーションがありません。

- 月輪投げ、円月旋、月蝕乱舞、輪光掃の既存ロジック、当たり判定、エフェクト、効果音を維持する。
- 攻撃中は現在方向の待機フレームで固定してよい。
- スプライト内の持っている月輪刃と、既存攻撃エフェクトの投射月輪が二重に見える場合は、攻撃状態中だけ自然な待機フレームを選ぶか、既存エフェクト側を調整する。
- 攻撃中にスプライト全体を回転、傾斜、伸縮させない。
- 後続の攻撃専用シートへ差し替えられる状態名と構造を保つ。

## 戦闘不能

- 正式な片膝フレームができるまでは、既存の簡易戦闘不能表示または待機フレームの暗色表示を使用する。
- 戦闘不能、自動交代、ターゲット除外、戦闘後復帰を壊さない。

## HUD

- 今回は左ステータス欄の顔アイコンを変更しない。
- HUD用アイコンは3人のフィールドスプライト確認後にまとめて作成する。
- ナディのHP、操作中枠、後方状態などの表示ロジックは維持する。

## 完了条件

- ナディが新しい正式スプライトで表示される。
- 上下左右の待機・歩行が正しい。
- カイルと並んだとき、身長とピクセル密度が自然に揃う。
- 月輪刃が全方向で1つだけ表示される。
- 後方AI時に陣形へ追従し、停止すると待機する。
- キャラクター交代後も正常に操作できる。
- 足元が浮いて見えず、水色リングも常時表示されない。
- 攻撃、特殊技、大技、交代攻撃、効果音、BGMが壊れていない。
- カイル、メル、敵、HUDは意図せず変更されていない。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。

実装後は、カイルとナディを隣に並べ、上下左右と歩行中を確認してください。採用した描画倍率、アンカー、接地影、月輪刃と攻撃エフェクトの重なりに関する確認結果を日本語で報告してください。
