# Codex向け修正指示：ゲート演出整理・補助マーク削除・進行SFX再構築 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：問題箇所は限定的だが、視覚エフェクト、全マップ描画、Web Audioの音色とイベント同期を横断して修正するため。

## 1. 目的

1. 根の解除時に表示される、カイルの必殺技に見える青い斬撃／風エフェクトを削除
2. 根のゲートや他の場所に表示されるシアン色の`＋`マークを全て削除
3. クリスタル、根の開放、湖上石段の効果音を短い通知音から臨場感のある進行演出音へ作り直す

## 2. 不要な斬撃状エフェクトを削除

スクリーンショット下側赤丸の青い葉・斬撃・風刃状エフェクトは不要。

調査対象：

- `GameWorld.updateStageEvents()`内、`gateUnlockTimer`進行中にspawnされる`kind: "wind"`
- クリスタルから根の門へ飛ばしている風エフェクト
- ゲート開放完了時の戦闘用`wind`、`slash`、`windBlade`、大きすぎる`ring`

要件：

- 根の解除演出で戦闘用の斬撃・風刃を使わない
- カイル、ナディ、メルの攻撃エフェクト定義自体は変更しない
- 根の前へ巨大な青い葉形シルエットを出さない
- クリスタル側は小さな発光粒子と控えめな同心円のみ可
- 根側は土埃、小さな葉、木片、根元の揺れのみ可
- 大きな円形衝撃波を使う場合も、攻撃判定のように見えない低輝度・短時間にする
- ランドマーク演出専用effect kindを新設してもよいが、今回だけの過剰なeffect system再設計は不要

## 3. `＋`マークを全マップから削除

スクリーンショット上側赤丸のシアン色の十字は削除する。根のゲートだけでなく、ユーザーが「他のところにもあった」と指摘しているため全ステージを確認する。

重点調査：

- `MossRootRuinsRenderer.ts`で縦線と横線を交差させて描く装飾
- ルート目印、門の脈、根タイル、void装飾、晶石粒子
- `LightwingCrystalCavernRenderer.ts`
- `TransferChamberRenderer.ts`
- QA/debug markerが通常プレイへ漏れていないか

特に`MossRootRuinsRenderer.ts`付近の、同じ座標へ縦6px・横6pxを描く処理を確認する。

要件：

- シアン・緑・白の明確な`＋`シルエットを通常マップから削除
- 必要な光粒子は1〜2pxの点、短い斜線、菱形、小さな欠け形へ置換可
- HP回復、照準、操作対象を示す正式なUIアイコンまで一律削除しない
- 今回削除するのは背景・ゲート・地形装飾として出ている意味不明な十字
- DEV/QAマーカーが通常URLへ出ないことも確認

## 4. 音の問題を診断してから修正

現在コード上には長い`rootGateOpen`等が定義されているが、実プレイでは「ピコン」の一瞬しか聞こえない。単にgainを上げる前に、次を確認する。

- 実際に`rootGateOpen` cueが再生されているか
- 同時に鳴る`crystalActivate`だけが聞こえていないか
- 音声イベントの位置減衰で低音が実質無音になっていないか
- `maxVoices`、`minInterval`、AudioContext unlockの影響
- 合成音のdelay付きtone/noiseがSfxSynthesizerで最後までscheduleされているか
- cue durationの途中でvoice cleanup／gain node停止が起きていないか
- 会話停止や遷移で音が即時破棄されていないか
- Mac/ブラウザの小音量スピーカーで100Hz以下が消えていないか

SFX soundboardと通常イベントの両方で同じ音が最後まで鳴ることを確認する。

## 5. クリスタル起動音の再構築

短いUIの`ピコン`ではなく、古代の大きな結晶へ魔力が満ちる音にする。

### 音像

- 全長1.2〜1.8秒
- 最初に透明な接触音
- 中盤に低中域の魔力充填音
- 3〜5個の高い倍音が順に上昇
- 最後に余韻のある共鳴音
- キラキラだけで軽くせず、大きな晶石の質量感を加える

### 実装

- 440〜1400Hzの可聴域を中心にし、Macスピーカーでも聞こえる
- 低音補強は160〜280Hz程度にも置く
- UI busの短い通知音ではなく、進行演出用busまたは減衰の弱いimpact/ambient系
- クリスタル操作直後から発光演出と同期
- 根が動く場合は、晶石音の後半から根音へ自然につなぐ
- 主晶石、副晶石にも同系統を使える

## 6. 根の開放音の再構築

一瞬の音ではなく、実際に根が軋みながらほどける音にする。

### 音像

- 全長2.0〜3.0秒
- `ゴ……ゴゴ……ギギギ……ズン`の流れ
- 180〜350Hzの低中音を主成分にする
- 木が軋む帯域、石床を擦るnoise、最後の低い停止音
- 爆発や必殺技にはしない
- 根の描画アニメーションも音に合わせて2秒前後へ延長

### タイミング

1. クリスタル接触音
2. 0.5〜0.8秒後から根の軋み開始
3. 根が徐々に左右へ退く
4. 開口が完成した瞬間に低い`ズン`
5. 結果会話を表示

- `rootGateOpen`をクリスタル操作直後に同時発火して終わらせない
- 根の移動開始タイミングで発火
- 根の音と開放アニメーション完了を一致
- 位置減衰で聞こえなくならないよう、進行イベントは最低gainを保証

## 7. 湖上石段・晶石足場音の再構築

石段1枚ずつが水底または湖上へせり上がる重量を出す。

### 1段ごとの音像

- 全長0.35〜0.55秒
- 160〜320Hzの明瞭な`ドン／ダン`
- 石擦れnoise
- 小さな水しぶきまたは晶石共鳴
- 段が奥へ進むほど少しだけピッチ上昇

### シーケンス

- 1段ごとの間隔：0.45〜0.65秒
- 5段なら全体3秒前後
- `ダン……ダン……ダン……ダン……ダン……キィィン`
- 各段の視覚出現と打音を完全同期
- 同一フレームに複数音をまとめない
- フレーム落ち時は未再生段をキューに残し、後続フレームで順に再生
- 最後の完成音は0.8〜1.2秒の晶石共鳴
- 会話は全段の演出終了後に表示

石段の見た目も一瞬で全部切り替えず、各段が下から数px持ち上がり、光って固定される短い段階表現にする。

## 8. 音量・減衰・ミキシング

- 進行演出音はBGMありでも確実に認識できる
- BGMを一時的に15〜25%程度duckしてもよい
- duckはクリスタル・根・足場演出中だけで、終了後滑らかに戻す
- 効果音マスター設定とミュートには従う
- 攻撃大技より極端に大きくしない
- 低音だけに頼らず、MacBook等の小型スピーカーで聞こえる中域を含める
- カメラ外の仕掛けでも、重要進行音は最低音量を保証
- 同じ演出の多重発火を禁止

## 9. 会話との同期

固定会話を維持する。

推奨進行：

```text
クリスタルを調べる
→ 説明会話
→ 決定入力
→ 会話を閉じる
→ クリスタル起動音＋発光
→ 根または石段の長い演出＋専用音
→ 演出完了
→ 結果会話
→ 決定入力で探索再開
```

会話中に演出timerが進まず、音だけ終わる状態を作らない。

## 11. 自動テスト

1. 根の解除中に`wind`、`slash`、`windBlade`をspawnしない
2. 攻撃時の既存wind/slashは維持される
3. 通常マップ背景に十字型装飾を描く対象コードが残らない
4. DEV/QA markerが通常起動へ漏れない
5. crystal cueが1秒以上scheduleされる
6. root cueが2秒以上scheduleされる
7. root cueが根の移動開始時に1度だけ発火
8. 根のアニメーション完了が音の完了より極端に早くない
9. 足場1段ごとにrise eventが1回
10. rise event間隔が最低0.4秒
11. 同一フレームにrise eventが複数発火しない
12. 最終段後だけcomplete eventが1回
13. 会話中に演出stepを消費しない
14. SFX mute時は全演出音が鳴らない
15. BGM duckが演出終了後に戻る
16. 第1層、第2層、会話、遷移、戦闘、アリーナの既存テストが成功

## 12. 視覚・実音QA

1. スクリーンショットの青い葉／斬撃エフェクトが出ない
2. 根のゲート上の`＋`が消える
3. 他の地形にも意味不明な`＋`が残っていない
4. クリスタルが1秒以上かけて共鳴する音を明確に認識できる
5. 根が2秒程度かけて軋み、最後に止まる音が聞こえる
6. 石段が1段ずつ`ダン`と分離して聞こえる
7. 視覚変化と各音が同期する
8. BGMありでも聞こえる
9. Macの内蔵スピーカー相当でも低音が消えず、演出を認識できる
10. 演出が必殺技や戦闘開始に見えない

## 14. 実装順序

1. 赤丸のエフェクト発生箇所を特定し、ランドマーク経路から削除
2. 十字装飾の描画箇所を全Rendererから検索して削除／置換
3. 通常イベントでどのSFX cueが実際に聞こえているか計測・確認
4. SfxSynthesizerがdelay付き音を最後まで再生するか修正
5. crystal SFXと演出を再構築
6. root SFX、根アニメーション、タイミングを再構築
7. platform SFX、段階描画、キュー処理を再構築
8. 必要なら短いBGM duckを追加
9. 自動テスト・QA更新
10. `npm run typecheck`
11. `npm test`
12. `npm run build`
13. BGMあり、内蔵スピーカー想定で実音QA
