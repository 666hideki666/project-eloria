# Codex向け追加指示：メル通常攻撃「燐光弾」モーションを導入

Project Eloriaへ、メルの通常攻撃「燐光弾」の4方向攻撃アニメーションを導入してください。

カイルの連刃剣とナディの月輪投げで追加済みの共通行動種別、攻撃シート読み込み、非ループ再生、攻撃開始時のリスタート処理を再利用してください。メルだけ別方式にしないでください。

## 使用ファイル

- 攻撃シート：`assets/sprites/characters/mel/attacks/mel-normal-phosphor-bolt-48px-v1.png`
- メタデータ：`assets/sprites/characters/mel/attacks/mel-normal-phosphor-bolt-48px-v1.json`
- 待機・歩行シート：`assets/sprites/characters/mel/mel-idle-walk-48px-v1.png`

攻撃シート仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透明背景
- 1行目：下向き
- 2行目：上向き
- 3行目：左向き
- 4行目：右向き
- 各行6コマ：構え、短い集中、杖を引く、発射、反動、復帰
- 非ループ
- 合計0.18秒
- 基準点：足元中央

ファイル名と制作資料では`mel`、ゲーム内部の`CharacterId`では既存どおり`meru`を使用しています。内部IDを変更しないでください。

## 設定への追加

`characterSpriteConfig.ts`で、カイルとナディの`normal`アクションと同じ構造を使用してメルの通常攻撃を登録してください。

- PNGとJSONをURL／メタデータとして読み込む。
- `MERU_SPRITE`の`actions.normal`へ登録する。
- 既存の`CharacterActionKind`、`actionKind`、`actionSequenceId`を再利用する。
- キャラクター固有の分岐をレンダラーへ増やさず、設定駆動で処理する。

## アニメーション再生

- メルかつ`actionKind === normal`の間だけ燐光弾シートを使用する。
- 攻撃開始時の方向を6コマの間固定する。
- 上下左右の画像をそのまま使い、左右反転しない。
- 各攻撃開始時に必ず1コマ目から再生する。
- ボタン長押しで次の通常攻撃が成立した場合、新しい攻撃ごとに再スタートする。
- 終了後は最後の方向の待機または移動へ戻る。
- 後方AIの通常攻撃でも同じモーションを再生する。
- ポーズ、タブ非表示、ゲームオーバー中にアニメーション時間が飛ばないようにする。

フレーム時間の合計は現在の通常攻撃`actionDuration`と同じ0.18秒です。基本攻撃なので長い詠唱や操作停止を追加しないでください。

## 杖と燐光弾

- 杖は全24コマの画像内に1本ずつ含まれている。
- 杖を別画像として追加描画しない。
- 既存の`phosphor`投射物はゲーム側で描画する。
- 魔法弾をキャラクタースプライトへ焼き込まない。
- 現在の投射物速度122、半径4、寿命1.25秒、ダメージ13を変更しない。
- 通常攻撃でMPを消費させない。
- 後方AI時の攻撃力半減を維持する。
- 投射物の生成位置、命中判定、効果音を維持する。
- 現段階では投射物生成を遅延させず、入力への即応性を優先する。
- 発射姿勢へ約0.035秒で到達するため、投射物が杖先から出たように見えるか実画面で確認する。

将来エフェクトを作り込む際は、杖先の淡い青緑色の収束光と発射後の小さな燐光粒をゲーム側へ追加できます。今回は追加しなくて構いません。

## 描画

- メルの待機・歩行と同じdrawScale、足元アンカー、方向別Y補正を使用する。
- 攻撃開始・終了時に身体が拡大、縮小、上下移動して見えないようにする。
- 長い杖がセル境界で欠けたり、隣フレームの杖が混ざったりしないこと。
- nearest-neighbor描画を使用する。
- 通常時の水色足元リングを復活させない。
- 接地影、操作中マーカー、HUD強調を維持する。

## 回復と後方AI

- 癒しの環と自動回復では燐光弾シートを再生しない。
- 自動回復、MP消費、回復量、回復エフェクト、効果音を変更しない。
- 後方AIのメルが通常攻撃した場合は燐光弾モーションを再生する。
- 攻撃後は最も遠い陣形位置へ戻る。

## 変更しないもの

- カイルとナディの全スプライト
- メルの待機・歩行スプライト
- 癒しの環、天晶崩落、瞬光障壁
- 攻撃力、クールダウン、投射物性能、MP
- 敵AI、陣形、当たり判定、ゲームバランス
- HUDポートレート
- BGMと効果音

## 完了条件

- メルの通常攻撃時だけ燐光弾の6コマが再生される。
- 上下左右すべて正しい向きで再生される。
- 発射途中で方向が変わらない。
- 全コマで杖が1本だけ表示される。
- 杖先から燐光弾が発射されたように見える。
- 攻撃開始時の反応が遅く感じられない。
- 足元位置と身体サイズが待機・歩行時から変わって見えない。
- 後方AIの通常攻撃でも再生される。
- 癒しの環、自動回復、天晶崩落で燐光弾シートが誤再生されない。
- カイル、ナディ、敵、HUDへ意図しない変更がない。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。
- 既存テストが通り、メルの通常攻撃状態に必要なテストが追加されている。

実装後は、上下左右、移動直後、ボタン長押し、後方AIで燐光弾を確認してください。採用した設定追加方法、杖先と投射物の同期、方向別の足元位置、杖の欠けや二重表示、自動回復への影響を日本語で報告してください。
