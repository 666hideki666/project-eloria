# Codex向け追加指示：ナディ交代攻撃「輪光掃」モーションを導入

Project Eloriaへ、ナディの交代攻撃「輪光掃」の4方向アニメーションを導入してください。

通常攻撃・特殊技・大技・カイルの交代攻撃で追加済みの共通アクションスプライト読み込み、方向固定、非ループ再生、終了後の待機・歩行復帰処理を再利用してください。ナディの交代攻撃だけ別方式のアニメーション管理にしないでください。

今回は表示モーションだけを追加します。交代順、交代地点、陣形再構築、攻撃判定、ダメージ、ノックバック、交代クールダウン、効果音、半円状の光刃エフェクトは変更しないでください。

## 使用素材

- 画像：`assets/sprites/characters/nadi/attacks/nadi-switch-rinko-so-48px-v1.png`
- 設定：`assets/sprites/characters/nadi/attacks/nadi-switch-rinko-so-48px-v1.json`

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- ループなし
- 再生時間：0.35秒

方向行：

- 0行目：下向き
- 1行目：上向き
- 2行目：左向き
- 3行目：右向き

各行は左から次の6コマです。

1. 月輪刃を持った低い交代構え
2. 月輪刃を身体の片側へ引く
3. 前方を横切るように払い始める
4. 反対側へ最大まで伸ばす広い半円斬り
5. 月輪刃を手に残した低い残心
6. 安定した構えへ戻る

ナディは6コマの間、開始時の方向を維持します。全身を一回転する「円月旋」ではありません。また、月輪刃は全コマで手に持っており、「月輪投げ」のように投擲しません。

物理的な月輪刃は全コマの画像へ1枚ずつ含まれています。別描画の手持ち武器を重ねず、飛行する月輪刃projectileも生成しないでください。半円状の光刃、円形軌跡、命中光などは画像へ含まれていないため、既存のゲーム側エフェクトを維持してください。

## 1. アクションスプライト登録

既存の`characterSpriteConfig.ts`へ、他の技と同じ構造で画像とJSONを読み込み、`NADI_SPRITE.actions.switch`として登録してください。

設定値：

- フレームサイズ：48×48px
- 列数：6
- 方向別行：down 0 / up 1 / left 2 / right 3
- 足元アンカー：`x: 0.5`, `y: 0.92`
- ループ：なし
- 総再生時間：0.35秒
- コマ時間：`[0.045, 0.05, 0.06, 0.075, 0.065, 0.055]`
- 斬撃中の見た目：2、3番コマ
- 視覚的な最大振り抜き：3番コマ

画像補間は無効にし、既存キャラクターと同じnearest-neighbor描画を使用してください。

## 2. ナディへの交代時だけ再生

現在の`switchCharacter()`で次の操作キャラクターがナディになり、`performSwitchAttack(incoming)`が呼ばれた場合、この輪光掃シートを再生してください。

既存の

```ts
this.beginCharacterAction(member, "switch", 0.35);
```

をそのまま共通アクション開始として利用してください。

- 交代成立時のナディの`actionFacing`から方向行を選ぶ。
- 0.35秒の間、選択した同じ行を使用する。
- キャラクター画像をコードで回転・左右反転しない。
- 中間コマでも全身の向きを別方向へ切り替えない。
- 6コマを1回再生し、終了後は待機・歩行へ戻す。
- 同じ技を再発動したときは0番コマから再スタートする。
- カイルやメルへ交代した場合、ナディのシートを再生しない。

## 3. 交代位置と陣形を維持

スプライト内には足運びと腰の回転が含まれていますが、ワールド座標上の移動ではありません。

- ナディを現在の後方位置から別地点へ瞬間移動させない。
- ナディへ追加速度やダッシュ距離を与えない。
- 交代直前の`incoming.pos`を維持する。
- 交代後の`followerState`、`followerTargetId`を変更しない。
- 送り出したキャラクターの`return`状態を変更しない。
- `formationRebuildTimer`と既存の陣形再構築を維持する。

## 4. 既存の攻撃判定を維持

現在の輪光掃仕様をそのまま維持してください。

- 判定位置：ナディ前方15px
- 攻撃半径：44
- 攻撃角度：`Math.PI * 1.08`
- ダメージ：24
- ノックバック：28
- 判定色：`#b4f8f3`
- 交代クールダウン：現在の`COMBAT.switchCooldown`、0.48秒
- バナー：`交代｜輪光掃`
- 既存の交代音とナディの交代攻撃音を使用

現在の攻撃判定は交代成立時に即座に生成されます。3番コマまで判定を遅らせたり、2〜3番コマで判定を複数回生成したりしないでください。

JSONの`activeFrames`は見た目上の斬撃区間であり、追加の攻撃判定イベントではありません。

## 5. 既存の半円斬撃エフェクトを維持

現在の`slash`エフェクトを維持してください。

- 位置：ナディ前方15pxの判定位置
- 寿命：0.3秒
- サイズ：48
- 色：`#c6ffff`
- 回転：ナディの向きに合わせる

スプライトには半円状の光刃が含まれていません。既存エフェクトを削除せず、2〜3番コマへ自然に重ねてください。

月輪投げ用の飛翔projectileや、円月旋用の全周リングを追加しないでください。輪光掃は前方約194度を払う交代攻撃として表示します。

## 6. 状態の優先順位

描画アクションの優先順位は既存の共通ルールを使用してください。

1. 戦闘不能
2. 交代攻撃を含む行動中
3. 移動
4. 待機

少なくとも次を保証してください。

- 輪光掃中に月輪投げ、円月旋、月蝕乱舞のシートを再生しない。
- 通常攻撃、特殊技、大技で輪光掃シートを誤再生しない。
- 戦闘不能時は交代攻撃より戦闘不能表示を優先する。
- 交代直後の陣形移動で、モーションが即座に歩行へ上書きされない。
- 0.35秒後に行動状態が正常に解除される。

## 7. 変更しないもの

- カイルとメルの全スプライト
- ナディの待機・歩行、月輪投げ、円月旋、月蝕乱舞
- 交代順と交代可能条件
- 輪光掃の攻撃判定・数値・エフェクト
- パーティー陣形と追従AI
- 敵AI、当たり判定、ダメージ計算
- HUD、回復、経験値、BGM、効果音

## 8. テスト

既存テストを維持し、可能なら次の確認を追加してください。

- ナディの`switch`画像とJSONが正常に読み込まれる。
- ナディへ交代した場合だけ輪光掃シートを使用する。
- 開始方向に対応する正しい行を使用する。
- 0.35秒で6コマを1回だけ再生する。
- 全24コマで物理的な月輪刃が1枚だけ表示される。
- 攻撃判定が交代成立時に1回だけ生成される。
- 前方15px、半径44、角度`Math.PI * 1.08`が変わっていない。
- ダメージ24、ノックバック28が変わっていない。
- 交代クールダウン0.48秒が変わっていない。
- ナディのワールド座標へ追加移動がない。
- カイルとメルへの交代ではナディのシートを再生しない。
- 行動終了後に待機・歩行へ正常に戻る。

最後に`npm test`と`npm run build`を実行し、既存機能に回帰がないことを確認してください。

- ナディへ交代した瞬間、4方向すべてで前方を広く払う。
- 全身回転の円月旋や投擲の月輪投げとは異なる、半円状の一撃に見える。
- 月輪刃を手放さず、全コマで物理的な刃が1枚だけ表示される。
- ナディが交代位置から瞬間移動せず、陣形が壊れない。
- 既存の淡い半円斬撃エフェクトがモーションへ自然に重なる。
- 輪光掃の攻撃判定、ダメージ、ノックバック、交代クールダウンが変更されていない。
- 他キャラクター、通常攻撃、特殊技、大技へ意図しない変更がない。
