# Codex向け修正指示：層間接続・遷移時再出現・演出効果音 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：既存実装の問題箇所が特定できており、マップ入口、遷移タイミング、音響設定を限定的に直す修正だから。

## 1. 目的

次の3点を修正する。

1. 根の門の「ゴゴゴゴ」と晶石足場の「ダン、ダン、ダン」が聞き取れない
2. 第1層では上へ進むのに、第2層から戻る時だけ左へ進む接続方向の矛盾
3. 第1層から第2層へ切り替わる暗転前に、撃破済みモスプルンが画面内へ復活する

## 2. 第1層と第2層の方向を統一

接続関係を次に統一する。

```text
第1層の北端（上）から進む
        ↓ 層移動
第2層の南端（下）から入る

第2層の南端（下）へ戻る
        ↓ 層移動
第1層の北端（上）へ戻る
```

ゲーム内の地理として「奥へ進むほど上」「前の層へ戻る時は下」と理解できるようにする。

### 第2層入口の変更

- 現在の左端入口と左向き境界判定を廃止
- 第2層の開始地点を南端寄りへ移す
- 第1層から来た時は、南端入口の少し内側に出現
- プレイヤーは上向きで出現
- 到着直後にカメラが黒いvoidばかり映さないよう、入口周辺へ十分な床を作る
- 南端へ向かって歩くと第1層へ戻る
- 戻るための境界判定は`input.move.y > 0.15`と下端座標を基準にする
- 左端は通常の洞窟壁または景観にし、層間出口として扱わない

### 戻り口の視認性

スクリーンショットでは第2層の戻り口が分からないため、入口そのものを明確なランドマークにする。

- 南端中央寄りに幅128〜160pxの石造アーチ
- 第1層の苔色と第2層の青色が混ざる境界表現
- 床へ下方向を示す淡い晶石ラインまたは足跡状の光
- 小さな下り階段、洞窟口、または門柱で「ここから来た」と分かる形
- 通常時に文字を常時表示しない
- 初回到着時だけ固定会話で`後ろの道を戻れば、第1層へ引き返せそうだ。`
- 入口へ近づいた時は必要なら`第1層へ戻る道`という短い不透明ラベルを安定表示するが、操作ボタンは不要
- 歩いて南端を越えると自動遷移

### 第2層主ルート

入口を南端へ移しても、第2層の横長探索という特徴は維持する。

- 南端入口から少し北へ進み、既存のA到着広場へ合流
- そこから右・上方向へ折れながら既存ルートを進む
- 新入口からルミバネ初戦まで、敵のいない導入距離を確保
- 水、壁、voidの衝突と描画を一致させる
- 入口変更で既存の主晶石、副晶石、回復晶泉、湖上足場、最終広場の座標関係を壊さない

## 3. 遷移開始時に敵を復活させない

現状は`beginRoomTransition()`が暗転開始前に`prepareCurrentLayerForDeparture()`を呼び、その中で全遭遇を即resetしている。このため、画面が第1層のままなのにモスプルンが復活して見える。

修正方針：

- 遷移開始時に移動元の敵オブジェクトを復活・再配置しない
- 暗転中も移動元の撃破状態の見た目を維持
- 移動元レイヤーの再出現予約だけを記録
- 完全に遷移先へ切り替わった後、移動元レイヤーを次回入場用にリセット
- リセット対象が現在描画中の`this.enemies`へ反映されないようにする

推奨概念：

```ts
private pendingRespawnLayer: "mossRootRuins" | "lightwingCrystalCavern" | null;
```

または層別の遭遇状態を現在のentity配列と分離する。

手順：

1. 境界遷移開始
2. 移動元の層IDを再出現予約へ保存
3. 戦闘、一時弾、エフェクト、案内だけ停止／消去
4. 画面暗転
5. 遷移先roomとentity配列へ切替
6. カメラとプレイヤー位置を確定
7. 画面が移動元を描画しなくなった後で、移動元遭遇状態を次回用に初期化
8. フェードイン

要件：

- 第1層最後のモスプルンは暗転完了まで復活して見えない
- 第2層から第1層へ戻る時も同じ
- 戻った時には通常敵がホーム位置へ復活済み
- 開放済みの根、石碑、晶石、足場、門は維持
- 再出現した敵は再び経験値を与える
- 遷移直前に倒した敵の死亡エフェクトが不自然に敵復活へ切り替わらない
- `prepareCurrentLayerForDeparture()`という名称と処理が実態に合わない場合、予約処理と実リセット処理へ分割する

## 4. 根の門の効果音を明瞭化

現在の`rootGateOpen`は短い単発低音で、位置減衰やBGMに埋もれて聞こえにくい。プレイヤーが「根が動いている」と確実に分かる音へ修正する。

### 音の方向性

- 全長1.2〜1.8秒
- 低い連続振動を3〜5回脈打たせる
- `ゴ…ゴ…ゴゴゴ…`という重量感
- 低いtriangle/saw系に、木・石が擦れるlow-pass noiseを重ねる
- 最後に低い着地・停止音を置く
- 攻撃の爆発音にはしない
- BGM再生中でも聞き取れるが、音割れしない

### 再生方式

- 重要な進行演出なので、通常の敵位置SFXほど強く距離減衰させない
- UI busにする必要はないが、カメラ中心から離れていても最低音量を保証
- 根が画面内にある場合、現在より明確に大きくする
- `rootGateOpen`を演出開始時に一度だけ発火
- root animationの長さと音の長さを合わせる
- 根の門以外のショートカット開放にも同音を使う場合、必要に応じて短いvariantを用意

聞き分け確認のため、開発用SFX soundboardがあるなら新設定をそこで単独再生できるよう維持する。

## 5. 晶石足場の効果音を明瞭化

現在の`crystalPlatformRise`は約0.1秒の小さな音で、5回鳴っていても一つの弱いノイズに聞こえる可能性がある。

### 音の方向性

- 足場1枚につき0.18〜0.28秒
- 低中域の明確な`ダン`という打音
- 石が水底からせり上がり固定される質感
- 低い打撃＋短い石擦れnoise
- 各打音のピッチをわずかに上昇
- 最後は高い晶石の完了音を重ねる

### タイミング

- 各足場の視覚出現と完全同期
- 打音間隔を最低0.22〜0.35秒空ける
- 5枚なら`ダン、ダン、ダン、ダン、ダン……キィン`と明確に分離
- 同一フレームのwhileで複数音が発火しないようにする
- フレーム落ち時も複数音を一度にまとめず、未再生stepを次フレーム以降へ順番に送る
- 演出時間を現在の0.8秒から必要なら1.4〜2.0秒へ延長
- 重要会話中にゲーム更新を止める場合、会話を閉じてから足場演出と音を開始
- 演出完了後に結果会話を出す

### 距離減衰

- 足場群が画面中央から離れていても進行演出として聞き取れる最低音量を保証
- 左右定位は軽く付けてもよいが、一方のスピーカーへ極端に寄せない
- 既存SFXミュート設定には従う

## 6. 効果音のQA補助

ユーザーが通常プレイで聞き逃さず確認できるようにする。

- root gate QAでは、クリスタル操作後に根の音まで確実に進む状態を用意
- platform QAでは、副晶石操作直前または演出開始直前から確認可能にする
- SFX soundboardがDEV限定で存在する場合、`根の門開放`、`晶石足場出現`、`晶石足場完成`を個別再生可能にする
- BGMあり／なしの両方で聞き取れるか確認
- ブラウザの初回音声許可後に鳴ることを確認

## 11. 実装順序

1. 第2層入口を南端へ変更し、地形・衝突・spawnを調整
2. 境界遷移を北↔南方向に統一
3. 遷移開始時resetを予約方式へ変更
4. 遷移完了後resetへ変更
5. root SFXの音色、長さ、音量、減衰を改善
6. platform SFXと演出stepの間隔を改善
7. QAと自動テスト更新
8. `npm run typecheck`
9. `npm test`
10. `npm run build`
11. BGMありの実音QAと境界往復QA
