# Codex向け追加指示：通常戦闘BGMの実装

Project Eloriaの現在の試作版へ、ユーザーが作成した通常戦闘BGMを実装してください。

## 使用する正式音源

- 曲名：晶界を駆ける
- ファイル：`assets/audio/music/battle-crystal-realm-v1.mp3`
- 形式：MP3 / Stereo / 48kHz
- 長さ：約189.44秒

音源ファイルは確認済みで、最後までデコードできる正常なMP3です。

既存音源を編集、上書き、削除しないでください。現在のゲームコードとビルド構成を確認し、既存構成に合う方法で参照してください。ビルド上必要な場合は公開用フォルダへ非破壊でコピーして構いませんが、原本は必ず残してください。

## 基本動作

- ゲームの戦闘アリーナ開始時に「晶界を駆ける」を再生する。
- 曲の最後まで到達したらループ再生する。
- 通常攻撃、特殊技、大技、キャラクター交代、敵撃破のたびにBGMを再起動しない。
- 同じBGMが複数重なって再生されないよう、音楽再生を一元管理する。
- 開発中の再レンダーや画面更新でAudio要素、AudioBuffer、イベントリスナーが増殖しないようにする。
- ゲームオーバー時は0.4〜0.8秒程度でフェードアウトする。
- 再挑戦時は戦闘開始に合わせてフェードインする。
- ポーズ中はBGMを停止または大きく減音し、解除後に同じ再生位置から戻す。
- ブラウザタブが非表示になった場合は一時停止し、表示へ戻った場合は、非表示前に再生中だったときだけ再開する。

## ブラウザの自動再生制限

ブラウザはユーザー操作前の音声再生を拒否するため、エラーを無視して自動再生を試し続けないでください。

- 最初のクリック、キー入力、ゲーム開始操作など、明確なユーザージェスチャー後に音声システムを有効化する。
- 初回ジェスチャーが移動キーだった場合でも、ゲーム操作を邪魔せずBGMを開始できるようにする。
- 再生が拒否された場合はクラッシュさせず、次のユーザージェスチャーで再試行する。
- 音声開始前は、必要なら小さな「音声を有効にする」案内を表示する。
- 一度有効化したあと、攻撃キーを押すたびに`play()`を呼ばない。

## 音量

- BGM初期音量は最大音量の35〜45%程度にする。
- 今後追加する効果音がBGMに埋もれない余裕を残す。
- ポーズメニューへBGM音量スライダーとミュート切り替えを追加する。
- `M`キーでもBGMをミュート／解除できるようにする。
- 音量とミュート設定は`localStorage`へ保存し、次回起動時に復元する。
- `localStorage`が利用できない場合でもゲームを止めない。
- 音量変更時にクリック音など不要な音を追加しない。

## UI

- 現在のHUDを大きく崩さない。
- 画面右上またはポーズ画面へ、小さなスピーカーアイコンを置く。
- ミュート中はスピーカーに斜線を付けるなど、文字がなくても状態が分かるようにする。
- キーボード操作中は必要に応じて`M`の表示を添える。
- 音声UIが攻撃ボタン、HP表示、敵の予兆を隠さないようにする。

## 実装構造

音楽再生をゲームロジックへ直接散在させず、`AudioManager`、`MusicManager`などの単一責務の仕組みへまとめてください。

最低限、次の操作を一元的に扱えるようにします。

- 音声システムの初期化
- ユーザージェスチャー後の有効化
- BGM再生
- BGM停止
- 一時停止と再開
- フェードインとフェードアウト
- ループ
- 音量変更
- ミュート
- 破棄とイベント解除

既存の技術構成に合えば`HTMLAudioElement`を使って構いません。Web Audio APIを使う場合は、AudioContextのresume処理と破棄処理を正しく実装してください。今回の目的は安定した試作であり、必要以上に複雑な音響エンジンを作らないでください。

## ループについて

まずは曲全体をループさせてください。

- `loop`または同等の仕組みを使う。
- ループ境界で明らかな二重再生が起きないことを確認する。
- 曲末の余韻や無音によってループが不自然な場合でも、原本を勝手に切らない。
- ループ位置の編集が必要と判断した場合は、開始秒と終了秒の候補を報告し、ユーザー確認後の別作業にする。

## 効果音への準備

次の作業で通常攻撃、特殊技、大技、命中、交代、敵撃破の効果音を追加する予定です。

- BGMと効果音の音量を別々に管理できる構造にする。
- 現時点では存在しない効果音ファイルを仮作成しない。
- BGMチャンネルとSFXチャンネルを分ける。
- 将来、大技中だけBGMを少し減音できるようにするが、今回は必須にしない。

## 完了条件

- ゲームを開いただけでは自動再生エラーを繰り返さない。
- 最初のユーザー操作後にBGMが1回だけ始まる。
- 3分以上再生し、曲末でループする。
- 攻撃や交代を連打してもBGMが重ならない。
- ポーズと解除で適切に一時停止・再開する。
- ゲームオーバーでフェードアウトし、再挑戦で再生される。
- `M`キーとUIでミュート／解除できる。
- 音量設定がページ再読み込み後も保持される。
- 通常の`npm run dev`とワンクリック起動の両方で音源を読み込める。
- 本番ビルドで音源パスが404にならない。
- 既存の戦闘、敵AI、陣形、操作、攻撃エフェクトを壊していない。

実装後は、音量初期値、音源の参照方法、ループ方法、操作方法、確認結果を日本語で報告してください。
