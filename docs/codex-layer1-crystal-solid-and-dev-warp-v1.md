# 第1層：クリスタルの実体判定と DEV WARP 移設（実装済み）

## ユーザーからの指摘

- クリスタル／石台の上をキャラクターの足元が通過できてしまう。物体としてぶつかるようにする。
- スタート地点右側の開発用 DEV WARP が赤線外にあり、歩いて近づけない。通路内へ移す。
- 参照：`/Users/katouhideki/Desktop/スクリーンショット 2026-09-24 23.16.18.png`。

## 現状の根拠

- `src/stage/maps/mossRootRuinsMap.ts` に `MOSS_ROOT_SOLID_PROPS` の `transferCrystal` があるが、`src/stage/tileCollision.ts` の `isMossRootPositionWalkable` / `resolveMossRootMovement` は `solidProps` を参照しない。赤線内の静的床と根の動的遮断のみを見るため、クリスタル中心を通過できる。
- `tests/stage.test.ts` にはクリスタル中心を歩行可能とする旧期待値、および旧石台通過を肯定するテストがある。障害物を導入するときは旧仕様を明示的に更新する。
- DEV WARP の現座標はワールド `(1170, 1820)`、背景ネイティブ座標でおよそ `(740, 1151)`。該当行の歩行マスクはおよそ x=616〜666 なので赤線外にある。描画と E キー操作は同じ `DEV_LIGHTWING_WARP_POSITION` を参照している。

## 実装案

1. 赤線から作った**静的床マスクを変更しない**。クリスタルを、その上に載る常設の物体コライダーとして扱う。第1層の唯一の仕掛けは引き続き「クリスタルで北の根を解除する」だけ。追加パズルや石碑は作らない。
2. プレイヤー・仲間・敵の移動では、従来どおり足元の接地点一点を床判定に使う。その点がクリスタル／石台の**地面に接する楕円形の範囲**に入るときだけ通行不可にする。キャラ全身の幅を床や通路の判定に戻さない。クリスタルの上に見える高い結晶部分全体を巨大な障害物にはせず、石台の見た目と足元に合わせる。必要なら現行の `MOSS_ROOT_SOLID_PROPS.transferCrystal` を地面側へ調整する（出発目安：背景座標中心 `(1160, 535)`、半径 `23×14` 画像 px）。確定サイズはゲーム画面と当たり判定オーバーレイで合わせる。
3. `isMossRootPositionWalkable` と移動線分の判定が同じ障害物を参照し、歩き・斜め移動・速い移動・押し戻しで石台を抜けないようにする。マスク内の他の床や狭い橋の通行幅は変えない。`westRuinArch` など別の装飾物に、一括で新しい障害物を適用しない。
4. E キーでのクリスタル操作は、石台に隣接する**歩ける位置**から可能なままにする。とくに現在の QA 座標 `crystal-touch`（クリスタル中心から左へ 46 ワールド px）が障害物外かつ操作範囲内かを確認する。解除後も石台は実体を持ち続ける。
5. DEV WARP を、スタートから歩いて届く通路内に移す。候補は背景座標 `(648, 1120)` ≒ワールド `(1024, 1771)`。スタート `(1024, 1840)` の約 69 ワールド px 北側で、近傍の赤線内部 x=617〜661 に収まる。スタートに重ねず、移動後に E の表示・操作範囲（表示 48、操作 44 ワールド px）へ入れるようにする。位置を移すのは定数だけを基本とし、描画・操作・QA 表示を共通座標のまま維持する。DEV 環境限定の表示・第2層へのワープ動作は保つ。

## 受け入れ確認

- キャラクターの足元がクリスタルの石台に重ならない。周囲の赤線内は歩けて、横や手前から E で根を解除できる。解除後も石台を通過できない。
- 細い橋、広場、赤線境界、根の閉鎖／解除は現状どおり。静的マスクのバイナリ差分はゼロ。
- スタートから DEV WARP まで通常移動で到達し、表示・E 操作・第2層ワープが機能する。本番ビルドでは DEV WARP は表示・操作できない。
- 当たり判定の単体テスト、実際の移動を使う正負テスト、クリスタル操作、DEV WARP 到達性と起動のテストを更新する。`npm run typecheck`、`npm test`、`npm run build` を通す。可能ならゲーム画面で当たり判定オーバーレイと通しプレイを確認する。
