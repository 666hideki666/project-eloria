# Codex向け実装指示：探索時の1人表示とBGM自動切り替え

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Ultra`：不要
- 理由：パーティ状態、描画、衝突、交代、音声管理にまたがる中規模の変更だが、新規アーキテクチャは不要なため。

## 目的

現在の「晶界・転送の間」では、探索中も後方の2人が追従するため、壁や門、狭い場所で引っかかりやすい。

探索と戦闘のパーティ表現を分ける。

- 非戦闘の探索中：操作キャラ1人だけを表示・移動・衝突判定の対象にする
- 戦闘中：3人が後方陣形を取って従来どおり戦う
- 探索時：新しい探索BGMを再生する
- 戦闘時：現在のバトルBGMを再生する

今回は転送の間に敵を追加しない。将来の「苔の回廊」で戦闘開始を接続できる状態まで作る。

## 参照音源

- 探索BGM：`assets/audio/music/exploration-forest-crystal-ruins-v1.mp3`
- 曲名：「森晶遺跡の静寂」
- 戦闘BGM：`assets/audio/music/battle-crystal-realm-v1.mp3`
- 曲名：「晶界を駆ける」

音源ファイルの加工、上書き、再エンコードは不要。

## 1. パーティ表示状態

ゲームモードとは別に、現在のパーティ表示状態をスナップショットから判定できるようにする。

```ts
export type PartyPresence = "solo" | "formation";
```

方針：

- `stage`モードで非戦闘の場合は`solo`
- `arena`モードは常に`formation`
- 将来、ステージ内戦闘が始まった場合は`formation`
- `WorldSnapshot`に`partyPresence`を追加する
- ファイル全体に`mode === "stage"`の条件分岐を散乱させない

今回の転送の間は常に`solo`でかまわないが、次の部屋で使えるよう、ステージ戦闘を開始・終了させる小さな状態またはメソッドを`GameWorld`に用意してよい。部屋スクリプトエンジンは作らない。

## 2. 探索中は操作キャラだけ存在させる

`partyPresence === "solo"`の間：

- `Renderer.drawActors()`は`activeId`のキャラだけ描画する
- 他の2人の影、スプライト、エフェクトを描画しない
- `updateFollowers()`を呼ばない
- 他の2人に部屋衝突解決を行わない
- パーティ間分離処理を呼ばない
- 他の2人が実体の当たり判定として操作キャラを押さない
- 他の2人の自動攻撃・自動回復を実行しない

単に透明にするだけではなく、追従AIと衝突自体を停めること。

探索中もパーティデータは保持する。

- HP・MP
- クールダウン
- 戦闘不能状態
- 経験値
- 現在のパーティ編成

ステータスHUDは3人分表示したままにする。「仲間は同行しているが、探索画面では操作キャラだけを表現する」仕様とする。

## 3. 探索中のキャラ交代

`Space`の操作は維持する。

`solo`で交代する場合：

1. 交代前キャラの位置と向きを保存
2. 次の生存キャラを`activeId`にする
3. 交代後キャラを同じ位置と向きへ置く
4. 通常の交代攻撃は出さない
5. 攻撃判定、バリア、ノックバックを生成しない
6. 短い交代音とHUDの操作中表示は維持
7. 必要であれば「カイルへ交代」程度の短いバナーは表示可

クールダウンは現在の交代連打防止値を利用する。

`formation`では現在の戦闘中の交代攻撃を完全に維持する。

## 4. 戦闘開始時の3人展開

将来のステージ戦闘に備え、`solo`から`formation`へ移る処理を作る。

- 操作キャラの位置は動かさない
- 他の2人は操作キャラの後方左右へ展開する
- 展開位置は現在の部屋境界と障害物を考慮する
- 障害物内や壁の外に出さない
- 左右の予定位置が使えない場合は、近い安全候補を小さな固定リストから選ぶ
- 全員の`followerState`を陣形用に初期化
- 不自然な長距離追従を見せない

演出は小さくてよい。今回は新規大型エフェクトを作らず、0.15〜0.25秒の短いフェードまたは小さな光粒を既存EffectPoolで表現してよい。`arena`モードの開始位置は変更しない。

## 5. 戦闘終了時

将来のステージ戦闘終了処理では：

- 戦闘後のHP・MP・戦闘不能処理を完了させる
- 操作中キャラは現在位置を維持
- 他の2人を非描画・非衝突の同行状態へ戻す
- `partyPresence`を`solo`へ戻す
- 探索BGMへ戻す

今回は転送の間に戦闘がないため、開始・終了メソッドの単体テストまででよい。デバッグキーを本番操作に追加しない。

## 6. BGMトラック切り替え

`AudioManager`が1曲のURLだけをコンストラクタで受ける現在の設計を、小さく拡張する。

```ts
export type MusicTrackId = "exploration" | "battle";
```

推奨API：

```ts
audio.setMusicTrack(trackId, url, {
  fadeOut: 0.35,
  fadeIn: 0.55,
  restart: true,
});
```

実際のAPI名は既存コードに合わせて調整可。次の要件を守ること。

- 同じトラックを毎フレーム再設定しない
- 変更時は短いフェードアウト後に`src`を差し替え、再生位置を0にしてフェードイン
- ブラウザの音声アンロック前に切り替えても、最初のユーザー操作後に正しい曲が再生される
- ミュート、音量、SFX音量、一時停止、タブ非表示時の状態を維持
- 既存の単一`HTMLAudioElement`とWeb Audioミキサーを再利用する
- 同時に2曲を鳴らさない
- 新しい外部依存は追加しない

`main.ts`で両方の音源をVite URL importする。

```ts
import explorationMusicUrl from "../assets/audio/music/exploration-forest-crystal-ruins-v1.mp3?url";
import battleMusicUrl from "../assets/audio/music/battle-crystal-realm-v1.mp3?url";
```

トラック選択：

- `partyPresence === "solo"`：`exploration`
- `partyPresence === "formation"`：`battle`
- 通常起動の転送の間：探索曲
- `?mode=arena`：バトル曲
- ポーズ中：現在の曲を一時停止し、再開後は同じ曲の続き

ステージ戦闘へ移る時は、仲間展開とほぼ同時にバトル曲へ移る。戦闘終了後は探索曲を先頭から再生する。曲ごとの再生位置保存は今回不要。

## 7. ポーズ画面の曲名

ポーズ画面の`BGM「晶界を駆ける」`が固定文字列なら、現在のトラックに合わせて切り替える。

- 探索：`BGM「森晶遺跡の静寂」`
- 戦闘：`BGM「晶界を駆ける」`

トラックIDと表示名の小さな定義を1か所に集約し、DOM制御側に曲名判定を重複させない。

## 8. HUDと操作ガイド

- 左のパーティHUDは3人分維持
- 操作中マーカーも維持
- 探索中も`Space 交代`を表示
- 戦闘用のJ/K/L欄は今回非表示にしない
- 将来の特殊能力探索に利用できるため、キー割り当ても変えない

## 9. QAパラメータ

既存のQAを残しつつ、次を追加する。

```text
/?stageQa=transferChamber&autoStartQa=1
/?stageQa=transferChamber&autoStartQa=1&partyQa=formation
/?mode=arena&autoStartQa=1
```

- 通常の転送の間：`partyPresence=solo`
- `partyQa=formation`：ステージ部屋内で3人展開だけを確認する開発専用状態
- アリーナ：`partyPresence=formation`

dataset：

```text
data-party-presence="solo|formation"
data-music-track="exploration|battle"
```

`partyQa`は開発ビルド限定とし、本番のゲーム操作に入れない。

## 10. テスト

最低限、次を追加・更新する。

### 探索パーティ

- 転送の間は`solo`で始まる
- 探索中は後方2人の追従位置更新が走らない
- パーティ間分離で操作キャラが押されない
- 狭い北側で移動しても非操作キャラが壁障害を起こさない
- 交代後のキャラが交代前と同じ位置・向きになる
- 探索交代で攻撃判定が生成されない
- HP・MPが交代で変化しない

### 陣形展開

- `formation`開始後は3人の後方陣形が復帰する
- 操作キャラの位置が飛ばない
- 後方2人が部屋の壁外や中央台座の中へ出ない
- `arena`モードの現在の交代攻撃、陣形、AIが変わらない

### 音楽

- 同一トラック指定で`src`を再設定しない
- 探索状態で探索曲が選ばれる
- 戦闘状態でバトル曲が選ばれる
- トラック変更後もミュートと音量が維持される
- ポーズから戻ると同じ曲の続きが再生される
- 既存の音声アンロック・SFXテスが通る

最後に実行：

```bash
npm test
npm run build
```

## 11. 画面確認

1. 通常起動し、転送の間でカイル1人だけが表示される
2. 北壁、門、中央クリスタル周辺を歩き、非操作キャラに引っかからない
3. `Space`でナディ、メル、カイルの順に同じ位置で入れ替わる
4. 交代攻撃が発生しない
5. 探索BGM「森晶遺跡の静寂」が再生される
6. `partyQa=formation`で他の2人が安全な後方位置へ展開する
7. `?mode=arena`で従来どおり3人が陣形を取り、バトルBGMが再生される

可能なら通常転送の間、陣形QA、アリーナの3枚の確認スクリーンショットを`docs/screenshots/`へ保存する。

## 完了条件

- 転送の間で操作キャラ1人だけが表示される
- 非操作キャラの追従・衝突・自動行動が探索を妨げない
- 探索中の交代は同一位置で行われ、交代攻撃を出さない
- 戦闘状態に入ると3人陣形に復帰できる
- 探索中は探索BGM、戦闘中は戦闘BGMが再生される
- ポーズ、ミュート、音量設定、SFXが壊れていない
- 既存のアリーナ戦闘、キャラクタースプライト、攻撃、敵AI、QAが変わらない
- `npm test`と`npm run build`が成功する
