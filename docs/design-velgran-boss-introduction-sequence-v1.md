# Project Eloria ヴェルグラン戦・登場演出設計 v1

## 1. 目的

ボス部屋への入場から、森晶獣ヴェルグランの覚醒、戦闘開始までを短く印象的に見せる。

第1ボスのため長い会話は入れず、「悪意ある怪物」ではなく「侵入者を試す聖なる守護者」として描く。

この文書は演出設計であり、実装指示書ではない。

## 2. 基準絵コンテ

- `assets/concepts/environments/crystal-dungeon-01/velgran-boss-introduction-storyboard-v1.png`
- 6コマを左上から右下へ読む
- ボス部屋：800 × 560
- 表示範囲：640 × 360
- 初回演出時間：約6.5〜7.5秒
- 再戦時短縮演出：約1.5秒

## 3. 初回入場シーケンス

### 0. 通常入場

- プレイヤー操作可能
- 表示キャラクターは現在の操作キャラクター1人だけ
- 探索BGMを通常音量で再生
- ボスは北祭壇で休眠状態
- ボスHP表示はまだ出さない

### 1. 演出開始：0.0〜0.5秒

- プレイヤーが南側の到着前庭、目安 `y = 440` を越えると開始
- 移動入力だけ一時停止する
- 攻撃・特殊技・大技・交代入力も停止する
- 探索BGMを0.5秒かけて約20%まで下げる
- 足音を止め、低い洞窟環境音を残す
- 操作キャラクターを安全な床の `(400, 420)` 付近へ補正する

### 2. 3人陣形：0.5〜1.1秒

- ナディとメルを後方左右へ表示する
- 操作キャラクター：前中央
- ナディ：後方左
- メル：後方右
- 壁・根・結晶柱との衝突を確認してから配置する
- 3人が北を向き、短く身構える
- 入口は開いたまま映す

### 3. 祭壇へのカメラ移動：1.1〜2.0秒

- カメラを北祭壇へ滑らかに移動する
- 3人は画面下端へ小さく残してもよい
- ヴェルグランは丸まって休眠している
- 探索BGMを完全に止める
- 0.2〜0.3秒だけ静寂を作る

### 4. コア点灯：2.0〜3.0秒

- 胸部コアが弱い青緑色から徐々に明るくなる
- 両目がコアより少し遅れて点灯する
- 祭壇の細い光脈が中心から外へ走る
- 根がわずかに動き、小石が浮く
- 画面全体を覆う大爆発エフェクトは使わない
- 効果音：低い鼓動1回 → 結晶の共鳴音

### 5. 起き上がり：3.0〜4.5秒

- 既存の覚醒ボディ6フレームを順番に再生する
- 石装甲が擦れる低い音を同期させる
- 前脚が着地する瞬間に弱い画面揺れを1回入れる
- 揺れは短く、UIや画面端が大きく動かない強さにする
- 胸部コアを画面内で最も明るい部分にする

### 6. 咆哮と名前表示：4.5〜5.8秒

- ヴェルグランが顔を上げて短く咆哮する
- 根先、小石、青緑の光粒が外側へ広がる
- ボスの姿を隠さない密度にする
- 画面中央または上部へ `森晶獣ヴェルグラン` を短く表示する
- 名前はタイプ表示にせず、一度に表示して約1.0秒で消す
- 効果音：低く重い咆哮＋短い結晶残響

### 7. 戦闘開始：5.8〜7.0秒

- カメラを操作キャラクター中心の戦闘位置へ戻す
- ヴェルグラン：北側
- 操作キャラクター：南側前中央
- ナディ：後方左
- メル：後方右
- ボスHPを表示する
- ボスBGMを頭から開始する
- 入力を戻す
- 入力復帰直後0.5秒はヴェルグランに攻撃させない

## 4. 表示文

登場時に長い説明文や会話は入れない。

ボス名のみ表示する。

> 森晶獣ヴェルグラン

守護者の性格は戦闘後の鎮静演出と封印石出現で伝える。

## 5. 音響設計

### BGM

- 入場：探索BGM
- 演出開始：0.5秒フェードダウン
- 祭壇表示：短い静寂
- 咆哮終了後：ボスBGM開始
- 戦闘BGMはフェードインさせすぎず、最初の拍を明確に聞かせる

### 効果音

1. 足音停止
2. 遠い低音の鼓動
3. コア点灯の結晶共鳴音
4. 石装甲が擦れる連続音
5. 前脚着地の低い衝撃音
6. ヴェルグランの咆哮
7. 短い結晶残響

既存の短い「ピコン」系解除音は使わず、低音・石・根・結晶を重ねた臨場感のある音にする。

## 6. カメラ設計

- プレイヤーから祭壇までの移動：約0.9秒
- イージング：急停止しない滑らかな加減速
- コア点灯時：祭壇中心で固定
- 前脚着地時：弱い画面揺れ1回
- 戦闘位置への復帰：約0.7秒
- カメラ復帰が終わる前に操作を戻さない

## 7. 再戦時

- 一度でも初回演出を見た場合は短縮する
- 部屋へ入った時点で3人陣形へ移る
- ヴェルグランは立ち上がり済みの状態から開始する
- ボス名を約0.5秒だけ表示する
- 約1.5秒で操作を戻す
- 初回演出を再確認できるDEV項目は残してよい

## 8. スキップ

- 初回もE／クリック／Escape長押しでスキップ可能にしてよい
- スキップ後は必ず次の状態へ揃える
  - 3人が安全な戦闘陣形にいる
  - ヴェルグランが覚醒済み
  - カメラが操作キャラクターへ戻っている
  - ボスHP表示済み
  - ボスBGM再生中
  - 入力可能

## 10. 完了条件

- カイル単独入場から3人陣形への変化が分かる
- ヴェルグランが休眠状態から自然に起き上がる
- 胸部コアが最も強い視線誘導になる
- ボス名が正しく表示される

- 入口は閉じず、戦闘開始後も撤退できる
- 戦闘開始時の3人とボスが歩行可能床にいる
- 初回演出、再戦短縮、スキップの各終了状態が一致する
