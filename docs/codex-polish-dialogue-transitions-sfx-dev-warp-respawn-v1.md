# Codex向け実装指示：固定会話・演出音・層間接続・開発ワープ・敵再出現 v1

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：HUD表示、入力制御、音、マップ境界遷移、開発専用機能、遭遇再生成を既存進行へ安全に統合する中規模の横断修正だから。

## 1. 目的

現在の第1層・第2層で気になる次の点をまとめて改善する。

1. 石碑や門の付近で、古い薄い文字が点滅・残像のように見える
2. 重要メッセージが時間切れで消え、読み終えられない
3. 重要メッセージが一瞬で全文表示され、RPGらしい会話感がない
4. クリスタル、根の門、晶石足場の演出音が弱い
5. 開発確認のたびに第2層まで歩く必要がある
6. 第1層と第2層が地続きなのに、操作ボタンで層移動する感覚になっている
7. 撃破した敵が戻らないため、往復して経験値を稼げない

## 2. 最初に確認する箇所

- 添付スクリーンショットの赤丸部分
- `src/render/HudRenderer.ts`
- `src/game/GameWorld.ts`の`banner`、`bannerTimer`、`interactionPrompt`、`showBanner()`、`interactWithStage()`、層遷移、遭遇状態
- `src/input/InputController.ts`
- `src/audio/SfxSynthesizer.ts`
- `src/audio/sfxConfig.ts`
- `src/game/audioEvents.ts`
- `src/stage/maps/mossRootRuinsMap.ts`
- `src/stage/maps/lightwingCrystalCavernMap.ts`
- `src/stage/roomDefinitions.ts`
- `src/main.ts`のDEV/QA分岐

既存の短時間バナーをすべて会話へ置換しない。重要な進行説明だけを固定会話にし、敵発見や短い通知は従来のバナーのまま維持する。

## 3. 薄い文字の点滅・残像を解消

スクリーンショット赤丸の、白い案内文字の背後で薄い古い文字が点滅する状態をなくす。

想定原因：

- `bannerTimer`終端の低alphaバナーと`interactionPrompt`が同時描画されている
- 同じ場所で状態説明バナーが距離判定により繰り返し再発火している
- promptの上下位置がbanner有無で毎フレーム切り替わる

要件：

- `banner`と`interactionPrompt`を同一位置へ半透明で重ねない
- 消滅直前のバナー文字を長く薄く残さない
- 近接状態説明は範囲へ入った瞬間に一度だけ表示し、毎フレーム再発火させない
- 同じ対象の範囲内にいる間は再表示しない。範囲外へ十分離れてから再進入した時だけ再表示可
- 通常の近接操作案内は不透明で安定表示し、上下へチカチカ移動しない
- 重要会話表示中は通常バナーと近接案内を隠す
- Canvasをフレームごとに従来どおり正しくclearし、文字の物理的な描画残りも確認する

短時間バナーをフェードさせる場合も、文字alphaは終端0.15秒程度で素早く0にする。読み取り不能な薄い文字を1秒以上残さない。

## 4. RPG形式の固定会話ウィンドウ

重要イベント用に、時間では消えない会話状態を追加する。

推奨概念：

```ts
type DialogueState = {
  pages: readonly string[];
  pageIndex: number;
  visibleCharacterCount: number;
  characterTimer: number;
  sourceId: string;
} | null;
```

実際の型・配置は既存構造へ合わせる。

### 表示

- 画面下部、アクションHUDの上に濃い半透明の会話ウィンドウ
- 明るい枠線と小さな名前／分類ラベルを任意表示
- 1ページ最大2〜3行
- 日本語の禁則を厳密実装する必要はないが、画面外へはみ出さない
- 文末まで表示されたら右下へ小さな▼または`E / クリック`表示
- 重要会話中は`banner`と`interactionPrompt`を非表示

### タイプライター表示

- 1文字ずつ表示
- 基本速度：1文字あたり約28〜40ms
- 句読点`、。！？`は少し長く間を置く
- `E`、`Enter`、マウス左クリック、タッチで全文表示へスキップ
- 全文表示後に同じ入力で次ページ
- 最終ページ後に同じ入力で閉じる
- 入力直後に同じキーが二重判定され、開いた瞬間に閉じないようedge triggerまたは短い入力ロックを入れる

### 会話中のゲーム状態

- プレイヤー移動停止
- 味方AI停止
- 敵AI、攻撃判定、クールダウン進行を停止
- 戦闘中には重要ランドマーク会話を開始しない
- BGMは継続
- Escはポーズと競合させない。会話を閉じるキーにはしない
- Spaceはキャラクター交代と競合するため、会話送りには使わない

## 5. 固定会話へ変更するイベント

最低限、以下は時間制バナーではなく固定会話にする。

### 第1層

- 最初のクリスタルに触れた時
- 根の門が開いた時
- 石碑を作動させ、ショートカットが開いた時
- 第1層出口へ初めて到達した時の説明

例：

```text
クリスタルの奥で、強い光が脈打っている。
光が遺跡の根へ流れ込んでいく……。
```

根が開く演出完了後：

```text
絡み合っていた大きな根がほどけ、奥への道が開いた。
```

### 第2層

- 主晶石を作動した時
- 主晶石なしで副晶石を調べた時
- 副晶石を作動した時
- 湖上の晶石足場がすべて出現した時
- 第3層未実装門を調べた時

短い近接案内（例：`E　晶石に触れる`）は固定会話にしない。

演出と文章の順番を一致させる。文章を読み終える前に演出が全て終わって意味不明にならないよう、必要なら会話ページの送りをトリガーに次の演出段階へ進める。

推奨：

1. 対象に触れる
2. 1ページ目をタイプ表示
3. プレイヤーが送る
4. 会話を閉じ、クリスタル発光／根・橋の動作を再生
5. 演出完了後、結果説明を固定会話で表示
6. プレイヤーが閉じると操作再開

## 6. タイプ音

新しい音声ファイルを必須にせず、既存Web Audio系の合成SFXで実装する。

- 文字ごとに非常に短い控えめな音
- すべての文字で鳴らすと耳障りな場合は2〜3文字ごと
- 句読点、空白、改行では鳴らさない
- 音量は攻撃音よりかなり小さい
- ピッチをわずかに2〜3段階変化させる
- 高すぎる電子音や電話のキー音にしない
- BGMミュートとは別に、既存SFXミュート設定へ従う
- タイプ表示をスキップした時に残り文字分の音を連打しない

推奨イベント名例：`dialogueType`。

## 7. ランドマーク演出音

既存の`SfxSynthesizer`と音量管理を利用する。

### クリスタル

- 触れた瞬間：透明感のある高いキラキラ音
- 2〜4個の短い上昇音
- 長すぎず0.6〜1.0秒
- 第1層クリスタル、主晶石、副晶石で同系統を再利用可
- 推奨イベント：`crystalActivate`

### 根の門

- 重い低音の「ゴゴゴゴ」
- 木と石が擦れる質感
- 開放アニメーションの間だけ鳴る
- ループする場合は演出終了時に必ず停止
- 推奨イベント：`rootGateOpen`

### 晶石足場／橋

- 足場1個ごとに低い打撃音を順番に鳴らす
- 「ダン、ダン、ダン、ダン」と出現順が耳で分かる
- 最後の足場だけ少し高い完了音を加える
- 全足場分を同一フレームで鳴らさない
- 推奨イベント：`crystalPlatformRise`、`crystalPathComplete`

音の多重発火、会話を閉じた後の遅延再発火、層移動後の鳴り残りを防ぐ。

## 8. 第1層と第2層をマップ端で接続

操作して層を選ぶ門方式をやめ、地続きの出口として扱う。

### 第1層 → 第2層

- 第1層出口の通路をマップ北端または現在の出口方向まで伸ばす
- 条件を満たして出口が開いている時、プレイヤーが歩いて境界を越えると第2層へ遷移
- `E` / `Enter`は不要
- 遷移地点直前で通常操作案内を出さない
- 必要なら短い画面暗転を入れる
- 第2層では左端の入口から、進行方向を保って出現

### 第2層 → 第1層

- 第2層左端を歩いて境界外へ戻ると第1層出口側へ遷移
- 第1層側では出口の少し内側に出現し、即座に第2層へ再遷移しない距離を確保
- 戻った時もカメラを正しい位置へsnap

### 共通

- 戦闘中は境界遷移しない。まず敵から離れて逃走状態へ戻る必要がある
- 会話中、ポーズ中、演出中は遷移しない
- 境界へ押し続けた1入力で往復しないよう0.4〜0.7秒または十分な出現位置オフセットを使う
- HP、MP、経験値、キャラクター選択、ランドマーク進行状態を維持
- 一時的な攻撃、敵弾、エフェクト、戦闘陣形、古いinteraction promptは消す
- 探索BGMは同じ曲なら再開せず継続。将来別曲になった場合はクロスフェード可能な構造にする

## 9. 開発専用・第2層直行ワープ

ゲーム開始地点付近に、第2層へ直接飛べる開発用オブジェクトを追加する。

要件：

- `import.meta.env.DEV`の時だけ存在
- production buildには描画、衝突、操作案内、処理のすべてを含めない、または絶対に有効化しない
- 明確に本編外だと分かる見た目とラベル
- 例：紫色の小型ワープ結晶、`DEV　第2層へ移動`
- 近づいて`E` / `Enter`で第2層到着地点へ移動
- いきなり転送せず、誤操作防止の固定会話を出す

```text
【開発用】第2層「光羽の晶洞」へ移動しますか？
E / クリック：移動
Esc：キャンセル
```

- 確認UIが既存会話仕様を複雑にする場合は、2ページ目で`移動する`を明示して確定させる簡易方式でもよい
- DEVワープ後、第2層の通常入口位置へ出す
- 第2層の装置状態は初期状態を基本とする
- 必要ならURL QAは従来どおり残す

## 10. 敵の再出現

撃破した通常モンスターが、プレイヤーが十分離れた後または層を移動した後に再出現するようにする。経験値稼ぎを可能にする。

### 対象

- 第1層と第2層の通常遭遇グループ
- 任意戦と必須戦の通常モンスター

### 対象外

- 守護者／ボス（今後も撃破後は復活させない）
- 仕掛けの進行状態
- 根の門、石碑、晶石装置、足場
- 最終門の開通状態

### 再出現条件

同一層にいる場合：

- そのグループの全敵が撃破済み
- プレイヤーがグループのホーム中心から最低700px程度離れる
- グループのスポーン範囲が画面外である
- 戦闘中ではない
- 撃破後、最低5〜10秒程度経過している

この条件を満たした時、グループを「再出現待ち」から「未発見」へ戻し、元のホーム位置へ全員再生成する。実際の距離はマップ規模と既存追跡距離に合わせて調整可だが、画面を少しスクロールしただけで背後に即復活させない。

層を移動した場合：

- 移動元の通常遭遇グループを再出現可能な初期状態へ戻す
- 次にその層へ戻った時、通常敵はホーム位置へ復活
- 層入口の出現地点から見える敵が即攻撃してこない配置・発見距離を維持

### 経験値

- 再出現した敵は再度経験値を与える
- 1個体の死亡処理が同一出現中に複数回経験値を与えない既存保護は維持
- 再生成時に敵IDまたはlife generationを更新し、前回の`rewardGranted`等を正しく初期化
- 逃走しただけでは撃破敵を即復活させない
- 敵を1体だけ倒して逃げた場合の扱いは、グループが十分離れた後に全員初期配置へ戻る方式でよい。生存敵と撃破敵が不自然に混在し続けない

### 最終戦と門

- 第1層・第2層の最終門開放は一度達成したら維持
- 最終グループが後で復活しても、開いた門を再ロックしない
- 復活した最終グループは経験値稼ぎとして戦える
- 進行フラグと現在の敵生存状態を分離する

## 11. 既存表示との役割分担

### 固定会話

- 進行に関わる説明
- 仕掛けを作動した結果
- プレイヤーが読み終える必要がある文章
- 開発ワープ確認

### 短時間バナー

- 敵発見
- 戦闘開始／逃走
- 経験値取得
- 短い状態通知

### interaction prompt

- `E　クリスタルに触れる`
- `E　石碑を調べる`
- `E　晶泉に触れる`

3種類を同時表示しない。優先順位は固定会話 > 短時間バナー > interaction prompt。

## 13. 自動テスト

最低限、以下を追加・更新する。

1. bannerとinteraction promptが同時に同じ位置へ描画されない
2. 同じ対象の近接範囲内で状態バナーを繰り返し再発火しない
3. 固定会話が時間経過だけで閉じない
4. タイプ表示が順番に進む
5. 入力1回で全文表示へスキップできる
6. 全文表示後の入力で次ページへ進む
7. 最終ページ後の入力で閉じる
8. 会話を開いた入力で即座に閉じない
9. 会話中は移動、敵AI、攻撃が停止
10. 会話中にSpaceで交代しない
11. タイプ音が空白・句読点で鳴らず、スキップ時に連打しない
12. クリスタル音が操作1回につき1回発火
13. 根の音が演出終了時に停止
14. 足場音が出現順に発火し、最後に完了音
15. 第1層端を越えると第2層へ遷移
16. 第2層端を戻ると第1層へ遷移
17. 押し続けで層間を往復しない
18. 戦闘中は境界遷移しない
19. DEVでは第2層ワープが使用可能
20. production buildではDEVワープが存在しない
21. 同一層で撃破後、近距離では復活しない
22. 十分離れ、画面外、待機時間後に復活
23. 層を移動して戻ると通常敵が復活
24. 再出現した敵が再度経験値を与える
25. 同じ死亡で経験値を二重取得しない
26. 敵再出現後も開放済みの門・仕掛けが維持される
27. ボス相当フラグを再出現対象にしない
28. 既存の第1層、第2層、アリーナ、逃走、BGMテストが成功

## 14. 視覚・操作QA

1. 赤丸部分の薄い文字・残像・点滅が完全に消える
2. interaction promptが安定して読める
3. 会話ウィンドウがHUDやキャラクターを過剰に隠さない
4. 日本語が1文字ずつ自然に表示される
5. E、Enter、クリック、タッチで読み進められる
6. 根の開放、クリスタル発光、足場出現と音が同期する
7. 第1層から上へ歩き続けて自然に第2層へ入る
8. 第2層から左端へ戻って第1層へ帰れる
9. DEVワープが本編オブジェクトと誤認されない
10. 復活した敵が画面内へ突然出現しない

## 15. 維持するもの

- 第1層・第2層のマップ形状と主要ルート
- 3キャラクターと全攻撃
- 探索中1人、戦闘中3人
- キャラクター交代
- 通路封鎖なし
- 距離による逃走
- 回復地点
- EXP取得
- BGM切り替え

- アリーナモード
- ワンクリック起動

## 16. 実装順序

1. 表示残像の再現と原因特定
2. banner、prompt、固定会話の表示優先度を整理
3. 固定会話とタイプライター入力を実装
4. タイプ音を実装
5. クリスタル、根、足場の演出音を実装
6. 第1層↔第2層の境界遷移を実装
7. DEV専用第2層ワープを実装
8. 遭遇グループの再出現状態を実装
9. 進行フラグと敵生存状態の分離を確認
10. 自動テスト追加
11. `npm run typecheck`
12. `npm test`
13. `npm run build`
14. スクリーンショットと実操作で視覚QA
