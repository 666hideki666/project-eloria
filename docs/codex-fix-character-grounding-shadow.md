# Codex向け追加指示：カイルの足元と影を自然にする

正式なカイル待機・歩行スプライトを導入したところ、足元の明るい水色リングとブーツの間が離れて見え、カイルが宙に浮いているように見えます。

既存の移動、当たり判定、陣形、攻撃、HUD、BGM、効果音を維持しながら、キャラクターの接地表現を修正してください。

## 確認された問題

- カイルの足元に太い水色の楕円リングが表示されている。
- リングが床の影ではなく、発光する選択マーカーに見える。
- ブーツとリングの間に空間があり、接地位置が一致していない。
- 操作中であることは左HUDの強調枠と頭上マーカーでも分かるため、足元リングは情報が重複している。

## 推奨修正

### 1. 水色リングを削除

- 操作キャラクター足元の水色発光リングを通常時は表示しない。
- カイルだけでなく、キャラクター交代後のナディとメルにも同じ方針を適用する。
- 操作中キャラクターの判別は、既存の頭上マーカーと左HUDの強調表示を使用する。
- 交代直後の短い演出として一瞬だけリングを表示する場合は、0.2〜0.4秒で消えるようにし、常時表示しない。

### 2. 接地影

通常のキャラクター影が必要な場合は、発光リングではなく小さな暗い楕円を使用する。

- 色：黒に近い深緑またはチャコール。
- 不透明度：20〜30%程度。
- 幅：キャラクターのブーツ間より少し広い程度。
- 高さ：幅の25〜35%程度の薄い楕円。
- 輪郭線、発光、グラデーションの強い縁取りを付けない。
- キャラクターより先に描画し、必ず足元の後ろへ置く。
- 影の中心をブーツの接地点に合わせる。
- 影とブーツの間を空けない。
- 影はゲーム側で描画し、スプライト画像へ焼き込まない。

暗い床で影がほとんど見えなくても問題ありません。存在を主張する影ではなく、接地感を補助する影にしてください。

### 3. 足元アンカー

使用中のメタデータ：

- `assets/sprites/characters/kyle/kyle-idle-walk-48px-v1.json`
- 推奨アンカー：足元中央

現在の描画コード、スプライトの透明余白、影位置を確認し、次を調整してください。

- スプライトのブーツ底がワールド座標上の接地点へ合うようにする。
- 影の中心も同じ接地点へ合わせる。
- 必要なら描画専用の`offsetY`または`shadowOffsetY`だけを調整する。
- 見た目を合わせるために、キャラクターの物理座標や当たり判定を移動しない。
- 方向ごとにブーツ底の高さがわずかに違う場合も、歩行中に大きく上下へ跳ねないよう共通基準線を優先する。

## 頭上マーカー

- 現在の黄色い操作キャラクターマーカーは残してよい。
- 頭との距離が広すぎる場合は少し近づける。
- マーカーはキャラクターの歩行上下動へ追従する。
- 攻撃エフェクトや敵HPを隠さない大きさにする。
- 将来、正式な操作マーカーへ変更できるよう描画を分離しておく。

## 避ける修正

- スプライト画像へ影を直接描き込む。
- 水色リングを半透明にするだけで常時残す。
- 影をキャラクターより大きくする。
- 影へ水色、白、金色の発光を付ける。
- 接地感を直すために当たり判定や移動座標を変更する。
- 方向ごとに別のワールド座標オフセットを大きく設定する。

## 完了条件

- 通常時に水色の足元リングが表示されない。
- カイルのブーツが床へ接して見える。
- 接地影を残す場合は、小さく暗く、ブーツ直下にある。
- カイルが歩行中に上下へ不自然に跳ねない。
- 上下左右すべての向きで接地位置が自然。
- キャラクター交代後のナディとメルにも常時水色リングが残らない。
- 頭上マーカーと左HUDで操作キャラクターを判別できる。
- 移動、当たり判定、攻撃、交代、陣形が従来どおり動作する。

実装後は、カイルを上下左右へ向けた状態と歩行中を確認し、採用した`offsetY`、影サイズ、不透明度、水色リングを完全削除したか交代演出だけに残したかを日本語で報告してください。
