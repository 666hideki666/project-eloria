# 第3層：キャラクター接地確認とボス前回復晶石（承認待ち指示書）

この文書は `work | エロリア2` での画像レビュー・実装指示案。**コード実装は未承認**。ユーザーがこの内容を確認・承認してから、`コード実装 | エロリア2` で実装する。

## 1. 画像レビューと接地不具合

- 2026-09-30 10.20.01 のスクリーンショットでは、ナディの靴の下に小さい赤茶色の点が離れて見え、足が分離した印象がある。10.20.58 のスクリーンショットでは同じ違和感が目立たない。静止画だけでは、その点が靴・武器・エフェクト・背景のどれか断定できない。
- 現行コードは3人とも同じ接地影の描画方式を使い、`src/render/characterSpriteConfig.ts` でキャラクター・向きごとの描画Y補正を持つ。ナディの横向きは大きめの補正がある。透過画像の最下端には武器や杖が含まれる向きもあるため、画像全体の下端だけで足位置を決めない。
- 実装時にカイル・ナディ・メルそれぞれの上下左右、待機・歩行・通常攻撃・特殊技・大技、操作中と追従中を実画面で並べて確認する。ブーツ底、影、ワールド接地点、独立したエフェクトを区別する。特にナディの横向き・技終了直後と、カイル／メルの横向きを確認する。
- 不具合が再現できた箇所だけ、描画専用のオフセット、アニメーションフレームの切り出し、影・エフェクトの位置を修正する。`pos`、歩行可能マスク、当たり判定、戦闘判定を見た目合わせで変更しない。
- QA：向き変更・歩行開始停止・技から待機への復帰・交代・追従で足が浮く／床に埋まる／別パーツが残る状態がない。修正前後の比較スクリーンショットを3人分残す。

## 2. ボス前「再生晶石」案

- ビジュアル素材：`assets/concepts/environments/spirit-cloth-stonescale-depths/landmarks/preboss-restoration-crystal-concept-v1.png`。透明背景の**コンセプト画像**であり、実装用サイズ・余白・描画アンカーの調整は別途必要。青白い晶石を主役にし、低い石台座で第3層の石造遺構に合わせる。第2層の泉や門解除装置に見せない。
- 配置は、中央封印門を抜けた後、最終ボスへの階段より手前の広場の**端寄り**。中央の足跡模様と、門から階段への直進路をふさがない。実装時に赤線マスクの内部で歩いて近づける足元位置を確認し、画面上の見た目だけで座標を決めない。
- プレイヤーが隣接して `E` または既存のタップ操作で調べる。触れるだけで自動発動させない。門の未開放状態ではアクセスできない。
- 発動すると、戦闘不能の仲間を復帰させ、3人全員のHPとMPを最大まで回復する。第2層の晶泉と同じ回復結果を基準にしつつ、泉とは異なる短い光の演出・効果音・テキストにする。操作キャラが戦闘不能のままにならず、HUDと追従隊列も更新する。
- ボス再挑戦で詰まらないよう、戦闘外なら繰り返し使える。発動中の連打と戦闘中の使用は防ぐ。使用後に消滅しない。
- 台座は物体として通り抜け不可。ただし赤線の歩行領域そのものは変更せず、小さな局所的な物体衝突を追加する。前後の重なりは足元基準の深度順で描画し、背後に回ると晶石がキャラを隠す。
- 第3層の既存門、敵、ステージ遷移、ボス戦、回復晶泉には不要な変更を加えない。既存仕様書の「第3層に新しい回復の泉は追加しない」は維持し、今回の新しい晶石はユーザー要望による追加として扱う。

## 3. 確認項目

1. 封印門を開く前は晶石を利用できず、門を開いた後に広場で迷わず近づける。
2. 戦闘不能の仲間を含めた全員のHP・MPが満タンになり、HUD・操作交代・追従に矛盾がない。
3. 再使用、戦闘中の拒否、連打防止、晶石の物体衝突、前後の重なりが正常。
4. 門から最終階段までの歩行が妨げられず、マスク外へ出られない。
5. 3人の接地QAと回復晶石QAを、実際のゲーム画面で記録する。
