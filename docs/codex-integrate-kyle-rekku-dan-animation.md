# Codex向け追加指示：カイル大技「裂空断」モーションを導入

Project Eloriaへ、カイルの大技「裂空断」の4方向アニメーションを導入してください。

通常攻撃「連刃剣」と特殊技「破陣突き」で追加済みの共通アクションスプライト読み込み、方向固定、非ループ再生、終了後の待機・歩行復帰処理を再利用してください。大技だけ別方式のアニメーション管理にしないでください。

今回は表示モーションだけを追加します。ダメージ、飛翔速度、当たり判定、持続時間、クールダウン、効果音、風刃と風の軌跡など、既存のゲームプレイとエフェクトは変更しないでください。

## 使用素材

- 画像：`assets/sprites/characters/kyle/attacks/kyle-ultimate-rekku-dan-48px-v1.png`
- 設定：`assets/sprites/characters/kyle/attacks/kyle-ultimate-rekku-dan-48px-v1.json`

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- ループなし
- 再生時間：0.5秒

方向行：

- 0行目：下向き
- 1行目：上向き
- 2行目：左向き
- 3行目：右向き

各行は左から次の6コマです。

1. 地面を踏みしめた剣の構え
2. 剣を肩の後ろへ引いて腰を落とす
3. 両手で剣を頭上へ掲げ、最大まで力を溜める
4. 全身を使って前方・下方へ振り抜く
5. 低い姿勢で振り抜いた余韻を残す
6. 通常の構えへ戻る

剣は全コマの画像へ1本ずつ含まれています。別描画の剣を重ねないでください。風刃、斬撃光、床の亀裂、風の軌跡、石片、衝撃光などはスプライトへ含まれていないため、既存のゲーム側エフェクトを維持してください。

## 1. アクションスプライト登録

既存の`characterSpriteConfig.ts`へ、通常攻撃と特殊技と同じ構造で画像とJSONを読み込み、`KYLE_SPRITE.actions.ultimate`として登録してください。

設定値：

- フレームサイズ：48×48px
- 列数：6
- 方向別行：down 0 / up 1 / left 2 / right 3
- 足元アンカー：`x: 0.5`, `y: 0.92`
- ループ：なし
- 総再生時間：0.5秒
- コマ時間：`[0.06, 0.08, 0.11, 0.09, 0.09, 0.07]`
- 視覚的なインパクト：3番コマ

画像補間は無効にし、既存キャラクターと同じnearest-neighbor描画を使用してください。

## 2. 裂空断の発動へ接続

カイルが大技を使い、現在の`performUltimate()`内で

```ts
this.beginCharacterAction(member, "ultimate", 0.5);
```

が呼ばれた場合、この裂空断シートを再生してください。

- 発動開始時の`actionFacing`から方向行を一度選ぶ。
- 再生中は向きを固定する。
- キャラクター画像をコードで回転・左右反転しない。
- 6コマを1回再生し、終了後は現在の待機・歩行へ戻す。
- カイルのワールド座標は固定する。
- 画像内には踏み込み姿勢が含まれるため、ゲーム側で追加の突進移動を行わない。
- 同じ技を再発動したときは0番コマから再スタートする。

現在の裂空断のゲーム仕様を維持してください。

- クールダウン：8秒
- ダメージ：58
- 発生位置：カイル前方14px
- 飛翔速度：180
- 当たり半径：14
- 持続時間：1.3秒
- ダメージ倍率：1
- 既存の`windBlade` projectileを使用
- 既存の大技効果音を使用
- バナー：`カイル｜裂空断`

現在は大技入力時に風刃が生成されます。表示モーション導入のために、風刃生成を3番コマまで遅らせるなど、ゲーム判定のタイミングは変更しないでください。3番コマは視覚上のインパクトであり、新しいゲームロジック用タイマーではありません。

## 3. 既存の風エフェクトを維持

現在の5個の`wind`エフェクトをそのまま維持してください。

- 発生位置：カイル前方`8 + index * 7`
- 速度：前方`30 + index * 8`
- 寿命：0.52秒
- サイズ：`22 + index * 4`
- 色：`#dffff9`と`#46dcca`の交互
- 回転：カイルの向きに合わせる

スプライトには風の刃や軌跡が描かれていません。既存エフェクトを削除せず、振り抜きモーションへ重ねてください。

大技らしい迫力を追加する場合も、この作業では既存エフェクトの値や個数を変更しないでください。まず新モーションとの組み合わせをゲーム内で確認し、エフェクト調整は別作業に分けてください。

## 4. 描画と接地

- カイルの待機・歩行、連刃剣、破陣突きと同じdrawScaleを使用する。
- 足元アンカーは`x: 0.5`, `y: 0.92`を使用する。
- 6コマの間、カイルのワールド座標を固定する。
- 頭上の剣を収めるためにフレームごとの描画倍率を変更しない。
- 通常の接地影がある場合は既存方式を維持し、裂空断専用の大きな円形影を追加しない。
- 画像内の足運びを追加のワールド移動として扱わない。

## 5. 状態の優先順位

描画アクションの優先順位は既存の共通ルールを使用してください。

1. 戦闘不能
2. 大技・特殊技などの行動中
3. 通常攻撃
4. 移動
5. 待機

少なくとも次を保証してください。

- 裂空断中に連刃剣や破陣突きのシートを再生しない。
- 連刃剣、破陣突き、先陣斬りで裂空断シートを誤再生しない。
- 戦闘不能時は大技より戦闘不能表示を優先する。
- 行動中に移動入力があっても、大技モーションが即座に歩行へ上書きされない。
- キャラクター交代後も大技状態が不正に残らない。

## 6. 変更しないもの

- ナディとメルの全スプライト
- カイルの待機・歩行、連刃剣、破陣突き
- 先陣斬り
- 裂空断のダメージ、投射物、クールダウン
- 敵AI、当たり判定、ダメージ計算
- パーティー陣形、交代、後方補正
- HUD、回復、経験値、BGM、効果音

## 7. テスト

既存テストを維持し、可能なら次の確認を追加してください。

- カイルの`ultimate`画像とJSONが正常に読み込まれる。
- 大技は方向別の正しい行を使用する。
- 0.5秒で6コマを1回だけ再生する。
- 連刃剣、破陣突き、先陣斬りで大技シートが誤再生されない。
- 裂空断のクールダウン8秒、ダメージ58が変わっていない。
- 風刃の速度180、半径14、寿命1.3秒が変わっていない。
- 既存の5個の風エフェクトが維持される。
- カイルのワールド座標へ大技専用移動が追加されていない。
- 行動終了後に待機・歩行へ正常に戻る。

最後に`npm test`と`npm run build`を実行し、既存機能に回帰がないことを確認してください。

## 完了条件

- カイルが4方向すべてで剣を大きく振りかぶり、全身で振り抜く。
- 通常攻撃や破陣突きより明確に大きく、重い大技モーションに見える。
- カイルの足元がずれず、浮いたり瞬間移動したりしない。
- 剣が二重表示されず、全コマで1本だけ見える。
- 既存の風刃と5個の風エフェクトがモーションへ自然に重なる。
- 裂空断のゲーム数値と発動処理が変更されていない。
- 他キャラクター、特殊技、交代攻撃へ意図しない変更がない。
