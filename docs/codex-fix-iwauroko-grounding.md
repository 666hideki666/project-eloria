# Codex向け修正指示：イワウロコを地面へ接地させる

現在のイワウロコは、本体と影の間に隙間があり、浮遊モンスターのように見えます。モスプルンと同様に、脚と腹が地面へ接して見える描画へ修正してください。

## 原因

現在は次の組み合わせです。

- スプライトの`anchor.y`：`0.90`
- イワウロコの影中心：敵座標から下へ`8px`
- 影の縦半径：`5px`

48px画像内の不透明部分はおおむね43px付近で終わるため、0.94倍描画では本体の最下部が敵座標付近になります。一方、影の上端は敵座標より約3px下です。本体と影が重ならず、画面倍率によって明確な空間として見えています。

## 修正内容

### 1. 更新済みJSONを使用

`assets/sprites/enemies/iwauroko/iwauroko-idle-crawl-48px-v1.json`

の接地点は次へ更新済みです。

```json
"anchor": {
  "x": 0.5,
  "y": 0.82
}
```

JSONを再び`0.90`へ戻さず、既存の`createEnemySpriteConfig()`からこの値を読み込んでください。これにより本体が画面上で約4px下がります。

### 2. 影を本体の下へ潜らせる

`Renderer.drawIwaUroko()`の影を次へ変更してください。

```ts
context.fillStyle = "rgba(0,5,4,0.42)";
context.beginPath();
context.ellipse(0, 3, 19, 4, 0, 0, Math.PI * 2);
context.fill();
```

目標は、本体の脚・腹の最下部と影の上半分が3〜4px程度重なることです。影は本体より先に描画し、脚で影の中央付近が隠れるようにします。

飛行敵のような離れた楕円影や、上下する影アニメーションは使用しないでください。

### 3. 接地型の動き

- 待機中に上下ボブを追加しない。
- 重歩行中も敵のワールド座標と腹部の接地点を維持する。
- 攻撃予兆の`squash`で接地点が上下する場合は、変形中心を足元側に固定する。
- 突進中も影は本体へ追従し、別座標へ遅延させない。

### 4. フォールバック表示

装甲破壊後に使う`drawIwaUrokoFallback()`にも、独自の上下ボブを適用しないでください。

現在の次の処理：

```ts
const bob = Math.sin(time * 4 + enemy.id) * 0.5;
```

はイワウロコを接地させる目的と合わないため削除し、`enemy.pos.y`へ整数座標で描画してください。

影は`drawIwaUroko()`側で一度だけ描画し、フォールバック側で二重描画しないでください。

## 変更しないもの

- イワウロコの画像とアニメーションコマ
- 描画倍率`0.94`
- 当たり判定半径16
- HP132、装甲42、ダメージ30
- 移動速度、突進速度、AI
- HP・装甲バーの位置
- モスプルンのスプライト、影、ホップアニメーション
- ウツロボウ、ルミバネ、ガラクロウの浮遊表現

## テスト

次を確認してください。

- イワウロコの正式スプライトで、脚・腹と影が視覚的に重なる。
- 正面・背面・左・右の全方向で接地して見える。
- `idle`と`move`の全コマで影との間に空白ができない。
- 装甲破壊後のフォールバックでも上下に浮かない。
- 予兆、突進、被弾中も影が本体から離れない。
- モスプルンの影とホップ表示が変更されていない。

最後に実行してください。

```bash
npm test
npm run build
```

## 完了条件

- イワウロコが浮遊敵ではなく、重い体を地面へつけた接地型モンスターに見える。
- 影が本体から独立した黒い楕円に見えず、脚と腹の下へ自然に隠れる。
- モスプルンを含む他の敵描画に意図しない変化がない。
