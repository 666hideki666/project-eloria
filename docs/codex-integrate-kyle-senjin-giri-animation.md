# Codex向け追加指示：カイル交代攻撃「先陣斬り」モーションを導入

Project Eloriaへ、カイルの交代攻撃「先陣斬り」の4方向アニメーションを導入してください。

通常攻撃・特殊技・大技で追加済みの共通アクションスプライト読み込み、方向固定、非ループ再生、終了後の待機・歩行復帰処理を再利用してください。交代攻撃だけ別方式のアニメーション管理にしないでください。

今回は表示モーションだけを追加します。交代順、交代地点、陣形再構築、攻撃判定、ダメージ、ノックバック、交代クールダウン、効果音、斬撃エフェクトは変更しないでください。

## 使用素材

- 画像：`assets/sprites/characters/kyle/attacks/kyle-switch-senjin-giri-48px-v1.png`
- 設定：`assets/sprites/characters/kyle/attacks/kyle-switch-senjin-giri-48px-v1.json`

画像仕様：

- 全体：288×192px
- 1コマ：48×48px
- 6列×4行
- 透過PNG
- ループなし
- 再生時間：0.35秒

方向行：

- 0行目：下向き
- 1行目：上向き
- 2行目：左向き
- 3行目：右向き

各行は左から次の6コマです。

1. 低い姿勢で先頭へ入る
2. 身体をひねり、剣を振り始める
3. 剣が身体の前を横切る
4. 反対側へ大きく斬り抜け、青いスカーフが流れる
5. 味方を守るような低い残心
6. 安定した構えへ戻る

剣は全コマの画像へ1本ずつ含まれています。別描画の剣を重ねないでください。青緑色の斬撃、スカーフを思わせる短い軌跡、命中光などは画像へ含まれていないため、既存のゲーム側エフェクトを維持してください。

## 1. アクションスプライト登録

既存の`characterSpriteConfig.ts`へ、他の技と同じ構造で画像とJSONを読み込み、`KYLE_SPRITE.actions.switch`として登録してください。

設定値：

- フレームサイズ：48×48px
- 列数：6
- 方向別行：down 0 / up 1 / left 2 / right 3
- 足元アンカー：`x: 0.5`, `y: 0.92`
- ループ：なし
- 総再生時間：0.35秒
- コマ時間：`[0.045, 0.05, 0.06, 0.075, 0.065, 0.055]`
- 斬撃中の見た目：2、3番コマ
- 視覚的な最大振り抜き：3番コマ

画像補間は無効にし、既存キャラクターと同じnearest-neighbor描画を使用してください。

## 2. カイルへの交代時だけ再生

現在の`switchCharacter()`で次の操作キャラクターがカイルになり、`performSwitchAttack(incoming)`が呼ばれた場合、この先陣斬りシートを再生してください。

既存の

```ts
this.beginCharacterAction(member, "switch", 0.35);
```

をそのまま共通アクション開始として利用してください。

- 交代成立時のカイルの`actionFacing`から方向行を選ぶ。
- 0.35秒の間、選択した同じ行を使用する。
- キャラクター画像をコードで回転・左右反転しない。
- 6コマを1回再生し、終了後は待機・歩行へ戻す。
- 同じ技を再発動したときは0番コマから再スタートする。
- ナディやメルへ交代した場合、カイルのシートを再生しない。

## 3. 交代位置と陣形を維持

スプライト内には低い踏み込み姿勢が含まれていますが、ワールド座標上の突進ではありません。

- カイルを現在の後方位置から別地点へ瞬間移動させない。
- カイルへ追加速度やダッシュ距離を与えない。
- 交代直前の`incoming.pos`を維持する。
- 交代後の`followerState`、`followerTargetId`を変更しない。
- 送り出したキャラクターの`return`状態を変更しない。
- `formationRebuildTimer`と既存の陣形再構築を維持する。
- カイルの交代モーション中も、ゲーム側の通常の位置更新を二重に適用しない。

「交代位置へ高速で入る」印象は、低い構え、剣の速い振り、青いスカーフの流れ、既存効果音で表現してください。

## 4. 既存の攻撃判定を維持

現在の先陣斬り仕様をそのまま維持してください。

- 判定位置：カイル前方19px
- 攻撃半径：34
- 攻撃角度：`Math.PI * 0.7`
- ダメージ：26
- ノックバック：32
- 判定色：`#6be3dc`
- 交代クールダウン：現在の`COMBAT.switchCooldown`、0.48秒
- バナー：`交代｜先陣斬り`
- 既存の交代音とカイルの交代攻撃音を使用

現在の攻撃判定は交代成立時に即座に生成されます。3番コマまで判定を遅らせたり、2〜3番コマで判定を複数回生成したりしないでください。

JSONの`activeFrames`は見た目上の斬撃区間であり、追加の攻撃判定イベントではありません。

## 5. 既存の斬撃エフェクトを維持

現在の`slash`エフェクトを維持してください。

- 位置：カイル前方19pxの判定位置
- 寿命：0.27秒
- サイズ：37
- 色：`#72e7dc`
- 回転：カイルの向きに合わせる

スプライトには斬撃光が含まれていません。既存エフェクトを削除せず、2〜3番コマへ自然に重ねてください。

青いスカーフを思わせる短い軌跡を別エフェクトとして既に描画している場合は維持してください。未実装の場合、このモーション導入作業では新しいエフェクトシステムを追加せず、まず既存の`slash`との組み合わせを確認してください。

## 6. 状態の優先順位

描画アクションの優先順位は既存の共通ルールを使用してください。

1. 戦闘不能
2. 交代攻撃を含む行動中
3. 移動
4. 待機

少なくとも次を保証してください。

- 先陣斬り中に連刃剣、破陣突き、裂空断のシートを再生しない。
- 通常攻撃、特殊技、大技で先陣斬りシートを誤再生しない。
- 戦闘不能時は交代攻撃より戦闘不能表示を優先する。
- 交代直後の陣形移動で、モーションが即座に歩行へ上書きされない。
- 0.35秒後に行動状態が正常に解除される。

## 7. 変更しないもの

- ナディとメルの全スプライト
- カイルの待機・歩行、連刃剣、破陣突き、裂空断
- 交代順と交代可能条件
- 先陣斬りの攻撃判定・数値・エフェクト
- パーティー陣形と追従AI
- 敵AI、当たり判定、ダメージ計算
- HUD、回復、経験値、BGM、効果音

## 8. テスト

既存テストを維持し、可能なら次の確認を追加してください。

- カイルの`switch`画像とJSONが正常に読み込まれる。
- カイルへ交代した場合だけ先陣斬りシートを使用する。
- 開始方向に対応する正しい行を使用する。
- 0.35秒で6コマを1回だけ再生する。
- 攻撃判定が交代成立時に1回だけ生成される。
- 前方19px、半径34、角度`Math.PI * 0.7`が変わっていない。
- ダメージ26、ノックバック32が変わっていない。
- 交代クールダウン0.48秒が変わっていない。
- カイルのワールド座標へ追加の突進移動がない。
- ナディとメルへの交代ではカイルのシートを再生しない。
- 行動終了後に待機・歩行へ正常に戻る。

最後に`npm test`と`npm run build`を実行し、既存機能に回帰がないことを確認してください。

- カイルへ交代した瞬間、4方向すべてで素早い一閃モーションを再生する。
- 破陣突きの一直線の突きではなく、剣が身体の前を横切る広い斬撃に見える。
- 青いスカーフが流れ、先頭へ飛び込む速さを感じられる。
- カイルが交代位置から瞬間移動せず、陣形が壊れない。
- 剣が二重表示されず、全コマで1本だけ見える。
- 先陣斬りの攻撃判定、ダメージ、ノックバック、交代クールダウンが変更されていない。
- 他キャラクター、通常攻撃、特殊技、大技へ意図しない変更がない。
