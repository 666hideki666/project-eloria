# 指示書案：封印石取得後の再訪ではヴェルグランと対話する v1

状態：**2026-10-26、ユーザーが「これで実装して」と会話文・仕様を明示承認。同日に実装・技術検証済み。実機・聴感・ユーザーの演出評価は未確認。** 推奨実装モデル：**Sol High**。洞窟封鎖案はユーザーが撤回した。

## 目指す体験

- 封印石を手に入れて古の森に帰還した後も、洞窟へ自由に入れる。第１〜３層から祭壇へもう一度行ける。
- 再訪した祭壇には、鎮まったヴェルグランが奥で静かに鎮座している。ボス戦は二度と始まらない。話しかけると、各地の封印石にも同じ異変が及んでいるかもしれないことを告げ、旅の次の目的を託す。
- その話を聞かなくても古の森へ戻って村道からタイトルへ進める。再訪会話は任意の物語補足で、進行を止めない。

## 承認済み会話

> ヴェルグラン「森の晶光は鎮まった。だが、この乱れは森だけのものではない。」
>
> ヴェルグラン「ほかの地の封印石も、同じ光に揺れているかもしれぬ。どうか、あの石たちの声にも耳を傾けてほしい。」
>
> メル「……うん。私たち、確かめに行く。」

原因や黒幕をこの時点で断定せず、世界各地へ向かう動機だけを示す。初回と再訪で同じ短い会話を読める形を基本案とし、長い演出・新規イラストは追加しない。

## 現行実装で手当てが必要な点

- 古の森の洞窟入口は現状どおり通れる。この入口を塞ぐ修正は行わない。
- 現在、封印石後の `VelgranBossController` は `cleared` になるが、`CrystalAltarRenderer.drawVelgran` は `cleared` を描画せず、祭壇への再入場時に `GameWorld.configureStageRoom` が `cleared` を `resetForRetreat` で `dormant` に戻す。そのままでは見えなくなるか、再戦になる。**取得済みを優先する平穏な再訪状態**を維持し、再入場と祭壇内の退出を繰り返しても戦闘に戻さない。
- 平穏時のヴェルグランは奥の足場に実体を持つ。既存の立ち姿・待機絵から自然な静止ポーズを選び、キャラとの前後関係と素通りできない当たり判定を確認する。攻撃エフェクト、敵HP／装甲UI、戦闘BGM、報酬・経験値・封印石再取得は発生させない。
- 近づいたときだけ「E　ヴェルグランに話しかける」の鮮明な操作表示を出し、PCのE／タッチ操作で会話を開く。遠方からの発話や誤操作を避け、会話中は既存の入力抑止を使う。繰り返し話しかけても報酬や章末アニメは再生しない。
- 封印石取得前の初回戦闘・撃破・メルの語りかけ・封印石取得演出・森への自動帰還、森の村道解放とタイトル復帰は現状を維持する。赤線歩行マスク・背景・各層の仕掛け・音源は変更しない。

## 検証

- 初回は従来どおり１回戦い、封印石取得・章末アニメ・森帰還が成立する。
- 取得後、森→第１〜３層→祭壇へ実移動し、ボスが静止して見え、近距離で会話でき、攻撃を受けず戦闘UI／BGMが出ないことを確認する。会話を再度開いても報酬や封印石・演出が重複しない。
