# Codex向け修正指示：実用性のある根のショートカット v2

## 実行設定

- 推奨モデル：`GPT-5.6 Terra`
- 推論レベル：`High`
- `Sol` / `Ultra`：不要
- 理由：局所的なマップ再配線、進行フラグ、衝突、石碑座標、描画、経路テストの修正であり、ステージ全体の再設計ではないため。

## 背景

現在の石碑は、根を解除しても少し先で通常ルートへ合流するだけである。

確認画像：

- `/Users/katouhideki/Desktop/スクリーンショット 2026-08-12 8.17.00.png`
- `/Users/katouhideki/Desktop/スクリーンショット 2026-08-12 8.17.20.png`

問題：

- 開通前でも両側へ簡単に移動できる
- 開通後に省略できる距離が小さい
- 開通先に固有の目的がない
- 根の模様が周辺装飾へ紛れ、どこが開いたか分かりにくい
- 石碑を操作するゲーム上の意味がない

今回の目的は、石碑を「最終戦前に回復の泉へ戻るための、明確に便利な帰還路」に作り直すことである。

## 1. 完成後の役割

初回攻略では、次の長い必須ルートを維持する。

```text
右側戦闘広場
→ 回復の泉
→ 右上遺構
→ 上部を西へ横断
→ 左上の根迷路
→ 最終戦手前
```

左上の根迷路を突破した後に石碑を作動させると、次が直接つながる。

```text
左上の根迷路・最終戦手前
⇄ 根の隠し通路
⇄ 回復の泉付近
```

開通後は、最終戦前に泉へ戻って回復し、短い道で最終広場へ復帰できる。

## 2. 現在のショートカットを撤去

現在のK-K2間、概ね次の部分をショートカットとして使わない。

- `shortcutWest: (730, 600)`
- `shortcutEast: (1320, 620)`
- row 17〜21、column 32付近の`shortcutGate`
- その周辺にある、解除前から通常通路へすぐ合流する横断路

対応：

- 現在の条件付き通路は通常の壁、根、水、または本来の通常通路へ整理する
- `shortcutGate`だけ消して常時通路にする対応は禁止
- 開通前後で実質的な移動距離が変わらない構造を残さない
- 旧座標に見えない衝突、操作判定、開放エフェクトを残さない

周辺の通常ルートを壊さず、旧ショートカット部分はコンセプトに沿った中央の巨大根・水路の一部へ戻す。

## 3. 新しい石碑位置

石碑を右上の通常ルート途中から、左上の根迷路を抜けた側へ移す。

基準座標：

```ts
monument: { x: 470, y: 300 }
```

許容範囲：根迷路出口から最終広場へ折り返す途中の歩行可能位置で、±96pxまで調整可。

配置条件：

- 初回の長い上部ルートを通らないと到達できない
- 最終戦広場へ入る少し前に存在する
- 石碑を画面内で認識しやすい小広場または壁際
- 戦闘中は操作不可
- E/Enterで操作
- 操作前から回復の泉側へ抜けられない

旧の右上石碑区画は、古代の小広場または将来の宝箱候補として残してよいが、ショートカット開放操作は行わない。

## 4. 新しいショートカットの接続

新しい通路は、左上・最終戦手前と回復の泉付近を結ぶ専用経路とする。

基準となる両端：

```ts
shortcutUpper: { x: 610, y: 410 }   // 根迷路・最終戦手前側
shortcutSpring: { x: 1700, y: 1040 } // 回復の泉への通路側
```

完全な直線にせず、中央の根塊の内部または背後を通る、2〜4回曲がる専用通路として作る。

推奨タイル経路の骨格：

```ts
[
  [19, 13],
  [24, 15],
  [31, 17],
  [38, 20],
  [45, 25],
  [51, 31],
  [53, 33],
]
```

これは基準であり、既存の水・根・通常ルートとの交差を避けるため調整可。

通路条件：

- 幅96〜128px
- 途中で既存通常ルートへ合流しない
- 出入口2か所以外から入れない
- 戦闘を配置しない
- 敵の発見範囲と重ねない
- 閉鎖中は両端が物理的に分断される
- 開通後は両方向に通行可能
- 通路中央に将来の宝箱を置ける小さな脇部屋を1つ作る
- 今回は宝箱やアイテム機能を実装せず、空の台座だけ描画する

通路全体を`shortcutGate`にしない。床はあらかじめ存在し、入口または中央の狭い断面3〜4タイル分だけを条件付きの根で閉じる。

## 5. 距離短縮の数値条件

「見た目では近そう」ではなく、タイル経路探索で効果を保証する。

測定地点：

- 出発：回復の泉`MOSS_ROOT_RUINS.spring`
- 到着：最終戦広場入口または`MOSS_ROOT_LANDMARKS.finalPlaza`

条件：

```text
shortcut locked時の最短経路 - unlocked時の最短経路 >= 65タイル
unlocked時の最短経路 <= locked時の50%
```

65タイルは2080px相当であり、少なくとも約2〜3画面分の戻り道を省略する目安。

加えて：

- 開放前も通常ルートで泉から最終広場へ到達できる
- 開放前にショートカット入口間を通過できない
- 開放後は新通路が最短経路として選ばれる
- 旧ショートカット座標を通っても同等の短縮が起きない

数値を満たせない場合、通路の場所だけでなく既存ルートとの接続位置を見直す。テスト閾値を緩めて済ませない。

## 6. 開放状態と操作

既存の`shortcutUnlocked: boolean`を再利用する。

- 初期値`false`
- 新石碑を調べると`true`
- 一度開けばそのプレイ中は開いたまま
- 既に開放済みなら「石碑の紋様は静かに輝いている。」
- 戦闘中は「戦闘中は石碑を調べられない」
- 開放時バナー：「遠くで大きな根がほどける音がした」
- 進行、経験値、敵状態を変更しない

操作距離は現状の48px前後を維持し、地形越しに調べられない位置へ置く。

## 7. 開放演出

開通場所を一目で理解できるようにする。

石碑側：

- 石碑の紋様が暗い青緑から明るいシアンへ変化
- 小さな環状エフェクト
- 既存の魔力系SFXを利用

根の入口側：

- 絡んだ太い根が左右へ退く
- 通路中央へ青い光が1〜2秒走る
- 少量の葉、胞子、土の粒
- 開通後は根の切れ端を左右へ残し、以前閉じていた場所と分かる

画面外で開放された場合でも、バナーと音で変化を伝える。後で現地へ戻った時には明確に通路が開いている。

茶色い根の装飾を周辺へ無秩序に増やさず、閉鎖根は他より太く、シルエットを明確にする。

## 8. 専用通路の見た目

通常ルートと少し雰囲気を変え、「根の内側を通る近道」と分かるようにする。

- 床は細長い古い石畳
- 両側に太い根と暗い空洞
- 青い晶石または胞子を低頻度で配置
- 将来宝箱用の小部屋に空の台座
- 前景根でキャラクターを完全に隠さない
- 水や穴と歩行床の境界を明確にする
- 3人陣形でも通れる幅を確保

## 9. 維持する機能

- 2048×1920のワールド
- 開始から最終広場までの初回必須ルート
- モスプルン10体と4エンカウント
- 戦闘封鎖なし
- 距離による逃走
- 回復の泉
- 3人陣形と探索1人表示
- BGM切り替え
- 経験値重複防止
- 最終戦撃破による第2層門開放
- 基本地形ビジュアル改善
- アリーナモード

石碑の移動によって、初回攻略の必須ルートを短縮してはならない。ショートカットは上部へ到達した後の往復だけを便利にする。
