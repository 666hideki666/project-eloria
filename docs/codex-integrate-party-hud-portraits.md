# Codex向け追加指示：3人の正式HUDポートレートを導入

Project Eloriaの左側「PARTY STATUS」にある仮のCSS顔アイコンを、カイル・ナディ・メルの正式なピクセルアートポートレートへ差し替えてください。

ゲームロジックやフィールドスプライトには触れず、今回の変更範囲はパーティーHUDの顔表示だけに限定してください。

## 使用ファイル

- カイル：`assets/ui/portraits/kyle/kyle-hud-portrait-32px-v1.png`
- ナディ：`assets/ui/portraits/nadi/nadi-hud-portrait-32px-v1.png`
- メル：`assets/ui/portraits/mel/mel-hud-portrait-32px-v1.png`

各画像の仕様：

- 32×34px
- RGBA・透明背景
- 顔から胸元までの正面寄りポートレート
- 現在の`.party-portrait`表示枠と同じ寸法
- nearest-neighbor表示を前提とする

64×68px版と高解像度透過版は再加工用として残し、通常HUDでは32×34px版を使用してください。

## 実装方針

- `index.html`の既存クラス構造は可能な限り維持する。
- `.portrait-kyle`、`.portrait-nadi`、`.portrait-meru`へ、それぞれ対応画像を背景画像として割り当てる。
- ゲーム内部IDは既存の`meru`を変更しない。画像フォルダ名だけが`mel`であることに注意する。
- `background-repeat: no-repeat`、`background-position: center bottom`を使用する。
- 原則として`background-size: 32px 34px`または枠に対する100%表示とし、縦横比を崩さない。
- `image-rendering: pixelated`を維持する。
- 現在の仮顔を描いている`.party-portrait::before`と`::after`は無効化する。
- 外側の1px枠、操作中の強調、戦闘不能時の彩度低下と透明度は維持する。
- ポートレート画像そのものへ新しい色枠や背景色を焼き込まない。
- 透明部分の背面には現在の暗い緑色のHUD背景を残す。

## レスポンシブ表示

現在の小画面用CSSでは`.party-portrait`を26×28pxへ縮小しています。

- 既存のレイアウトを崩さず、画像も枠に合わせて縮小する。
- 小画面でも縦横比を維持し、顔が切れないこと。
- ブラウザの補間でぼやけないこと。
- 必要なら小画面時は64×68px版をCSSで縮小表示してもよいが、見た目を確認して採用する。

## 状態表示

- 操作中キャラクターの金色・青緑色の強調枠を維持する。
- HP、MP、操作中ラベル、自動回復待機マークを変更しない。
- 戦闘不能時はカード全体の既存フィルターがポートレートにも適用される状態を維持する。
- キャラクター交代時に正しいカードが強調されること。

## 変更しないもの

- カイル、ナディ、メルのフィールドスプライト
- キャラクターの移動、攻撃、回復、交代処理
- 敵AI、陣形、当たり判定
- BGM、効果音
- HP・MPの数値やゲームバランス
- HUD全体の配置とサイズ

## 完了条件

- 左HUDに3人の正式ポートレートが表示される。
- カイル、ナディ、メルの画像対応が正しい。
- 仮の四角いCSS顔が重なって表示されない。
- 32×34pxの枠内で顔や髪が切れていない。
- 通常画面と小画面の両方で画像がぼやけない。
- 操作中、非操作、戦闘不能の表示が正常に切り替わる。
- 開発サーバーと本番ビルドの両方で画像が読み込まれる。
- 既存のフィールド描画と戦闘機能に意図しない変更がない。

実装後は3人が通常状態の画面、キャラクター交代後、戦闘不能状態、小画面表示を確認し、採用した画像サイズとCSS指定を日本語で報告してください。
