## マップの読み取り

- 右下の帰還・入口テラスから中央の円形広場へ進む。
- 左枝は霊布の広間、右枝は石鱗の曲がった通路と複数の待避広場へ至る。両端は仕掛けを後置きできる空の石床。
- 中央広場から北の細い通路に唯一の中央封印門があり、その先に守護者の前室と最北のボス方面出口がある。
- 新背景・赤線には、旧プロトタイプの「右枝から入口へ戻る別の近道」は描かれていない。**見えない旧ショートカットを残さない。** 必要なら新たなユーザー赤線指定を受ける。
- 霊灯と石楔は両方作動して初めて中央門が開く。赤線は門の前後を含む**静的な床**を示すだけで、閉じた門・装置・立体物の衝突は別レイヤー。

参考の背景ネイティブ座標（厳密な配置値は実装と画面確認で決める）：入口 `(1450,900)`、中央 `(830,585)`、霊布広間 `(200,250)`、石鱗側終点 `(1425,230)`、門下側 `(830,380)`、守護者の前室 `(825,110)`、北出口 `(845,20)`。色・石畳・階段から範囲を増やさず、赤線とマスクを優先する。

## 実装指示（実装承認後）

1. 第3層の現在の手続き的タイル背景・床判定を、採用済み v2 背景とこの赤線マスクに基づく画像マップへ移行する。主な参照先は `src/stage/maps/spiritClothStonescaleDepthsMap.ts`、`src/stage/spiritClothStonescaleDepthsCollision.ts`、`src/render/stages/SpiritClothStonescaleDepthsRenderer.ts`、`src/game/GameWorld.ts`、`tests/stage.test.ts`。第1・2層は変更しない。
2. 背景・マスク・オブジェクト・カメラを **1638×960 の同一 source 座標**にそろえ、ワールドとの変換を一元化する。拡大表示時の非等方伸縮や座標の二重変換を防ぐ。古い 76×48 タイル位置や敵座標をそのまま流用しない。
3. プレイヤーの移動判定は足元接地点 `pos` の一点を静的マスクで調べる。線分全体を検査し、高速・斜め・ノックバック・フォロワー・敵・スクリプト移動・ワープが境界や閉じた門を飛び越えないようにする。戦闘・被弾・装置操作の半径は移動用の足元判定と分離する。
4. 中央封印門は、静的マスクを削るのではなく **独立した動的障害物**として、閉鎖中は通路の壁から壁まで塞ぐ。0/2・1/2 は通れず、霊灯と石楔の両方が作動し開門演出が完了した後だけ通れる。両端からのすり抜け、斜め抜け、背後へのワープを防ぐ。開門後は見た目と衝突が同時に開放され、見えない壁を残さない。
5. **閉じた大きな石門は背景 v2 に描き込まれている。** コライダーだけ解除しても見た目が閉じたままになる。背景全体を再生成して差し替えると画素位置がずれるため、扉部分だけに原寸で一致する開放状態のパッチ／前景レイヤーを作り、背景との継ぎ目を画素単位で確認する。合わない場合は適当に引き伸ばさず、画像レビューへ差し戻す。
6. 霊灯・石楔はそれぞれ空の終点広場に別オブジェクトとして配置し、台座等の立体物の足元だけ別コライダーとする。赤線床を全体的に縮めない。装置の前・横から操作距離内に立てることを実移動で確認する。
7. 既存の敵グループ・BGM・パーティ陣形・進行フラグ・第2層との往復・ボス前室への遷移は機能を保ちつつ、新座標に再配置する。敵は歩行範囲内かつ到達可能な位置に置き、開始地点や狭い階段を塞がない。旧ショートカット用の可視・不可視判定は新赤線外への経路にならないよう整理する。

## QA と完了条件

- マスクの入口・中央・左広間・右終点・門下・前室は連結。診断点 `(400,180)`、`(1590,350)` などの崖側は非歩行。画像外も非歩行。
- 診断用に門の足元帯 `x=770..904, y=311..334` を仮遮断すると、入口から中央・左右の広間へは到達でき、北の前室だけ到達不能になった。これは**経路構造の検算**であり、実際の門コライダーは門絵の足元と壁幅に合わせて再確認する。
- 背景 v2、赤線、マスク、装置、開門後の見た目を原寸で重ね、右下入口、左右の階段、石鱗側の二つの待避広場、中央門両端、北出口にずれがない。
- 入口から左右の装置まで、狭い階段を含めてゲーム内操作で実際に歩ける。赤線外・暗い崖・背景の飾り橋・画面外へは行けない。マスクの連結性だけで完了扱いにしない。
- 0/2、左のみ、右のみでは前室に入れず、両方作動＋開門演出後のみ通れる。左右の迂回・ダッシュ・ノックバック・キャラ交代・敵移動でも破綻しない。
- 北のボス方面出口と右下の第2層帰還が、画面端の赤線を越えて崖へ出ることなく正常に遷移する。
- 実ブラウザで全ルート・装置操作・戦闘・帰還・再入場を確認し、`npm run typecheck`、`npm test`、`npm run build` を通す。検証用ブラウザの音楽・タブ・サーバーは作業後に閉じる。
